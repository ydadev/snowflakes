# Snowflakes

Самостоятельное приложение на Rust для Windows 10 и Windows 11: снегопад с сугробами и дождь с лужами на рабочем столе и окнах. Панель управления и API работают как обычный сайт PHP + SQLite.

Проект: [ydadev/snowflakes](https://github.com/ydadev/snowflakes). Лицензия — [MIT](LICENSE).

## Состояние

Сейчас дорабатывается только снег и необходимая основа клиента. Дождь и лужи отложены; общий план проекта сохраняется.

P0 выполнен. P1 в работе: созданы Rust workspace, общий JSON-контракт, проверенный PHP/SQLite API и эксперимент прозрачного GPU-слоя. Основа P2 запускается в трее, хранит профили и имеет нативную панель. Первая реализация P3 рисует физический снег и сугробы через Direct2D; добавлены процентные размер и заметность снежинок. P4 подключает капли и брызги дождя; лужи, HTTP и установщик ещё в разработке.

Актуальный прогресс: [DEVELOPMENT_STATUS.md](docs/DEVELOPMENT_STATUS.md).

## Планируемые возможности

- Снегопад, накопление, смахивание, осыпание и таяние.
- Дождь, брызги, лужи, рябь, стекание и испарение.
- Отдельные регуляторы интенсивности снега/дождя и размера сугробов/луж.
- Несколько мониторов, прозрачный слой, пропуск ввода и управление из трея.
- Серверный профиль с опросом каждые 10 минут и отключаемой галочкой «Слушать сервер».
- Обычный PHP-сайт с прямым доступом по настраиваемому IP и порту.
- MSI, CLI и доменное развёртывание.

Пример локального стенда: http://127.0.0.1:805. Адрес конкретной установки задаётся отдельно. Файлы окружения и учётные данные в репозиторий не входят.
