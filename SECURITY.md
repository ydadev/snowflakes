# Безопасность и частные данные

Репозиторий содержит продукт и нейтральные примеры. Параметры конкретной организации, серверные адреса, личные данные, реквизиты и содержимое реальных панелей в него не входят.

## Секреты и конфигурация

- Пароли, токены и приватные ключи не хранятся в Git и Markdown.
- Рабочие настройки окружения, SQLite, журналы и резервные копии исключаются из публикации.
- Реальный IP и реквизиты клиента задаются при установке.
- Пользовательский токен защищается DPAPI; токены сервера имеют ограниченные права.
- Администратор сайта авторизуется отдельно; применяются безопасное хеширование пароля, HttpOnly/SameSite, CSRF и ограничение попыток входа.
- Код первичной установки индивидуален, а повторная установка после завершения блокируется.

Выбранный сценарий размещения — доверенная локальная сеть с настраиваемым HTTP-адресом. Учетная запись, сессия и клиентский токен сохраняют свои функции независимо от способа размещения.

## Проверка публикации

Проверяются содержимое файлов, история и сообщения коммитов, идентичность автора, артефакты и изображения. При обнаружении чувствительных данных публикацию остановить и зафиксировать только факт проблемы без значения секрета.

## Сообщение об уязвимости

Не прикладывать рабочие реквизиты, дампы и реальные данные к публичным issues. Если доступен приватный канал сообщения владельцу проекта, использовать его; способ связи уточнять без публичного раскрытия уязвимых данных.
