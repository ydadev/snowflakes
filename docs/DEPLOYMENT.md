# Установка и размещение

Документ описывает обычный PHP-сайт с прямым доступом по настраиваемому IP и порту. Реальные адреса, имена, реквизиты и вывод рабочих панелей сюда не включаются.

## Требования

- PHP 8.3+, PDO_SQLITE, JSON и sessions.
- Nginx/PHP-FPM либо совместимое PHP-размещение.
- Публичный корень public и приватные app/config/storage.
- Права PHP на запись в storage.
- IP и порт задаются при установке; значение порта по умолчанию — 805.

Пример локального стенда — http://127.0.0.1:805. На другом компьютере необходимо указать IP фактического сервера в частной конфигурации.

## Публикация PHP-пакета

1. Создать запись сайта/каталог на хостинге и выбрать подходящий PHP.
2. Настроить отдельный listener выбранного IP и порта с PHP-FPM pool сайта.
3. Загрузить готовый пакет и направить document root на public.
4. Оставить конфигурацию, БД и журналы вне публичного корня.
5. Проверить PHP-расширения, запись storage и пробную транзакцию.
6. Открыть установщик, ввести индивидуальный код и создать администратора приложения.
7. Проверить блокировку повторной установки, панель, API и резервное копирование.

Для HestiaCP использовать собственный шаблон на основе штатного PHP-шаблона, сохраняющий отдельный порт после пересборки конфигурации. Внутреннее имя записи сайта не требует DNS. [Шаблоны HestiaCP](https://hestiacp.com/docs/server-administration/web-templates).

Nginx поддерживает выбор сайта по адресу и порту. [Обработка запросов Nginx](https://nginx.org/en/docs/http/request_processing.html).

## Windows-клиент

1. Установить portable-пакет либо MSI.
2. Задать адрес управления и выполнить регистрацию клиента.
3. Проверить первый sync, подтверждение профиля и выключение эффекта сервером.
4. Проверить галочку «Слушать сервер» и независимый местный профиль.

Для доменной установки применяются GPO и административные инструменты по ТЗ. Машинная установка и пользовательский графический сеанс разделены.

## Обновление и восстановление

Перед обновлением сохранять совместимую копию конфигурации и БД. Обновление выполняет миграции и сохраняет пользовательские настройки. Проверить возврат предыдущей версии и восстановление БД с новым generation_id.

## Частные параметры

Данные конкретной установки допустимы только в игнорируемом .local/ или соответствующем защищённом хранилище. Пароли, токены и ключи в Markdown не записываются. Готовые пакеты не должны содержать рабочие конфиги, БД и журналы.
