# Цель разработки Snowflakes

Реализовать версию 0.1 самостоятельного приложения для Windows 10/11 x64 на Rust: снегопад с сугробами и дождь с лужами, четыре регулятора осадков/накопления, процентные размер и заметность снежинок, взаимодействие с курсором и окнами, трей и несколько мониторов. Реализовать обычный PHP + SQLite сайт управления, опрос каждые 10 минут, переключение на независимый местный профиль и доменное развёртывание MSI/GPO.

## Порядок выполнения

Текущий приоритет — только снег и необходимая для него основа клиента P2/P3. Разработка дождя и луж отложена; к P4 возвращаться после отдельного указания. Сайт и развёртывание сохраняются в общем объёме проекта, но сейчас не заменяют работу над снегом. Отложенные требования не считаются выполненными, общий критерий завершения проекта сохраняется.

1. Читать AGENTS.md, DEVELOPMENT_STATUS.md и ROADMAP.md перед началом работы.
2. Выполнять следующий незавершённый этап, сохраняя проверяемые промежуточные результаты.
3. Проверять требования по TECHNICAL_SPEC.md, CENTRAL_CONTROL.md и TEST_PLAN.md.
4. Обновлять статус и решения по итогам каждого законченного шага.
5. Подтверждать условия завершения реальными проверками. Отсутствующий стенд или непроведённый тест записывать явно и продолжать независимые задачи.
6. Публиковать только нейтральные исходники, документацию и синтетические примеры; проверять содержимое и метаданные перед push.
7. Считать цель достигнутой после выполнения всех условий P7 и обязательных критериев приёмки версии 0.1.

## Критерии результата

- Оба режима погоды и накопления работают на обеих ОС.
- Эффект не мешает работе, имеет заданные регулировки и проходит проверки окон/DPI.
- Сайт устанавливается готовыми файлами и управляет клиентами по общему контракту.
- Местный профиль, серверное выключение, кеш и паузы работают по требованиям.
- Проверены упаковка, установка, обновление, удаление и доменный запуск.
- Измерены производительность и устойчивость; непроверенных обязательных требований не осталось.
- В публичной истории, исходниках, примерах и артефактах нет секретов и сведений реальной инфраструктуры.
