# Матрица требований снега SN/CT

Дата сверки: 13 ноября 2026 года. Источники: [ТЗ](TECHNICAL_SPEC.md), [симуляция](../crates/snowflakes-client/src/snow.rs), [геометрия](../crates/snowflakes-client/src/geometry.rs), [нативная отрисовка](../crates/snowflakes-client/src/platform/weather.rs), [управление](../crates/snowflakes-client/src/control.rs) и [тесты снега](../crates/snowflakes-client/tests/snow.rs). Активны только P2/P3; P4 отложен.

«Проверено моделью» означает подтверждённый сценарий автоматического теста. Это не завершение требования на реальном рабочем столе. Видимая приёмка, обе ОС, задержки и показатели производительности не следуют из успешной компиляции или числа тестов.

## SN

| Требование | Текущее доказательство | Остаток |
| --- | --- | --- |
| SN-01 Разнообразие и силы | Flake::integrate, random_flake, seed_air; gravity_drag_and_mass_determine_terminal_speed, percentage_scaling_preserves_the_distribution_and_existing_velocity; кристаллы рисуются в GPU-пути | Визуальное восприятие и обе ОС Not run |
| SN-02 Ветер | changing_wind_accelerates_a_body_instead_of_replacing_its_path; нативный trackbar проверяет отрицательные/положительные значения, Controller хранит отдельное поле снега | Настоящее взаимодействие регулятора с видимым эффектом Not run |
| SN-03 Доступные опоры | Scene::supports, двумерные маски; visible_ledges_respect_front_to_back_order_and_monitor_edges, covered_snow_keeps_its_mass_and_ignores_cursor_and_new_deposits | Реальная классификация всех обычных/системных окон, несколько DPI и обе ОС не приняты |
| SN-04 Уклон и края | Drift::relax переносит массу между соседними ячейками; shed_edges отделяет связные куски от перегруженной неподвижной кромки. Девять новых сценариев проверяют массу, маски, паузы, бюджет, 256 опор, FPS/DPI и индекс; [результаты](TEST_RESULTS_SNOW_EDGES.md) | Модель подтверждена в указанных сценариях; видимая оценка, реальные DPI/окна, обе ОС и потребление ресурсов не приняты |
| SN-05 Движение окна | gentle_window_motion_retains_the_snow, abrupt_window_acceleration_detaches_material_and_it_falls_past_its_ledge, teleporting_a_window_does_not_create_a_particle_explosion | Реальное перетаскивание, смена DPI/монитора и изменения размера при частично приостановленной опоре не приняты |
| SN-06 Закрытие и пласты | Связные пласты сохраняют исходный профиль и образуют горки. Маски бывшей опоры сохраняют перекрытие в полёте по текущим прямоугольникам окон; десять новых сценариев проверяют узкое перекрытие, контакты, курсор, паузу, FPS/DPI и очереди. [Результаты](TEST_RESULTS_FALLING_MASKS.md) | Подтверждена модель указанных сценариев. Пиксели GPU, видимое закрытие/сворачивание, виртуальные рабочие столы и обе ОС не приняты. Нижняя опора сохраняет прежний слой; полное представление всей массы при экстремальном насыщении очереди также не принято |
| SN-07 Курсор | Локальное смахивание восстановлено; off/on проверены, маски исключают скрытый профиль; [ADR 0012](adr/0012-cursor-sweeping.md) | Неподвижное наведение и смахивание на видимом стенде с новым набором настроек не приняты |
| SN-08 Таяние и время | Отдельный флаг, ограниченное удаление за шаг; physical_state_matches_at_thirty_and_sixty_display_frames, battery_transitions_preserve_trajectories_and_accumulation | Реальное время/частота кадров и длительный прогон Not run |
| SN-09 Предел и свободное место | Ёмкость, headroom и общий лимит входящих потоков relax; шесть новых сценариев подтверждают узкий зазор, ожидающую массу, размеры, паузы, разные верхние границы, отражение DPI и 30/60 FPS. [Результаты](TEST_RESULTS_SNOW_CAPACITY.md) | Модель подтверждена в указанных сценариях; реальные окна/панели, DPI/hotplug, обе ОС и длительная нагрузка не приняты. Плавный переход ранее накопленного избытка сохраняется |
| SN-10 Выключение накопления | Четыре сценария переключателей подтверждают постепенное удаление осевшей/ожидающей массы, размер 0, паузы, возврат и обновление сцены | Визуальная приёмка и обе ОС Not run |

## CT — область снега

| Требование | Текущее доказательство | Остаток |
| --- | --- | --- |
| CT-01 Независимость интенсивности | Профиль разделяет интенсивность, лимит и ветер; emission_and_drift_limit_are_independent_and_clear_is_accounted | Проверка видимого поведения и частоты применения Not run |
| CT-02 Интенсивность 0 | emission_tracks_logical_width_and_intensity_and_zero_intensity_adds_no_mass: после выключения эмиссии introduced_mass не растёт; обычное таяние управляется отдельно | Визуальная приёмка Not run; вода Deferred |
| CT-03 Пропорция и ширина | Тот же сценарий проверяет 25/50/100% на 1920 DIP при синтетических 100/200% до насыщения бюджета, отклонение не более одной частицы | Реальный DPI и измерение длительной частоты Not run |
| CT-04 Поступление и предел | Ограниченная deposit_capacity, независимое хранение; full_drift_does_not_recycle_excess_into_a_future_growth_wave | Визуальная скорость роста и насыщенная сцена не приняты |
| CT-05 Качество и баланс | Существующее снижение качества меняет FPS/дополнительные проходы, физические состояния совпадают при 30/60 FPS | Это не доказательство произвольного прореживания основных частиц или реального бюджета GPU; вода Deferred |
| CT-06 Увеличение лимита | raising_a_drift_limit_does_not_inflate_a_resting_profile; возврат из уменьшения сохраняет оставшуюся массу | Визуальная приёмка Not run |
| CT-07 Уменьшение лимита | Пять новых сценариев интенсивности/лимита; четыре подтверждают переход ненулевого лимита, паузу, resize, ожидающую массу, 30/60 FPS и 100/200% | Визуальный переход и обе ОС не приняты; [результаты](TEST_RESULTS_SNOW_LIMITS.md) |
| CT-08 Размер 0 | accumulation_switches_remove_small_piles_and_pending_mass_gradually и независимые проверки эмиссии | Визуальная приёмка Not run; вода Deferred |
| CT-09 Ширина воды | К снегу не относится | Deferred вместе с P4 |
| CT-10 Применение за 200 мс | Отдельные потоки, очередь и сохранение до применения реализованы | Нет измерения пути ввод → сохранение → кадр, включая задержку диска. Серверная часть Deferred. Требование не засчитано |
| CT-11 Пресеты | Контроллер, TOML и скрытая панель подтверждают 20/50/85%, custom, политики и порядок очереди; [результаты](TEST_RESULTS_SNOW_PRESETS.md) | Видимая приёмка Not run; пресеты дождя Deferred |
| CT-12 Процентный размер | Сохраняются относительные размеры и распределение, интенсивность/лимит независимы; размер пластов не меняется | Визуальная приёмка Not run |
| CT-13 Заметность | visibility_is_an_appearance_setting_and_cannot_change_physics, global_opacity_changes_no_particle_motion_or_accumulation; поля панели/CLI подключены | Рендер при 0/100/200% заметности и разных фонах требует видимой проверки |

## Очередь дальнейшей работы

1. Проверить представление сброшенной массы при насыщенной очереди; ограниченный бюджет не должен подменять требуемые горки невидимым стоком.
2. Добавить измеряемое подтверждение CT-10 и бюджеты P3.
3. Выполнить разрешённую нативную матрицу Windows 10/11, ввода, DPI, мониторов, событий, оседания около перекрытий, осыпания кромки, перекрытия падающих пластов и длительного прогона.

Матрица не объявляет P2/P3 или весь проект завершёнными. Рабочий эффект не возобновляется без отдельного запроса; отложенные дождь, сайт и поставка не заменяют текущую работу над снегом.
