# Проверки управления автоматическими паузами

Дата: 14 ноября 2026 года. Windows 11 x64, Rust 1.99.1/MSVC. P2-01/04, OS-06/08. [Решение](adr/0045-auto-pause-controls.md).

## Реализованный результат

Галочки панели и --set pause_fullscreen=true/false, pause_remote_session=true/false изменяют существующие поля performance местного профиля. При серверном источнике действует режим только для чтения. Обязательная политика Windows удерживает эффективную паузу; сохранённое предпочтение возвращается после снятия ограничения. Ручная пауза, пресет снега и масса не сбрасываются. [Описание команд](CLIENT_CLI.md).
