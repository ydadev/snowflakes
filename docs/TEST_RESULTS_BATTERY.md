# Проверки экономии батареи

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P2/P3, раздел производительности ТЗ. Этапы остаются In progress.

Полный tools/check.ps1 Passed: 130 тестов клиента, 3 теста протокола, fmt, clippy с -D warnings, release, JSON Schema, PHP syntax, контракт, SQLite и HTTP. Добавлены пять сценариев; существующие проверки скрытой панели, нативных уведомлений и отдельного IPC-процесса расширены.

| Проверка | Результат |
| --- | --- |
| Выбор качества | Passed: батарея снижает цель 60 → 30; цель 30 не повышается; отключённая настройка экономии сохраняет качество; исходный профиль равен копии |
| События питания | Passed: батарея, сеть, ИБП и системная экономия независимы; неизвестные значения сохраняют предыдущее состояние; PBT_APMPOWERSTATUSCHANGE запрашивает сверку |
| Пауза и время | Passed: события качества не меняют revision пауз, местный профиль и ручную паузу |
| Нативный путь | Passed: GetSystemPowerStatus возвращает документированные числовые значения; зарегистрированы три уведомления; скрытое HWND принимает синтетические DWORD-сообщения и игнорирует неверную длину |
| Физическое состояние | Passed: за 18 секунд со сменой 60/30 FPS каждые 3 секунды позиции, скорости, углы, масса частиц и профиль сугробов совпадают с непрерывными 60 FPS; проверено сохранение массы |
| Настройки | Passed: target_fps и battery_saver сохраняются и перечитываются; серверный режим отклоняет местное изменение; неверный FPS не записывается; политика 30 FPS сохраняет местное предпочтение 60 |
| Панель | Passed: скрытые Win32-контролы передают обе независимые команды, сохраняют значения и ручную паузу, отключаются при серверном управлении |
| IPC | Passed: команды проходят через отдельный headless-процесс теста, сохраняют паузу; без графического worker effective_target_fps=0 |

Пропуск вторичных графических проходов проверен по исходному пути draw и компиляции. Автоматический тест физики не является визуальным сравнением рендера или измерением потребления.

Not run: настоящее отключение/подключение зарядки, переключение системной экономии через интерфейс, реальный ИБП, расход энергии/CPU/GPU, визуальное сравнение качества и управление новыми полями клавиатурой при разных DPI, Windows 10. Системные параметры питания не менялись, новый эффект на рабочем столе не запускался.
