# Проверки очереди выпавшего снега

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P3-03/04, SN-06 и бюджеты материала. Разработка остаётся сосредоточена на снеге; P4 отложен.

Полный tools/check.ps1 Passed: 189 тестов клиента, 3 теста протокола, fmt, clippy с -D warnings, release, JSON Schema, PHP syntax, контракт, SQLite и HTTP. Добавлены семь сценариев: шесть snow и один библиотеки; два прежних сценария насыщения усилены. Всего 85 сценариев снега/геометрии.

| Сценарий | Результат |
| --- | --- |
| Переполнение широкой опоры | Сначала Failed: очередь превращала около 11755,72 единицы массы, примерно 21%, в сток. После исправления Passed: вся масса сохранена без стока, число записей ограничено, тела связные |
| Объём, центр и приземление | Passed: при синтетических 100/200/400% очередь содержит 128 записей; площадь каждого профиля соответствует его массе, не более 16 ячеек. Общий центр до шага совпадает с исходным. После падения более 99,9% исходной массы находится в нижнем сугробе, записи масок освобождены |
| Полный активный бюджет | Passed: 2400 частиц на приостановленном экране не меняются; 240 закрытий другого экрана сохраняют массу в 128 ожидающих записях. После явного освобождения мест материал выпускается и образует горки |
| Невидимые источники | Сначала Failed на плотном приземлении: из 14640 единиц видимого материала около 293 провалились мимо выросшего сугроба. После исправления перекрытия Passed: видимая масса образует горки, невидимая остаётся отдельной и становится предусмотренным стоком |
| Число классов и отключение экранов | Passed: 65 синтетических экранов с двумя видами источников используют 130 записей; после сокращения до одного экрана — 128. При паузе масса сохраняется, Clear учитывает её полностью. Это не испытание настоящего hotplug |
| FPS, пауза и сцена | Passed: при 30/60 FPS после паузы и повторных снимков сцены совпадают положения, скорости, контуры, ключи слоёв и баланс |
| Перекрытие с растущей горкой | Passed: уже перекрывающий сугроб пласт принимает контакт немедленно; частица ниже крыши окна не возвращается на неё |
| Тонкий слой и передний слой | Passed: насыщение двух широких опор сохраняет тонкий материал связным, с маской переднего окна, без нового стока |
| Импульс и численная устойчивость | Passed: уплотнение двух профилей сохраняет массу, центр и линейный импульс; профиль имеет 16 конечных неотрицательных высот. Почти нулевая масса с округлившейся до нуля высотой не вызывает NaN |

Первый полный прогон выявил проваливание плотных пластов, поэтому успешный ограниченный прогон очереди не считался достаточным. После исправления контакта выполнен полный набор. Прежние сценарии смахивания, плавных размеров, осыпания, масок и пауз проходят.

Not run: внешний вид укрупнённых профилей, реальные задержки выпуска, CPU/GPU/память под потоком закрытий, настоящие DPI/мониторы, Windows 10 и длительный прогон. При полном активном бюджете очередь пока ждёт места; испытание сохранения массы не доказывает своевременный выпуск или независимость бюджетов при паузе одного экрана. Консервативное объединение масок может дополнительно скрыть часть объединённого профиля. Рабочий эффект для этапа не запускался.
