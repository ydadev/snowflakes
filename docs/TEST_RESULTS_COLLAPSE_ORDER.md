## Две воспроизведённые регрессии

На синтетическом экране шириной 12000 физических пикселей при масштабе 100% создан полный активный пул из 2400 пластов. Затем закрытие небольшой старой крыши и широкой крыши заполняет очередь до 128 записей. Широкая крыша нужна, чтобы вызвать уплотнение без большого числа окон; это не базовый аппаратный стенд ТЗ.

При объединении нового близкого снега с ранней записью прежний код отправлял агрегат в конец. После естественного выхода одного активного тела первым выпускался более поздний дальний материал. Тест Failed. Исправление сохраняет прежнее место старого родителя; тот же тест Passed при 100/200%.

Второй сценарий создаёт две близкие старые крыши перед большим поздним поступлением. После исправления только первой ветви он всё ещё Failed: объединение двух ожидавших записей тоже меняло порядок. Исправлена вторая ветвь, проверка Passed при обоих масштабах.

| Сценарий | Результат |
| --- | --- |
| merging_new_snow_does_not_send_the_oldest_waiting_roof_to_the_back | Passed после Failed: первый свободный слот получает старый агрегат, очередь остаётся ограниченной |
| merging_two_waiting_roofs_preserves_their_oldest_admission_position | Passed после Failed: объединение ожидавших родителей сохраняет раннее место |
| repeated_arrivals_and_paused_scene_refreshes_keep_old_snow_first | Passed: 24 закрытия при паузе, неизменность полей всех 2400 летящих тел, предел 128, масса агрегата и выпуск после возобновления/освобождения места |
| compacted_waiting_order_matches_at_thirty_and_sixty_fps | Passed: совпадают очередь, положения, скорости, углы, возраст и масса после одинакового физического времени |

Выход одного тела выполняется обычным шагом модели, а не удалением из вектора. На этом шаге освобождается место; на следующем активном шаге выпускается старый агрегат. Проверка баланса учитывает явный сток вышедшего тела. В повторном сценарии масса выпущенного агрегата совпадает с суммой старой крыши и новых порций в пределах 0,1%.
