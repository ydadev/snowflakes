# Предупреждения конфигурации в журнале

Дата: 16 ноября 2026 года. Область: P2-03, ненумерованное требование TECHNICAL_SPEC об неизвестных полях и допустимых значениях TOML. Решение: [ADR 0091](adr/0091-configuration-warning-counts.md). Производственные изменения ограничены Controller и типами локального журнала; разбор и нормализация не менялись.

## Воспроизведение

Новая регрессия на исходниках до исправления завершилась Failed с configuration warnings were not journaled. До этого условия проверили настоящий UserStore/Controller, 13 предупреждений, исправленные значения, двадцать чтений статуса с ручной паузой и побайтную сохранность входного файла. Отсутствие записи подтверждено явно, а не выведено из поиска по коду.

Исправление группирует предупреждения существующего загрузчика по четырём категориям. В журнал попадают только фиксированный вид и количество. Неизвестные имена ключей, включая вложенные пути, и значения не передаются писателю. Количество относится к WarningKind загрузчика, а не к каждому листу неизвестной таблицы. Чистые категории не пишутся, Recovered остаётся одним прежним событием.

| Три новые проверки конфигурации/журнала | Passed в debug/release |
| Две прежние проверки восстановления/отказа сохранения | Passed в debug/release |
| tools/check.ps1 | Passed: 545 + 3 + 8 выполнений Rust, 47 ignored |
| CI окончательных исходников | Passed: [0f01bcf](https://github.com/ydadev/snowflakes/actions/runs/43760496484) |

## Независимые условия

Смешанный вход содержит три неизвестных ключа, один неверный тип, семь ограниченных чисел и два неверных значения. Проверяются четыре итоговые записи с точными категориями/количествами и сумма configuration_warnings=13. Сравниваются нормализованные интенсивность, ветер, размер/заметность снежинок, прозрачность, режим, флаг накопления, интервалы и пустой отклонённый адрес. Исходный TOML остаётся побайтно прежним; повторный Status сохраняет ручную паузу и не порождает повторных записей. В тексте JSONL отсутствуют синтетические приватные ключи/значения/адрес и временный путь.

Отдельный допустимый по размеру файл содержит 2500 неизвестных ключей. Требуются ровно одна поставленная в очередь запись, отсутствие переполнения, полный счётчик 2500 и итоговая строка короче 512 байт. Этот тест защищает от реализации с отдельным событием на каждое поле.

Два входа без предупреждений — отсутствующий файл и сохранённый штатный профиль — не ставят события в очередь и не создают каталог журнала. Отсутствующий профиль не создаётся чтением. Прежняя проверка повреждённого TOML сохраняет ровно одно событие восстановления; отказ атомарного сохранения сохраняет настройки, диск и ручную паузу.

## Общие регрессии и границы

Окончательный tools/check.ps1 Passed: fmt/clippy, 545 тестов клиента + 3 протокола + 8 release-повторов — 556 выполнений и 548 уникальных проверок Rust; 47 ignored, библиотечный набор 232. Восемь прежних smoke-отпечатков и границы массы/пулов сохранены. Все пять проверок control::error_tests дополнительно Passed в release. Сборщики 35/31 assertions прошли в одной локальной редакции PowerShell; прежние schema 60, PHP 60+5, SQLite/HTTP прошли как регрессии компонентов. Разработка воды/сайта не возобновлялась.

CI исходников [0f01bcf](https://github.com/ydadev/snowflakes/actions/runs/43760496484) завершился success в задачах Windows и contract-and-php. Декодированный Windows-журнал подтвердил три новые и десять прежних проверок журнала, общий набор 545+3+8, 47 ignored и восемь прежних отпечатков. Сборщики 35/31 прошли в обеих редакциях PowerShell; контрактный журнал подтвердил schema 60, PHP 60+5, SQLite/HTTP. Пять дополнительных release-проверок control::error_tests выполнялись локально; обычный CI сохранил прежние восемь release-повторов.

Нативные UI/Worker-пробы повторно не запускались: их интерфейсы не менялись. Автоматические проверки временного хранилища не заменяют настоящие ошибки Shell/GPU, многопользовательскую матрицу, видимый вывод, Windows 10/11 целиком, ресурсы и восьмичасовой прогон. Пределы и возможные потери журнала сохраняются по ADR 0090.

Сводный аудит активных SN/CT/GE/EN/OS и ненумерованных P1/P2/P3 не завершён. Далее проверить остальные буквальные требования по текущим исходникам и результатам, отделяя функциональные пробелы от недостающей нативной приёмки. Рабочий эффект не запускался и не заменялся; read-only статус подтвердил manual/rendering=false. Вода, сайт и поставка отложены. Общая цель остаётся активной.

## Повторение

~~~text
cargo test -p snowflakes-client --lib --locked control::error_tests -- --nocapture
cargo test -p snowflakes-client --release --lib --locked control::error_tests -- --nocapture
~~~

Эти команды используют временные хранилища и не включают рабочий снег.
