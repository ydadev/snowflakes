# Подсказки принятого времени контакта

Дата: 14 ноября 2026 года. Windows 11 x64, Rust 1.99.1/MSVC. База — 4acd438; решение — [ADR 0064](adr/0064-accepted-contact-hints.md). Только P2/P3, рабочий эффект не включается.

## Изменение

[Предыдущая проба](TEST_RESULTS_LATER_EVENTS.md) показала возможность передавать принятые времена между рёбрами и ячейками. Теперь World передаёт их через contact_before; AngularEdge объединяет подсказку с локальным реальным попаданием и использует прежний доказанный отсев. Начальный best пустой. Общий и линейный fallback могут вернуть поздний реальный контакт; вызывающая сторона по-прежнему принимает только строгое улучшение.
