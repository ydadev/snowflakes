# Подсказки принятого времени контакта

Дата: 14 ноября 2026 года. Windows 11 x64, Rust 1.99.1/MSVC. База — 4acd438, код — 6232b8b; решение — [ADR 0064](adr/0064-accepted-contact-hints.md). Только P2/P3, рабочий эффект не включается.

## Изменение

[Предыдущая проба](TEST_RESULTS_LATER_EVENTS.md) показала возможность передавать принятые времена между рёбрами и ячейками. Теперь World передаёт их через contact_before; AngularEdge объединяет подсказку с локальным реальным попаданием и использует прежний доказанный отсев. Начальный best пустой. Общий и линейный fallback могут вернуть поздний реальный контакт; вызывающая сторона по-прежнему принимает только строгое улучшение.

## Фактические вызовы и повторная выборка позы

Текущий код перенесён в отдельную игнорируемую копию. Добавлены счётчики вызовов без дополнительных проверок гипотетического отсева и без коротких вложенных таймеров. Повторены 60/2 шага contact-global, seed 24301, fma; 60 измеряемых шагов отделены от подготовки/прогрева. Отпечаток ebec7a8291d12ead и ошибка массы 4.37e-8 сохранены. Времена этой копии не используются как результат A/B/B/A.

| Счётчик | За 60 шагов |
| --- | --- |
| Запросы полинома | 6793920 |
| Запросы с принятым временем | 6166380 |
| Фактически отсеяно | 5251020 |
| Оставшиеся refine | 1120080 |
| Трассировки с уже принятым временем тела | 771960 |

В предыдущем пути было 4677540 вызовов refine; после передачи времени их примерно на 76.1% меньше. Это фактический результат реализации, отдельно от предварительной пробы. Запросы полинома продолжают строиться; новый отсев выполняется внутри них.

| Выборка AngularMotion::sample | Вызовов |
| --- | --- |
| Всего | 12674760 |
| Начало, x=−1/2 | 7955400 |
| Конец, x=1/2 | 2691960 |
| Внутренняя точка, вызывающая sin_cos | 2027400 |
| Внутренние корни границы span | 540840 |
| Внутренние корни конца ребра | 562380 |

По исходникам для корня span сначала выбираются оба конца при том же x, затем при допустимом параметре — точка внутри ребра. Счётчики дают 945720 допустимых внутренних consider; равенство 2027400=2·540840+945720 выполнено. Одна временная поза на событие соответствовала бы 1103220 оценкам, то есть потенциально устранила бы 924180 повторных sin_cos в этой сцене. Это число возможных повторов, не доказательство будущей скорости или эквивалентности кеша.

Также вершина уже оценивает начальную f64-позицию для bounds, а запрос контакта снова выбирает начало ребра. Следующий эксперимент — проверить повторное использование полной начальной f64-позы и параметров одного времени. Нельзя подменять эти данные округлёнными before/after Point; нужны независимый некешированный эталон, проверки точек/скоростей и полного состояния, затем отдельное сравнение окончательных артефактов.
