Дата: 14 ноября 2026 года. Windows 11 x64, Rust 1.99.1/MSVC. База — 6d0a39c; решение — [ADR 0056](adr/0056-contact-workload-and-zero-hit.md). Входы синтетические, рабочий эффект не включается.

## Повторение

```powershell
cargo test -p snowflakes-client --example snow_model_bench --locked
cargo test -p snowflakes-client --lib --locked snow::prefilter
cargo run -p snowflakes-client --release --locked --example snow_model_bench -- --scenario contact-stress --steps 60 --warmup 2 --seed 24301
```

Пять прежних нативных сценариев остаются ignored; IPC/WTS выполнены в обычном Windows-контексте.

Опубликованный код — [6a6677b](https://github.com/ydadev/snowflakes/commit/6a6677b38f55070a4f9c2e1f3a17fee6a5214200). CI использует Windows Server 2022; приёмка настольных Windows 10/11 остаётся открытой.

Перед публикацией проверены 210 файлов и 566 местных ссылок, история, метаданные и удалённые blobs. Частные настройки и исполняемые файлы в Git не включены. Подготовлена отдельная сборка клиента, рабочий процесс не заменён; read-only статус подтвердил ручную паузу и rendering=false.

## Измерение

Две release-сборки содержат одинаковую новую нагрузку. База физики — прежний полный поиск, новый вариант завершает доказанный нулевой минимум. Запуски последовательны A/B/B/A, seed 24301. Baseline: 1200 шагов/120 прогрева; material-stress: 360/120; contact-stress: 60/2. Всего 12 запусков; другие проверки в это время не выполнялись. [Общая методика](MODEL_BENCHMARK.md) отделяет подготовку и наблюдение от шага.

| Сценарий | Прежний средний / p95, мс | Новый средний / p95, мс |
| --- | --- | --- |
| baseline | 0.05250 / 0.06320 | 0.05424 / 0.06535 |
| material-stress | 0.49121 / 0.54475 | 0.52613 / 0.59780 |
| contact-stress | 244.28413 / 330.85200 | 23.38991 / 23.73510 |

Показаны средние двух запусков каждого варианта, включая среднее двух p95. В контактном режиме средний шаг сократился примерно на 90.4%; два других входа немного выросли, общего ускорения всех сцен не заявляем.

Каждый из четырёх контактных запусков подтвердил 60 наблюдений, начало с 4800 тел и чистое уменьшение на 4800. Минимальный прирост массы принимающих крыш — 48363.36 условных единицы за эпизод, доля исходной массы — 0.9927274. Избыток учитывается отдельно в removed_mass; максимальная наблюдённая относительная ошибка — 4.22e-8. Суммы contact_activity относятся к независимым эпизодам.

Выборочные отпечатки совпали: baseline — 3646490212806ffa, material-stress — 2b40f0da0dca0af3, contact-stress — c1b226d3cfc02ba1. Совпадение не заменяет проверки всех полей и не доказывает любые геометрии.
