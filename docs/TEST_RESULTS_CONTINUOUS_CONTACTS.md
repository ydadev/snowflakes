# Непрерывный поток пластов в модели

Дата: 14 ноября 2026 года. Windows 11 x64, Rust 1.99.1/MSVC. База — 68bea07. Решение — [ADR 0066](adr/0066-continuous-model-contact-load.md). Только снег P2/P3; рабочий эффект не запускается.

## Сценарий

contact-stream сохраняет один World в прогреве и измерении. Перед каждым шагом — 16000 связных тел, по 2000 на каждом из восьми экранов. Освободившиеся места пополняются через World::release материалом с действующими масками восьми закрытых источников; нижняя точка новых тел находится на 1000 пикселей выше 64 принимающих крыш. Пределы и резервы клиента сохраняются. Снегопад выключен: это нагрузка внешним потоком связного материала, а не измерение интенсивности осадков.

Первый предварительный прогон завершился stream_admission_failed: стенд снимал маски исходных опор и тем самым переводил новые тела в обычный класс с меньшим доступным пулом. Исправлен стенд: он сохраняет и проверяет реальные действующие маски. Идентификаторы не подделываются, правила допуска модели не меняются. Прежние источники остаются представлены находящимся в полёте материалом; при потере маски прогон завершается ошибкой.

| Новая проверка | Подтверждение |
| --- | --- |
| stream_arguments_require_consecutive_work_and_the_full_fixture_is_balanced | Менее 360 шагов отклоняются; нет эпизодического сброса; полная сцена содержит 16000 пластов с равным распределением |
| consecutive_steps_keep_old_receivers_and_admit_new_material_on_every_screen | 360 последовательных шагов на уменьшенном стенде, старое накопление сохраняется, новый материал поступает на каждом экране; высота рождения контура проверяется непосредственно |
| outflow_without_receiving_snow_cannot_prove_a_contact_stream | Выключенные принимающие крыши дают удаление материала, но не положительную приёмку потока |
| a_finite_initial_burst_without_refills_cannot_pass_as_continuous | Начальные тела приземляются; без нового допуска поток не засчитывается |
| driver_rejects_changed_layout_and_never_discards_an_excess_body | Смена порядка экранов, лишнее тело и истёкшая после clear маска отклоняются; лишний снег не удаляется для подгонки |
| mass_corruption_and_short_or_missing_observations_are_rejected | Нарушение баланса обнаруживается на текущем шаге; недостаточные/отсутствующие наблюдения не принимаются |

Шесть сценариев Passed. Мутации отключённого пополнения, пропущенной проверки массы и принятия отсутствующего контакта получили Failed по утверждениям. Файлы восстановлены побайтно с проверкой SHA; набор повторно Passed. Полный tools/check.ps1 Passed: 424 теста клиента, включая 148 lib и 20 example, 3 protocol, 35 проверок ресурсов и 31 кадров. Прошли fmt/clippy/release, четыре smoke модели, Ajv 60, PHP 60+5, SQLite и HTTP. Пять нативных сценариев ignored; IPC/WTS выполнялись в обычном Windows-контексте. Smoke потока 360/0 подтвердил каждый экран и отпечаток 9d473fb25f990d81. CI нового коммита ещё не запускался.

## Предварительный поток

Отдельный release-прогон 600/120 шагов, seed 24301, fma: средний World::step — 15.494 мс, p95 — 21.336 мс, 233/600 шагов превысили DT. Перед каждым шагом было 16000 тел, минимум после шага — 15873. Все восемь экранов получили новый материал и положительную массу на крышах; максимальная относительная ошибка баланса — 1.04e-7. Отпечаток — 50318f2c0ac5f16c. Этот предварительный результат не подменяет окончательный длительный замер.

## Локализация перед новым сценарием

В отдельной игнорируемой копии исходников счётчики contact-global за 60/2 шага обнаружили 1731960 созданных рёбер и 1698480 запросов контакта, дошедших до построения полиномов. Из них 943140 — первые запросы ребра, 755340 — повторные. Всего построено 6793920 полиномов. Теоретически повторное использование двух уравнений концов могло устранить 1510680 построений, около 22.2%. Отпечаток ebec7a8291d12ead, fma и ошибка массы 4.37e-8 сохранились. Таймеров коротких вложенных участков в этой копии нет.

Изолированный прототип ленивого кеша уравнений проверен 16 последовательными A/B/B/A запусками четырёх сцен. Контактные средние базы/прототипа: 5.294/5.303 мс; общего пула: 20.635/20.816 мс. Преимущество не подтверждено, четыре отпечатка совпали. Прототип отклонён до отдельной численной приёмки; совпадение выборочных отпечатков не объявляется доказательством эквивалентности. Его код, EXE и журналы сохранены только локально. В основную ветку перенесён измеритель непрерывной нагрузки, кеш не добавлен.

## Окончательный поток

После полного набора отдельный неизменяемый release-артефакт выполнил 3600 измеряемых шагов после 120 прогрева, seed 24301, fma. Пересозданий мира не было; пополнение и наблюдение находились вне таймера World::step. Это 60 секунд модельного измеряемого времени, исполненных без ожидания кадров. Параллельные сборки и проверки не запускались; перед получением результата один раз проверено существование только собственного процесса.

Каждый экран получил существенное накопление: положительные приращения за отдельные шаги составили 28905–44395 единиц массы. Они могут повторно учитывать перераспределённый снег и не интерпретируются как уникальный объём осадков. Сохранились восемь масок источников. Выборочный пик spill — 119; ожидающих пакетов/тел в выборках не было. Бюджеты ожидающих пакетов/тел и баланс дополнительно проверялись каждый шаг. Выборочные снимки Observed берутся после шага и потому не обязаны содержать полный допуск 16000; его отдельно учитывает stream_activity перед каждым шагом.

SHA256 измерителя: E18F673AF2EA2CC3EE335958CEE491FFBEFE4BEB63122C7779B847FE37A03E06. Снимки ресурсов относятся только к консольному процессу модели, без GPU, окон и IPC. Более длинный поток показал существенно большую среднюю стоимость, чем предварительные 600 шагов. Это разные горизонты одной нагрузки, а не A/B ускорения. Требование производительности не выполнено; следующий шаг — локализация стоимости именно накопившегося непрерывного потока.
