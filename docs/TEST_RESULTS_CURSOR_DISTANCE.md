# Результаты проверки радиуса до маски курсора

Дата: 15 ноября 2026 года. Область: EN-09, P3-03/04. [ADR 0073](adr/0073-cursor-distance-before-mask.md), [методика](MODEL_BENCHMARK.md), [исходная сцена курсора](TEST_RESULTS_CURSOR_WORKLOAD.md).

## Диагностика до изменения продукта

Две игнорируемые копии добавили счётчики обращений к маскам и прямоугольникам. Для классификации счётчик сам вычисляет расстояние: его затраты не представляют стоимость производственного шага. Обе копии выполнили cursor-stream 360/120, seed 24301, fma; исходный и пробный порядок сохранили 09937a0df76aafb3. Это отдельная конфигурация, не отпечаток 360/0 или 3600/120.

| Фаза, 120 измеряемых шагов | Запросы маски: прежде / проба | Просмотры прямоугольника: прежде / проба |
| --- | --- | --- |
| Далеко | 1920000 / 0 | 107225145 / 0 |
| Рядом с видимым телом | 1920000 / 4272 | 107220514 / 273408 |
| Рядом с закрытым телом | 1920000 / 5138 | 55678838 / 163746 |
| Всего | 5760000 / 9410 | 270124497 / 437154 |

Все измеряемые тела имели действующие маски; hidden в этой сцене не использовался. В пробе осталось около 0.16% просмотров. Прежний путь мог завершить скрытый случай до hypot, а новый проверяет расстояние и для него; эта дополнительная работа не скрывается за числом пропущенных прямоугольников. Закрытые источники с hidden проверяются отдельно в эталоне, нативная стоимость этого случая ещё не принята.

Предварительный неинструментированный прототип менял порядок прямо в прежнем цикле. Четыре последовательных неизменяемых запуска A/B/B/A, cursor-stream 360/120, seed 24301, fma, дали среднее двух средних 5.66542→5.13599 мс и среднее двух p95 6.55895→6.00800 мс. Все четыре отпечатка совпали с диагностикой. Это примерно −9.3% среднего шага и основание для отдельной реализации/проверки, а не окончательная серия готового метода.

Счётчики и выбор эталона не добавляют полей World и исключаются из release-продукта.

Полное сравнение включает все поля Debug World, в том числе очереди, маски, RNG, контакты, состояния интерполяции и учёт. Диагностические счётчики не обнуляются внутри World для такого сравнения. Это шире выборочного отпечатка benchmark, но не подменяет нативную матрицу.

Все семь сценариев Passed в debug и release. Выполнено 387 полных сравнений World после шага, включая три нулевых пути. Четыре отдельные неверные мутации — увеличение радиуса, удаление проверки перекрытия, потеря ограничения скорости и лишний ранний просмотр маски — получили Failed по утверждениям выбранного численного/рабочего теста. Ошибки компиляции не засчитывались. Файл восстановлен побайтно в finally и проверен SHA, затем все семь сценариев повторно Passed.

Полный локальный набор: 455 тестов клиента, включая 174 lib и 25 example, плюс 3 protocol; пять нативных ignored. Семь проверок эталона отдельно повторяются в release; эта команда добавлена в tools/check.ps1 и Windows CI. fmt/clippy/release, ресурсы 35, кадры 31, шесть smoke, Ajv 60, PHP 60+5, SQLite и HTTP Passed. IPC/WTS выполняются в обычном Windows-контексте. Повторный общий сценарий проверяет также добавленный release-шаг; одинаковые проверки двух профилей не считаются разными тестами продукта.

[CI коммита 8b47a0c](https://github.com/ydadev/snowflakes/actions/runs/43651561733) завершился success. Декодированные журналы подтвердили 455 тестов клиента и 3 protocol, плюс повтор семи новых сценариев в release: 465 успешных исполнений, ноль ошибок, пять нативных ignored. Каждый из семи новых сценариев имеет два успешных исполнения. Ресурсы 35 и кадры 31 прошли в PowerShell 7 и Windows PowerShell; release, шесть smoke, Ajv 60, PHP 60+5, SQLite и HTTP Passed. Три непрерывных отчёта проверены на полный пул и получение массы каждого экрана; оба курсорных — на все фазы.

У короткого CI cursor-stream 360/0, fma, средний шаг enabled 7.763 мс, p95 8.467 мс; disabled 7.771 мс, p95 8.416 мс. Превышений DT нет, отпечатки 292dbae070646c4c и 9d473fb25f990d81 совпадают с локальным smoke; это другие параметры, чем у окончательной серии ниже. Максимальная ошибка массы менее 2.63e-8. Общий однокадровый пул в CI дал 22.683 мс и 60/60 превышений. Это отдельный стенд и короткие запуски, не A/B с другими CI или локальной парой. Перед публикацией аудит 260 файлов, 773 местных Markdown-ссылок, истории и noreply-метаданных Passed; опубликованные HEAD и все blob SHA сверены.

## Окончательное сравнение

Отдельная release-программа с внутренним методом сравнивается с исходной опубликованной сборкой, а не с предварительным встроенным вариантом. На каждую из семи конфигураций выполняется A/B/B/A, seed 24301: baseline 1200/120, material-stress 360/120, contact-stress и contact-global 60/2, contact-stream и оба входа cursor-stream 3600/120. Сборки, проверки и другие эксперименты во время этой серии не запускаются. Пополнение/выбор целей, как прежде, вне step и внутри wall/CPU.

Все 28 отчётов проверены отдельно на порядок, параметры, fma, прежние отпечатки, пределы, баланс и нагрузку каждого экрана. Таблица — среднее двух средних и среднее двух p95, мс; превышения суммируются по двум повторам каждой сборки.

| baseline | 0.05229 / 0.06320 | 0.05064 / 0.06370 | 0 / 0 из 2400 |
| material-stress | 0.52319 / 0.59970 | 0.53105 / 0.60570 | 0 / 0 из 720 |

У enabled средний шаг сократился примерно на 13.4%, p95 — на 14.5%; число превышений уменьшилось с 182 до 61 из 7200. Отдельные средние исходной сборки 10.37670/10.60792 мс, новой — 8.99269/9.17734 мс. У disabled среднее почти прежнее, p95 и превышения выросли; material-stress замедлился примерно на 1.5%. Все первые пять сцен передают None: их изменения не следует приписывать сокращению просмотров курсора. Общий контактный шаг всё ещё имеет превышения, а эти времена не являются FPS приложения.

У каждой непрерывной конфигурации 3600 наблюдений каждого повтора, полный допуск 16000 и по 2000 на экран перед шагом, минимум после шага 15873. Все экраны получали массу и пополнялись. В enabled допущено по 298161 новых тел, в двух других потоках — по 298174; значения до/после совпали. Ошибка массы не выше 1.04e-7; обе курсорные сцены имеют по 150 наблюдений каждой фазы каждого экрана. Семь сохранённых отпечатков конфигураций: 3646490212806ffa, 2b40f0da0dca0af3, c1b226d3cfc02ba1, ebec7a8291d12ead, db1e1ce4b296f5bf, 1914defa9185ddc1, db1e1ce4b296f5bf.

Клиент подготовлен в отдельном файле, SHA256 1CB3D0F8F059046107E5C334898845D3C26DED27D08654ED110EC01FC1307D3B; рабочий процесс не заменялся. Диагностика, EXE и сырые отчёты остаются в игнорируемом каталоге.

## Остаток

Результат не является приёмкой EN-09/P2/P3. Сохраняются форма/формулы силы и прежнее смахивание; экономия происходит при выборе тел, которым нужен просмотр перекрытий. Нативная стоимость полностью скрытого потока, видимые кадры/ввод, Windows 10/11, полный CPU/GPU/память и восемь часов Not run. Рабочий процесс не заменялся и не возобновлялся; read-only status подтвердил manual/rendering=false. Вода, сайт и поставка отложены.
