# Проверки перехода подвижного снега между DPI

Дата: 14 ноября 2026 года. Windows 11, Rust 1.99.1/MSVC x64. P3-01/03/04, частичное покрытие GE-09/OS-04. Активны снег и его основа.

Подвижное тело сохраняет текущий масштаб координат. Переход выполняется на фиксированных физических шагах с ограничением 4% за шаг; пиксельная скорость пересчитывается до приложения сил. Рендерер и геометрия используют один масштаб тела. [ADR 0034](adr/0034-moving-snow-dpi-transition.md).

## Регрессии и дополнительные проверки

| Проверка | До исправления | После |
| --- | --- | --- |
| dpi_transition_keeps_flake_size_and_physical_velocity_continuous | Failed: масштаб 1 → 2,5 за пересечение границы | Passed: переход в обе стороны между 100/250%, ограниченное изменение размера, без добавленной горизонтальной скорости в заданном потоке, прежние радиус и масса |
| dpi_transition_keeps_a_slab_cohesive_until_one_landing | Failed: граница меняла ширину с 52 до 124 пикселей | Passed: учитывается вращение, пласт остаётся одним телом и один раз передаёт все 240 единиц массы нижней опоре целевого экрана |
| dpi_transition_waits_for_an_unpaused_step | Failed: масштаб становился 2,5 во время паузы | Passed: 180 возможностей шага не меняют масштаб, положение, скорость, возраст и массу; после снятия паузы переход возобновляется постепенно |
| dpi_transition_is_identical_at_thirty_and_sixty_fps | Passed, но не обнаруживал резкий переход | Passed: масштаб, координаты, скорости, угол, возраст и масса совпадают после одинакового времени StepClock |
| pending_compaction_keeps_saved_physical_units_after_a_dpi_change | Добавлен после ввода состояния масштаба | Passed: старые масштабы 200/100% при текущем 100% дают размах 263 пикселя, скорость 45/18 DIP/с, прежние центр и массу |

Два синтетических экрана примыкают по вертикальной границе x=800. Обычная снежинка радиусом 3 DIP начинает движение в 0,5 пикселя от границы. Для проверки скорости задано горизонтальное движение без постоянного ведущего ветра; стохастический поток воспроизводим. Проверка пласта использует профиль из восьми ячеек по 6 DIP и высотой 5 DIP. Баланс массы учитывает только существующий материал; новых осадков и таяния нет.

Полный tools/check.ps1 Passed: 232 теста клиента, включая 107 в snow и 37 модульных, 3 теста протокола, 33 проверки ресурсов, 31 проверка кадров, fmt/clippy/release, JSON Schema и PHP/SQLite/HTTP. Один аппаратный тест кадров исключён из обычного прогона. Сценарии отсутствующих экранов, очередей и длительного конечного притока остаются в наборе.

~~~text
cargo test -p snowflakes-client --test snow dpi_transition --locked
cargo test -p snowflakes-client --lib pending_compaction_keeps_saved_physical_units_after_a_dpi_change --locked
~~~
