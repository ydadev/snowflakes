# Проверки рёбер снежного пласта

Дата: 14 ноября 2026 года. Windows 11 x64, Rust 1.99.1/MSVC. P3-02/04. [Решение](adr/0043-swept-contour-edges.md).

Эти результаты описывают линейный этап. Последующее [вращение контура между позами](TEST_RESULTS_ANGULAR_CONTACT.md) добавляет отдельные регрессии и замер стоимости.

## Воспроизведение

Пласт шириной 80 DIP и высотой 4 DIP, нижний край y=298, падает на крышу y=300. Крыша открыта только при x=[110,75;111,75). Нижнее ребро занимает этот зазор, но вершины проходят под перекрытиями. edge_contact_lands_when_only_the_interior_overlaps_a_visible_ledge сначала Failed на опубликованном контакте вершин: после шага пласт продолжал падать. После проверки рёбер Passed: есть накопление, тело приземлилось, баланс введённой, оставшейся и удалённой массы сохранён.

Во время реализации отдельно воспроизведён пропуск ячейки 3 при дробной ширине 88/15 пикселя: её вычисленный левый край возвращал индекс 2. Новый тест сначала Failed на промежуточной реализации рёбер; после обратного поиска границ все 15 вариантов высокой ячейки проходят. Это не регрессия, заявленная для прежнего опубликованного алгоритма.

| edge_contact_lands_when_only_the_interior_overlaps_a_visible_ledge | Полный World::step, удар серединой нижнего ребра через узкий открытый зазор, накопление и масса |

| edge_contact_finds_a_narrow_active_monitor_between_paused_ones | Активная полоса шириной 0,002 пикселя сохраняется между приостановленными экранами; полная пауза запрещает удар |
| edge_contact_finds_interior_and_reversed_slopes_across_dpi | Наклонное ребро, оба порядка концов, отрицательное начало и 100/250% DPI, время 0,45 |
| edge_contact_finds_the_first_of_two_corner_roots | Для двух корней 12t² − 14,2t + 3,8 = 0 выбирается ранний; оба порядка концов |
| edge_contact_rejects_upward_material_while_the_other_end_descends | Разные направления концов не запрещают удар всей фигуры; вверх движущаяся часть не принимает контакт |
| edge_contact_preserves_initial_overlap_and_degenerate_points | Начальное перекрытие t=0, проход ниже основания, движение вверх/горизонтально, точка и вертикальное ребро |
| edge_contact_agrees_with_independent_material_point_samples | 512 детерминированных рёбер и 257 фиксированных точек на каждом: аналитический удар не позже найденного выборочного; проверяются диапазон времени/x и пересечение плоскости |
| active_spans_follow_nearest_ownership_above_an_edge | Смена ближайшего экрана в верхнем отступе, включая точную границу и соседний float |
| active_spans_preserve_narrow_monitors_and_overlap_order | Узкая активная полоса и порядок владения перекрывающимися прямоугольниками |

Локальный повтор: cargo test -p snowflakes-client --lib edge_contact_; отдельно cargo test -p snowflakes-client --lib active_spans_. Выборочные точки используются только в проверке; расчёт рёбер продукта не имеет заданного шага выборки.

## Стоимость контакта рёбер

По [методике модели](MODEL_BENCHMARK.md): release, 28 доступных логических процессоров. A — опубликованный e5ae818 с траекториями вершин; B — полные рёбра с уточнёнными границами. Для каждого сценария последовательно A/B/B/A, seed 24301, 120 шагов прогрева и 3600 измеряемых шагов, без параллельной компиляции.

Среднее равных по длине пар: baseline 59,102 → 59,722 мкс (+1,05%); material 5,869 → 6,491 мс (+10,59%). Близкие baseline не доказывают отсутствие накладных расходов. В material шагов дольше DT 17/7200 → 25/7200. Это наблюдения одного стенда; p95 указан для отдельных запусков, объединённый p95 не вычислялся. Затраты предыдущих сравнений не складываются в общий процент.

В baseline отпечаток A 6f87250832da2c41, B bc0e107e3354777b; повтор каждого варианта стабилен. Контакты пластов изменяют состояния, поэтому сравнение не заявляет одинаковую последовательность физики. Оба варианта наблюдали 309–383 активных тела; максимальная относительная ошибка массы менее 0,000934%.

В material все четыре отпечатка f47f72fe4822f335 совпали; 4800 активных, 812 ожидающих частей в 128 пакетах, 40814/12279 ячеек профилей. Во время шагов нет открытых окон; этот сценарий измеряет насыщенный путь, а не исправленный узкий контакт. Выборочный отпечаток не доказывает равенство всего World.

Максимальный пик private bytes модели: baseline A 1,266 МиБ/B 1,285 МиБ, material A 4,754 МиБ/B 4,758 МиБ. Подготовка нагрузочной сцены измеряется отдельно, около 49–52 мс. Короткая модель не подтверждает память всего клиента, реальный FPS или длительную устойчивость. [Предыдущее исправление точки удара](TEST_RESULTS_SWEPT_CONTACT.md) имеет отдельную исходную пару и отчёт.

Not run: видимый снег, настоящий ввод, реальные DPI/мониторы, Windows 10, GPU/DWM и восемь часов. Линейная интерполяция концов не является точной дугой вращения. Рабочий эффект и CUA не запускались; дождь, лужи, сайт и поставка Deferred. P2/P3 и проект остаются In progress.
