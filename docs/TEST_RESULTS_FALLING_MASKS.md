# Проверки перекрытия падающего снега

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P3-03/04, SN-06, GE-02 и AC-04. Разработка остаётся сосредоточена на снеге; P4 отложен.

Полный tools/check.ps1 Passed: 176 тестов клиента, 3 теста протокола, fmt, clippy с -D warnings, release, JSON Schema, PHP syntax, контракт, SQLite и HTTP. Добавлены десять сценариев snow; всего 73 сценария снега/геометрии.

| Сценарий | Результат |
| --- | --- |
| Полностью перекрытый сугроб | Passed: после закрытия масса сохраняется в связных пластах; они невидимы за окном, появляются после выхода из-за него и пополняют нижний сугроб |
| Узкое перекрытие и вращение | Passed: маска исключает полосу шириной 0,5 пикселя; площади свободных прямоугольников совпадают с ожидаемой разностью и не перекрываются; границы учитывают повёрнутый контур и обводку при 100/200/400% |
| Изменение перекрытия | Passed: текущие перемещение, скрытие и закрытие окна меняют маску; окно сзади не перекрывает материал; новый ID не наследует старый, новая системная панель маскируется |
| Курсор и крыша переднего окна | Passed: скрытые тела движутся одинаково с курсором и без него; пересечение крыши переднего окна не помещает на неё снег из заднего слоя |
| Пауза и очередь | Passed: очередь сохраняет массу без движения; после смены перекрытия и возобновления тела используют новую геометрию |
| FPS и DPI | Passed: при 30/60 FPS совпадают положения, скорости, углы, маски и масса после периодических снимков сцены; проверены синтетические масштабы 100/200/400% |
| Освобождение записей | Passed: после приземления и Clear бывшая опора не оставляет действующую маску |
| Невидимый источник | Passed: закрытие невидимой опоры сохраняет массу при паузе; после возобновления тела остаются скрытыми и переходят в учтённый сток, не создавая горок на активном рабочем столе |
| Сложная маска | Passed: перекрытие 128 прямоугольниками превышает бюджет свободных полос; падающий материал скрывается, его масса сохраняется |
| Насыщенная очередь | Passed: 128 обычных фрагментов не смешивают разные исходные опоры и не теряют слой; непредставимый остаток учтён как сток, баланс сохраняется |

Графический путь D3D11/Direct2D подключён к тем же прямоугольникам. Результаты выше доказывают геометрию и модель; они не являются проверкой пикселей GPU, внешнего вида или фактической задержки. Путь обычного снегопада и принятое локальное смахивание сохраняются; прежние сценарии прошли.

Not run: видимая оценка закрытия/сворачивания и выхода из-за края, настоящие виртуальные рабочие столы и системные панели, смешанный DPI, Windows 10, нагрузка CPU/GPU и длительный прогон. Рабочий эффект для этапа не запускался. Полная видимая масса при экстремальном насыщении остаётся открытой задачей бюджета.
