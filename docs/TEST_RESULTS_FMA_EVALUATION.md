# Аппаратное вычисление контактов снега

Дата: 14 ноября 2026 года. Windows 11 x64, Rust 1.99.1/MSVC. База — 0a9d81b; решение — [ADR 0058](adr/0058-runtime-fused-contact-evaluation.md). Рабочий эффект не включается.

## Локализация и машинный код

В отдельной игнорируемой копии поставлены вложенные таймеры World::step, внешнего roots и уточнения интервала. Счётчики сбрасываются перед каждым измеряемым шагом; подготовка/наблюдение исключены. Contact-stress: 60/2 шага, seed 24301. Средние: весь шаг 22.314 мс, roots 17.275 мс, уточнение 15.419 мс. На 1 722 480 внешних запросов пришлось 1 605 720 уточнений и 89 550 000 итераций. Это инструментированная локализация с накладными расходами; вложенные времена не складывать.

Самостоятельная release-проба того же evaluate.rs подтвердила FMA на стенде и правильный результат вызова. Её assembly содержит девять scalar-double FMA-инструкций внутри accelerated_refine и ноль вызовов библиотечного fma в этом участке. Это подтверждение ограничено компиляцией пробы; итоговое ускорение проверено отдельным обычным измерителем ниже. Числовые/CPU предпосылки приведены в ADR.

## Проверки

```powershell
cargo test -p snowflakes-client --lib --locked snow::contact
cargo run -p snowflakes-client --release --locked --example snow_model_bench -- --scenario contact-stress --steps 60 --warmup 2 --seed 24301
```

Все 25 проверок контактов Passed, включая прежние 8640 сравнений битов корней с полным поиском и 720 сравнений всех полей World. Мутация fused операции на отдельные умножение/сложение получила Failed; игнорирование запрета ускорения также получило Failed. Обе восстановлены в finally с совпадением SHA, контактный набор повторно Passed.

Полный tools/check.ps1 Passed: 392 теста клиента (126 lib и прежние интеграционные/10 example), 3 protocol, 35 проверок ресурсов, 31 кадров. Прошли fmt/clippy, release, оба smoke модели, Ajv/PHP/SQLite/HTTP. Пять прежних нативных сценариев ignored; IPC/WTS выполнены в обычном Windows-контексте.

Опубликованный код — [9099564](https://github.com/ydadev/snowflakes/commit/9099564e41ffe5f15b7d1d7dbf643166f924244d). [CI 43592410764](https://github.com/ydadev/snowflakes/actions/runs/43592410764) завершился success: Windows — 4 мин 11 с, контракт/PHP — 22 с. Логи подтвердили 392 + 3 теста, все шесть новых сценариев и оба smoke. Контактный smoke подтвердил 60 свежих эпизодов и ту же долю полученной массы 0.9927274.

На CI средний контактный шаг составил 20.588 мс, все 60 шагов превысили DT. Условия CI отличаются от локального A/B/C; фактически выбранный backend в прежнем JSON не фиксируется, причину разницы не выводим из времени. Этот результат сохраняет открытую приёмку производительности. Перед сравнением разных стендов нужно добавить наблюдение выбранного вычислителя.

Перед публикацией проверены 216 файлов, 591 местная ссылка, история, метаданные и удалённые blobs. Копии измерения, логи и EXE в Git не включены. Отдельная сборка не заменяла рабочий процесс; read-only статус подтвердил manual/rendering=false.

## A/B/C/C/B/A

Три замороженных release EXE: A — прежний 0a9d81b, B — runtime, C — отдельная копия с принудительным portable. Все используют одинаковую нагрузку/seed; только C отключает выбор аппаратной функции. Сценарии запускаются последовательно A/B/C/C/B/A, всего 18 запусков, без параллельных компиляций и проверок. Baseline — 1200/120 шагов, material-stress — 360/120, contact-stress — 60/2. [Общая методика](MODEL_BENCHMARK.md).

| Сценарий | Прежний средний / p95, мс | Runtime средний / p95, мс | Portable средний / p95, мс |
| --- | --- | --- | --- |
| baseline | 0.05439 / 0.06710 | 0.05332 / 0.06580 | 0.05336 / 0.06315 |
| material-stress | 0.53181 / 0.60040 | 0.55501 / 0.72915 | 0.51552 / 0.58005 |
| contact-stress | 20.77625 / 21.30190 | 15.29676 / 15.95485 | 20.00308 / 20.72635 |

Показаны средние двух запусков и среднее двух p95. Контактный runtime сократился примерно на 26.4%; material-stress немного вырос. Универсального ускорения не заявляем. Все 120 runtime-контактных шагов не превысили DT≈16.7 мс; все 120 portable и 120 прежних превысили его. C выполнялся на том же FMA-процессоре, отдельный процессор без FMA не проверялся.

Отпечатки всех вариантов совпали: baseline — 3646490212806ffa, material-stress — 2b40f0da0dca0af3, contact-stress — c1b226d3cfc02ba1. Все контактные запуски подтвердили по 60 свежих эпизодов с 4800 тел, чистое уменьшение на 4800 и долю массы на крышах 0.9927274; максимальная относительная ошибка 4.22e-8.
