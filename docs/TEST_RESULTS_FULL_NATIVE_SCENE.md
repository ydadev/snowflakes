# Полный Native и сцена снега

Дата: 15 ноября 2026 года. Клиент 0.1.0, Rust 1.99.1/MSVC, Windows x64. Область: P2-02, OS-02/03 и часть SN-06. Продолжает [WinEvent](TEST_RESULTS_NATIVE_WINEVENTS.md) и [связь событий со снегом](TEST_RESULTS_NATIVE_SNOW.md).

## Отличие стенда

Добавлены два библиотечных сценария с производственным Tracker::poll. Они выполняют настоящее объединение событий, Native::order, проверку PID/Thread ID, Native::read, DWM-запросы и Native::screens. Подставной Source и подмена видимости/collect не используются. Число, размеры, рабочая область и ключи дисплеев приходят от Native, без синтетической замены. Сцены передаются настоящему World.

Дочерний процесс создаёт обычные окна с заголовком и WS_VISIBLE на отдельном desktop. Это признак видимости окна для Windows API; desktop не становится входным и не выводится пользователю. Каждое создание или перемещение разрешается только после успешной проверки имени собственного desktop и UOI_IO=false. В правах desktop отсутствует DESKTOP_SWITCHDESKTOP, SwitchDesktop и активация не вызываются, окна имеют WS_EX_NOACTIVATE. Проверка UOI_IO повторяется в конце сценариев. Чужие окна, заголовки и изображения не считываются и не изменяются.

Служебный дочерний процесс, его окна, handles и hooks очищаются штатно; родитель проверяет нормальный код завершения. Новые сценарии используют три дочерних запуска, полный набор вместе с прежними проверками — девять. Рабочий эффект не запускается.

## Проверяемые результаты

| Область | Подтверждение |
| --- | --- |
| Настоящий Native::read | Два captioned-окна другого процесса допущены как видимые опоры; PID/поток совпадают с нативным порядком, maximized/taskbar=false |
| Геометрия DWM | Прямоугольник совпадает с DWMWA_EXTENDED_FRAME_BOUNDS, при ошибке рамки — с GetWindowRect; DWMWA_CLOAKED успешно прочитан и равен 0 |
| Фильтры | Видимое окно собственного процесса, скрытые окна ребёнка и уничтоженное окно исключаются |
| Реальное движение | После SetWindowPos первый прямоугольник смещается на 80/40, его ключ сохраняется, геометрия и ключ второго окна стабильны |
| Закрытие | Настоящий DestroyWindow удаляет прежний ключ из сцены; вторая опора сохраняется |
| Native → World | Профили высотой 5 при исходном масштабе Native загружаются на две настоящие опоры; закрытие первой выпускает связные пласты, затем их масса оседает на пол соответствующего нативного дисплея |
| Пауза | Закрытие проверяется как при активном дисплее, так и после ручного World::set_paused_monitors; 120 шагов сохраняют очередь без выпуска тел, после возобновления первый шаг выпускает пласты |
| Масса и горка | Баланс проверяется на каждой принятой сцене/шаге, масса пола совпадает с закрытым слоем с относительным допуском 1e-5, второе окно сохраняет массу. Высота горки больше 1, заняты хотя бы три ячейки и меньше половины ширины дисплея; учтённый численный остаток меньше 1e-6 исходной массы |

Время Tracker ограничено 0–90 мс: периодическая сверка не подменяет доставку событий. Модель идёт фиксированными шагами; до 1800 шагов на естественное приземление без изменения поз/скоростей тестом. Это не измерение задержки и FPS. Начальный снег задан тестом, новые осадки, ветер и таяние отключены.

Целевой прогон Passed: оба сценария, включая два варианта закрытия. Локальная предварительная проба подтвердила доступность DWM-метаданных на невходном desktop; диагностическая проба заменена проверками утверждений. Продуктовый код и фильтры не менялись.

Сборщики: 35/31; JSON Schema: 60; PHP: 60 общих + 5 транспортных, SQLite и HTTP Passed. Это регрессионная проверка существующих компонентов, разработка воды/сайта не возобновлялась.

## Повторение и ограничения

~~~powershell
cargo test -p snowflakes-client --locked --lib platform::scene::tests::events::native_source:: -- --nocapture
.\tools\check.ps1
~~~

Not run: ненулевой cloak/uncloak, show/hide и минимизация в полном Native, разные классы настоящих приложений, потеря DWM/уничтожение между отдельными запросами, производственный графический поток, DPI-коррекция Layer, GPU-вывод и ввод на входном desktop, Shell/fullscreen/hotplug, несколько физических мониторов, ресурсы всего клиента, длительный прогон и полная матрица Windows 10/11. Native::screens задаёт исходный scale=1; последующий GetDpiForWindow графического слоя здесь не проверяется. Ручная пауза World в тесте не является приёмкой автоматического fullscreen. P2/P3 остаются In progress; вода, сайт и поставка отложены.

Основания изоляции: [desktop и входная поверхность](https://learn.microsoft.com/en-us/windows/win32/winstation/desktops), [UOI_IO](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getuserobjectinformationw), [право SwitchDesktop](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-switchdesktop).
