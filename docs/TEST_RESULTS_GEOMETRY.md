# Проверки идентификаторов и масок накопления

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P2-02/P3-04, части GE-02/03/07/08. P2 и P3 остаются In progress.

## Автоматические проверки

Полный tools/check.ps1 прошёл: 113 тестов клиента, 3 теста протокола, fmt, clippy с -D warnings, release, 60 общих случаев JSON Schema, PHP syntax, контракт PHP, SQLite и HTTP.

| Проверка | Результат |
| --- | --- |
| Display-ID | Passed: регистр, повторения и порядок путей, номер GDI, разные устройства, явный fallback и закреплённый результат хеша |
| Перекрытие выше опоры | Passed: верх сугроба скрыт, основание доступно; окно позади не закрывает передний сугроб |
| Свободная область рядом с перекрытием | Failed в первой реализации маски: ложный предел 2 вместо 140 физических пикселей; после разбиения на вертикальные полосы Passed |
| Нижняя опора | Passed: объединение перекрытий, отрицательные координаты, скрытое окно и обычное приложение; выборочная проверка точек не обнаружила пропусков и двойного рисования |
| Бюджет маски | Passed: сетка из 100 синтетических перекрытий скрывает опору при превышении 2048 прямоугольников |
| Сохранение снега | Passed: перекрытый снег не смахивается курсором и не принимает новые частицы; после раскрытия сохраняет массу и снова реагирует на движение |
| Нижний сугроб под меню | Passed: скрытый участок не принимает снег и не реагирует на курсор |
| Рост под перекрытием | Passed: осадки заполняют свободный зазор, не увеличивая слой выше его потолка; баланс массы сохраняется |
| CLI без экземпляра | Passed: два перечисления дают одинаковые уникальные ID и допустимую геометрию; статус до и после остаётся ABSENT |
| CLI при ручной паузе | Passed: обнаружение не меняет PID и причины паузы изолированного headless-процесса |

Всего: два новых unit-теста идентификаторов, шесть сценариев снега и один сценарий CLI. Существующий тест жизненного цикла процесса расширен проверкой паузы. Тест снега с зазором первоначально имел неверную исходную позицию частицы уже ниже поверхности контакта; входные данные исправлены, это не засчитывается как дефект продукта.

## Проверка release

Passed: команда --list-monitors --json дважды обнаружила два монитора, оба с persistent=true и различными ID; результаты совпали. Проверка статуса существующего экземпляра подтвердила ручную паузу и rendering=false. Новый графический процесс не запускался, действующий экземпляр не заменялся. Реальные ID и конфигурация стенда не публикуются.

## Непроведённая приёмка

Not run: физическое переподключение дисплеев, смена порта/док-станции/драйвера, реальные смешанный DPI и поворот, RDP и повторное создание HMONITOR. Два одинаковых перечисления не доказывают эти сценарии.

Not run: визуальный результат Direct2D-масок, настоящие меню «Пуск»/уведомления на Windows 10/11, автоскрытие панели задач и нагрузка сложных перекрытий. Геометрические тесты подтверждают входные прямоугольники, а не полноту распознавания системных окон. Настройки выбора мониторов в GUI ещё не реализованы.
