# Проверки движения нижней опоры

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P2-02/P3-04, GE-05/06/07. Этапы P2/P3 остаются In progress.

Полный tools/check.ps1 прошёл: 125 тестов клиента, 3 теста протокола, fmt, clippy с -D warnings, release, JSON Schema, PHP syntax, контракт, SQLite и HTTP. Добавлены семь сценариев: пять в snow и два в scene_registry.

| Проверка | Результат |
| --- | --- |
| Переход опоры | Failed на прежнем коде: событие сразу меняло высоту 600 → 560; после исправления Passed — монотонное движение в обе стороны с ограниченным шагом |
| Сохранение снега | Passed: при отключённых осадках и таянии перенос не меняет плоский профиль и массу, не создаёт частицы |
| Маска панели | Failed на прежнем коде: панель отсутствовала в сцене; после исправления Passed — она закрывает накопление, но сама его не принимает |
| Рабочая область | Passed: событие известной панели обновляет снимок мониторов; скрытие и уничтожение не оставляют прежний резерв рабочей области |
| Несколько мониторов | Passed: нижняя панель меняет цель своего монитора, другой сохраняет собственную рабочую область; верхняя и боковая панели не задают нижнюю опору |
| Пауза | Passed: одна опора остаётся неподвижной, другая достигает цели; первый шаг после возобновления ограничен обычной скоростью |
| Маски и столкновения | Passed: текущие прямоугольники не проходят через панель; после перемещения вниз через границу пространственного индекса снег сталкивается с новой опорой |
| Новая геометрия экрана | Passed: изменённый прямоугольник дисплея сразу задаёт опору в новых координатах |
| FPS и DPI | Passed: промежуточное положение при 30/60 FPS совпадает, при синтетических 100/200% совпадает перемещение в DIP |

Первый полный прогон остановился на замечании clippy о вложенном if после изменения ветвления; структура исправлена, повторный полный прогон Passed. В двух новых тестах первоначально использовался предел шага для 120 Гц, тогда как существующая симуляция работает на 60 Гц; исправлены ожидания тестов, частота симуляции не менялась.

Not run: видимый переход на настоящей панели задач, переключение её автоскрытия, сторонние appbar-панели, перезапуск Explorer, смешанный DPI и Windows 10. Синтетическая рабочая область не подтверждает поведение всех оболочек. Измерения CPU/GPU при движении опоры не проводились.

Новая release-сборка подготовлена без запуска графического процесса; рабочая конфигурация и системная панель задач не менялись. Ручная пауза действующего экземпляра сохраняется.
