# Проверка времени и интерполяции снега

Дата: 14 ноября 2026 года. Область: P2/P3, EN-01/02. Решение: [ADR 0047](adr/0047-fixed-step-render-interpolation.md).

## Исправление

Предел шагов снижен с восьми до пяти согласно EN-01. Полные избыточные шаги отбрасываются без будущего долга. Рендерер снега использует остаток времени для выбора позы между двумя физическими состояниями. Падающие пласты используют тот же путь. Масса, столкновения, топология и маски не заменяются визуальной симуляцией.
