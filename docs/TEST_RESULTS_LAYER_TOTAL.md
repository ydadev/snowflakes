# Точная сумма слоёв снега

Дата: 14 ноября 2026 года. Windows 11 x64, Rust 1.99.1/MSVC. База — 6303e76. Решение — [ADR 0067](adr/0067-rounded-layer-total.md). Только снег P2/P3; рабочий эффект не включается.

## Локализация длительного потока

Из текущих исходников создана отдельная игнорируемая копия. В World::step добавлены пять крупных неперекрывающихся таймеров: подготовка; тела/контакты/приземление; учёт и оседание; курсор/кромки; очистка масок. Короткие вложенные участки не измерялись. Выполнены 3600/120 шагов contact-stream, seed 24301. Отпечаток db1e1ce4b296f5bf, fma, допуск 16000 перед каждым шагом и ошибка массы 1.04e-7 сохранились. Сумма этапов практически совпала с общим временем шага этой копии.

Рост числа запросов не объяснил удвоение времени. Проверка состояния обнаружила субнормальные pending: после последовательных интервалов по 600 шагов — 0, 1759, 3286, 3750, 4041, 4147 ячеек. Во всех этих ячейках mass оставалась достаточно большой, чтобы прежнее f32-сложение округлялось к ней. Субнормальных mass, flux и scratch в этих снимках не было.

Первый условный прототип сохранил отпечаток, но не ускорился. Его ассемблер содержал addss до проверок обходной ветки, после чего выбирался результат. Второй прототип использовал доказанный разрыв экспонент и отдельный обычный fallback; среднее диагностического потока стало 17.513 мс, p95 22.158 мс, 2416/3600 превышений DT. Времена последней части тел оставались около 15.6–15.9 мс вместо 27–28 мс. Остатки и отпечаток сохранились. Эти прототипы не подставляются в окончательное сравнение. Аппаратные события FP assist не измерялись; объяснение связано с наблюдённым вычислительным путём, а не с прямым замером таких событий.

## Окончательное A/B/B/A

После полного набора неизменяемые release-артефакты выполнили 20 последовательных запусков без параллельных компиляций и проверок. Каждая сцена использовала порядок A/B/B/A, seed 24301, fma. Baseline — 1200/120 шагов, material-stress — 360/120, две однокадровые контактные сцены — 60/2, непрерывный contact-stream — 3600/120. В таблице среднее двух средних и среднее двух p95. Диагностические прототипы в неё не включены. [Методика](MODEL_BENCHMARK.md).

| Сценарий | Прежний средний / p95, мс | Новый средний / p95, мс |
| --- | --- | --- |
| baseline | 0.05389 / 0.06435 | 0.05327 / 0.06425 |
| material-stress | 0.53487 / 0.67485 | 0.53687 / 0.61880 |
| contact-stress | 5.12845 / 5.59925 | 5.22487 / 5.41135 |
| contact-global | 19.96671 / 20.72815 | 20.55186 / 21.29530 |
| contact-stream | 26.61863 / 37.57940 | 18.19697 / 23.48070 |

Длительный поток в этой паре ускорился примерно на 31.6% по среднему и 37.5% по p95. Отдельные средние базы — 26.409/26.829 мс, новые — 18.103/18.291 мс. Свежие контактные средние выросли примерно на 1.9% и 2.9%; одинакового выигрыша во всех сценах нет. Такой обмен принимается для устранения большей стоимости зрелого потока, при сохранении открытого EN-09 и необходимости дальнейшего измерения. Превышений DT в потоке было 5940/7200 и стало 5758/7200; обе глобальные однокадровые сборки дали 120/120, двухэкранные — 0/120. Требование производительности не выполнено.

Сохранены все пять отпечатков: 3646490212806ffa, 2b40f0da0dca0af3, c1b226d3cfc02ba1, ebec7a8291d12ead, db1e1ce4b296f5bf. В каждом потоке — 3600 наблюдений, 16000 тел перед каждым шагом, минимум 2000 на каждый экран и подтверждённое новое поступление/получение массы. Повторно допущено 298174 тела, минимум после шага 15873, максимальная относительная ошибка массы 1.04e-7. Времена и ресурсы относятся к консольной модели.

SHA256 базы: E18F673AF2EA2CC3EE335958CEE491FFBEFE4BEB63122C7779B847FE37A03E06. Нового измерителя: A06CE418A108947458204F7EFF2D868D139B62C0181F227F805DD2613006170A. Код измерения и исходные результаты хранятся отдельно от рабочих настроек; бинарные файлы и журналы в Git не включаются.
