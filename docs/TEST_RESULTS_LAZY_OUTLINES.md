# Обход контура по мере необходимости

Дата: 15 ноября 2026 года. Windows 11 x64, Rust 1.99.1/MSVC. База дерева — 5e9de9b, прежний производственный код — c3730f8. [ADR 0071](adr/0071-lazy-contact-outlines.md). Только снег P2/P3; рабочий эффект не запускается.

## Повторная локализация

После [временной проекции](TEST_RESULTS_TIME_PROJECTION.md) отдельная копия текущих исходников измерила пять крупных участков шага. Внутри выбраны каждый 128-й вызов построения движения, контура и поиска ребра; начало выборки сдвигается между шагами. Метки коротких участков не добавляются каждому вызову. Общий пул: 120/2 шага, поток: 3600/120, seed 24301, fma.

Короткие интервалы включают часы и запись отметок. Их нельзя без поправки умножать на весь пул или использовать как A/B. Крупный участок тел/контактов общего пула занял 18.392 мс среднего шага при полном шаге 18.695 мс; у потока — 4.698–7.242 мс в окнах по 600 шагов при полном среднем 8.718 мс. Учёт/оседание потока — 0.349–1.841 мс. Эти измерения выделили подготовку неиспользованных точек для отдельного опыта.

Поток сохранил db1e1ce4b296f5bf; общий пул 120/2 — 4c7fd3d49483106a. Последний независимо воспроизведён неизменяемой основной сборкой с теми же параметрами. Его нельзя подменять отпечатком 60/2. Диагностические исходники, EXE и журналы остаются в игнорируемом каталоге.

## Геометрия и проверки

Контактный итератор выдаёт те же занятые участки и округлённые точки. Последняя точка задаёт начало физического обхода и присутствует в конце полной последовательности; сохраняются все направленные рёбра и замыкание. Старый публичный contours и его арифметика используются для отрисовки и независимого сравнения. Тестовая ветвь без оптимизаций строит прежний полный Vec.

| Новый сценарий | Подтверждение |
| --- | --- |
| stopping_after_the_first_edge_rounds_only_the_boundary_corners | До первого ребра округлены два угла участка из 8192 ячеек вместо прежних 8196; после раннего выхода остальное не строится |
| separate_runs_and_the_closing_edge_match_the_original_contour | Три самостоятельных участка, разрывы с нулём/NaN/Infinity и направленные замыкающие рёбра совпадают с прежним списком |
| short_straight_and_tiny_corners_keep_literal_point_bits | Одинарные, прямые, tiny/subnormal, нулевые/отрицательные ширины, signed zero и большие смещения сохраняют биты координат |
| exceptional_coordinates_and_overflow_keep_the_original_classification | Overflow, Infinity и NaN сохраняют прежнюю классификацию; не-NaN значения сравниваются по битам |
| generated_profiles_keep_all_points_in_both_directions | 1024 профиля и 212151 точка прямого прохода, также весь обратный и смешанный проходы, порядок участков и начальная точка |

Все пять Passed в debug и release. Это 212151 исходная точка с повторной проверкой трёх способов обхода, а не три независимых набора профилей. Мутации принудительного полного расчёта, потери последней точки, удаления finite-фильтра и изменения четвертного шага получили Failed по утверждениям. Файл восстановлен побайтно в finally с проверкой SHA; все 102 библиотечные проверки снега Passed. Совпадение битов относится к проверенному стенду; численные границы API приведены в ADR.

Полный tools/check.ps1 Passed: 443 теста клиента, включая 167 lib и 20 example, 3 protocol, 35 проверок ресурсов и 31 кадров; fmt/clippy/release, четыре smoke, Ajv 60, PHP 60+5, SQLite и HTTP. Пять нативных сценариев ignored; IPC/WTS выполнены в обычном Windows-контексте. CI ещё не запускался.

## Окончательное A/B/B/A

После полного набора неизменяемые release-артефакты выполнили 20 последовательных запусков без параллельных компиляций и проверок. Для каждой сцены — A/B/B/A, seed 24301, fma. Baseline — 1200/120 шагов, material-stress — 360/120, две однокадровые контактные сцены — 60/2, contact-stream — 3600/120. В таблице среднее двух средних и среднее двух p95. Предварительные и инструментированные варианты не подставляются в эту пару. [Методика](MODEL_BENCHMARK.md).

Средние свежих контактных сцен сократились примерно на 13.6% и 10.7%. У общего пула стало 41/120 превышений DT вместо 120/120. Среднее близко к DT≈16.667 мс, но p95 ещё выше и бюджет каждого шага не принят. Двухэкранная контактная сцена — 0/120 у обеих сборок. Поток замедлился примерно на 2.8% по среднему и 3.4% по p95, превышения остались 26/7200. Отдельные средние потока: база 8.652/8.644 мс, новый путь 8.859/8.914 мс. В остальных сценах превышений не было; p95 material-stress вырос. Принимается обмен стоимости полного обхода на сокращение подготовки при ранних контактах, при открытом EN-09 и необходимости измерять оба режима дальше.

Все 20 отчётов проверены на порядок, параметры, вычислитель, баланс и пять прежних отпечатков: 3646490212806ffa, 2b40f0da0dca0af3, c1b226d3cfc02ba1, ebec7a8291d12ead, db1e1ce4b296f5bf. В каждом потоке — 3600 наблюдений, 16000 тел перед каждым шагом, минимум 2000 на каждом из восьми экранов и подтверждённое поступление/получение массы. Повторно допущено 298174 тела, минимум после шага 15873, максимальная относительная ошибка массы 1.04e-7. Времена относятся к модели без интерфейса и отрисовки.
