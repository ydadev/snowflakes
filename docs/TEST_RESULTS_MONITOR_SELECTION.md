# Проверки выбора мониторов

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P2-01/03; этап P2 остаётся In progress.

Полный tools/check.ps1 прошёл: 118 тестов клиента, 3 теста протокола, fmt, clippy с -D warnings, release, JSON Schema, PHP syntax, контракт, SQLite и HTTP.

| Проверка | Результат |
| --- | --- |
| Местный выбор | Passed: CLI selected сохраняет полный список, повторное открытие Controller восстанавливает его, all/primary очищают список ID |
| Независимость | Passed: серверный профиль и запрет редактирования не затирают местный список; возврат в местный режим восстанавливает его; ручная пауза сохраняется |
| Неверные значения | Passed: пустой selected, повторения, более 16 ID, управляющий символ и непустой all не меняют файл или Session |
| Отказ записи | Passed: недоступный целевой файл сохраняет прежние режим и список в памяти |
| Обнаружение | Passed: перестановка устройств и отрицательная координата не переносят выбор на другую строку; отключённый ID остаётся выбранным, пустой снимок не превращает его в all |
| Очередь | Passed: повторный выбор заменяется целиком, переключение источника сохраняет границу порядка |
| Настоящие контролы | Passed: скрытая Win32-панель создаёт список, собирает выделение только по кнопке применения, сохраняет более поздний черновик при ответе, показывает отключённый ID, запрещает пустой выбор и редактирование в серверном режиме |
| IPC процесса | Passed: изолированный headless-клиент принимает --monitors selected с двумя синтетическими ID и сохраняет Manual |

Добавлены пять тестов: два Controller, два модели UI/очереди и один скрытых контролов. Существующий тест процесса расширен проверкой monitor-команды. Проверка скрытой панели не использует настоящий ввод и не считается визуальной приёмкой.

Release-сборка подготовлена отдельно; новый графический процесс не запускался. Статус существующего экземпляра подтвердил ручную паузу и rendering=false. Его конфигурация не изменялась.

Not run: видимая панель, навигация настоящей клавиатурой, смешанный DPI, переключение графических слоёв в пределах 200 мс, физическое отключение/подключение и Windows 10. Синтетический список подтверждает логику сопоставления, но не работу конкретного драйвера или док-станции.
