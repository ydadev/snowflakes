# Подготовка переноса снега между настоящими мониторами

Дата: 15 ноября 2026 года. Область: часть P1/P2/P3, SN-05 и GE-08/09. Изменения только под cfg(test). [ADR 0088](adr/0088-native-monitor-transfer-gates.md).

## Доступность и результат

Штатная read-only команда --list-monitors --json и отдельный EnumDisplayMonitors на частном desktop показали один монитор. Положительные ветви переноса и пересечения экранов **Not run**. Нет подставного второго Screen, изменения раскладки, DPI или переключения входного desktop.

| Проверка | Результат |
| --- | --- |
| Размещение собственного окна на настоящем основном экране | Passed в debug/release |
| Идентичность окна и неизменная контрольная опора | Passed |
| Отсутствующий secondary не перемещает окно | Passed как отрицательная проверка команды |
| Неверный GPU-адресат сохраняет запрос снимка; правильный получает буфер | Passed в debug/release |
| Перенос естественного запаса primary → secondary → primary | Not run: distinct_secondary_unavailable |
| Пересечение двух экранов и пиксели обоих сегментов | Not run: distinct_secondary_unavailable |
| Настоящий mixed DPI и WM_DPICHANGED | Not run |

Тестовый родитель завершился успешно, но это не Passed для переноса. Его report имеет probe_completed=true, transfer_status/bridge_status=not_run_distinct_secondary_unavailable, пустые checkpoints/transferred_dpi, source_identity_retained=false и layers_retained=false. Ветка естественного заполнения и дочерний хост переноса не запускались. Новый обычный геометрический тест использовал отдельный собственный хост и проверил размещение/идентичность без снегового запаса.

## Подготовленный сценарий

NativeTestHost получил строго ограниченные команды primary/secondary/shared vertical edge. Они перечитывают настоящие экраны и меняют только своё окно после проверок startup desktop/владельца/потока/PMv2; NOACTIVATE сохраняется. Сортировка фактических rect согласует выбор secondary у родителя и ребёнка. Отсутствие secondary или общей вертикальной границы имеет отдельный ответ. Обычный тест проверяет настоящий DWM/Tracker, стабильный ключ окна и нетронутое второе окно; отсутствие событий при неизменном положении не форсирует новую сцену.

Для отдельных GPU-слоёв снимок запрашивается по идентичности живого bitmap. По умолчанию прежний capture остаётся первым доступным; при выбранном адресате чужой слой не расходует запрос. Чтение выполняется после EndDraw до Present. Одна и та же модельная отметка времени позволяет последовательно читать слои; bitmap/сырой handle не публикуются.

При наличии двух различных мониторов положительная ветка получает весь запас обычным emitter: сначала нулевая масса, затем заполнение крыши и естественное оседание при интенсивности 0. Условия включают запас и пиксели пола каждого экрана. Передвижения собственного окна проверяют одну идентичность, постоянный introduced_mass, общий баланс и сохранение HWND/swap-chain/эпох слоёв. Пиксели проверяются относительно текущих тел/опор с отступом 2 DIP. Масса срыва при ускорении входит в баланс; тест не требует жёсткой привязки всего снега к окну. Общая вертикальная граница проверяется отдельно; другая геометрия экранов не объявляется принятой.

Эти положительные ветви проверены чтением исходников и компиляцией, но не исполнением на двух экранах. Они могут потребовать исправления по результатам настоящего прогона; GE-08/09 и SN-05 этим не закрыты.

## Выполненные проверки

Новая проверка размещения Passed в debug/release. GPU-preflight подтвердил один реальный слой, ожидание неверного адресата, пустой правильный буфер, уничтожение ресурсов и три Present: все OCCLUDED, S_OK=0. Масса/частицы при этом не создавались; ошибка баланса 0 относится к пустой сцене, а не к переносу снега.

После изменения общего capture прошла прежняя [нативная очистка](TEST_RESULTS_NATIVE_CLEAR.md) в release: сохранены 130/370 обычных тел, вне текущих границ 0/0 пикселей. Все 3221 Present OCCLUDED. Это регрессия старого режима capture, не подтверждение нового второго GPU-слоя.

Итоговый tools/check.ps1 Passed: fmt/clippy, 529 тестов клиента + 3 протокола + 8 release-повторов (540 выполнений, 532 уникальные проверки Rust), 46 ignored. Восемь прежних smoke-отпечатков и границы массы/пулов сохранились. Сборщики 35/31 assertions Passed в одной локальной редакции PowerShell, существующие schema/PHP/SQLite/HTTP-проверки компонентов Passed. Разработка воды/сайта не возобновлялась.

В первом общем прогоне прежний production_native_tracker_reads_dwm_geometry_and_updates_move_close_without_fixture_source упал при TestDesktop::drop: SetThreadDesktop(original), HRESULT 0x800700AA. Новый тест размещения прошёл. Адресный повтор прежнего теста и повторный полный набор Passed. У нового фикстура отдельный суффикс имени desktop, но причинное исправление сбоя не доказано. Причина ERROR_BUSY остаётся открытой; строгие проверки восстановления не ослаблены.

[SetThreadDesktop](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setthreaddesktop) может отказать при оставшихся окнах/хуках вызывающего потока; [UnhookWinEvent](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-unhookwinevent) требует исходного потока. Это направление следующей диагностики, не установленная причина конкретного сбоя.

CI исходников [8356054](https://github.com/ydadev/snowflakes/actions/runs/43742456012) Passed: обе задачи success. Декодированный журнал Windows подтвердил новый обычный тест размещения, прежний Native-тест, 529+3+8 выполнений, 46 ignored, восемь прежних отпечатков и сборщики 35/31 в обеих редакциях PowerShell. Журнал PHP подтвердил 60 общих случаев + 5 транспортных, SQLite/HTTP. Две новые аппаратные точки действительно ignored; успешный CI не заменяет двухмониторный прогон и не доказывает устранение прежнего ERROR_BUSY.

## Открытые условия

Настоящий второй монитор, общий край, mixed DPI, полный Observer/Worker, реальный ввод, видимый S_OK/FPS, Windows 10/11 целиком, hotplug/device loss, ресурсы/длительный прогон и причина однократного сбоя очистки тестового desktop.

Рабочий клиент не заменялся и не получал Clear/Resume. Read-only статус manual/rendering=false подтверждён. Дождь, лужи, сайт и поставка отложены, цель активна.
