# Стоимость и монотонность уравнений контакта

Дата: 14 ноября 2026 года. Windows 11 x64, Rust 1.99.1/MSVC. База — a26fe51; решение — [ADR 0057](adr/0057-monotone-contact-roots.md). Все входы синтетические, работающий эффект не включается.

## Локализация

В отдельной игнорируемой копии модели добавлены таймеры на World::step, outline_range, trace_edge_contact_inner, AngularEdge::contact, внешний Polynomial::roots и deposit_mound. Рекурсивные вызовы входят во внешний таймер roots. Перед каждым измеряемым шагом счётчики сбрасываются; подготовка сцены и проверка результата не входят. Использован contact-stress, 60 шагов, 2 прогрева, seed 24301.

| Участок | Среднее, мс/шаг | Вызовов/шаг |
| --- | --- | --- |
| Весь шаг | 26.131 | 1 |
| Построение контура | 0.858 | 4800 |
| Поиск контакта ребра | 22.963 | 8252 |
| Проверка углового контакта | 21.545 | 11851 |
| Внешний поиск корней | 19.807 | 28708 |
| Оседание массы | 0.568 | 4800 |

Времена вложенные, складывать строки нельзя. Доля roots — около 76%; таймеры добавляют собственную стоимость, поэтому это локализация, не точное разделение CPU. Отдельный прогон со счётчиками насчитал 8 777 160 узлов рекурсии на 1 722 480 внешних запросов; почти все внешние запросы имели доминирующий линейный член производной. Обычный неизменённый EXE в контрольном прогоне дал 24.670 мс. В производственный код таймеры/счётчики этого опыта не включены.

## A/B/B/A

Две неизменяемые release-сборки, последовательные запуски без параллельной компиляции/проверок. Baseline: 1200/120 шагов; material-stress: 360/120; contact-stress: 60/2. Seed 24301, всего 12 запусков. [Методика](MODEL_BENCHMARK.md) отделяет подготовку и наблюдение от физического шага.

| Сценарий | Прежний средний / p95, мс | Новый средний / p95, мс |
| --- | --- | --- |
| baseline | 0.05329 / 0.06160 | 0.05855 / 0.07825 |
| material-stress | 0.56962 / 0.64925 | 0.53279 / 0.61380 |
| contact-stress | 23.73762 / 24.03170 | 20.48233 / 20.80410 |

Показаны средние двух запусков каждого варианта и среднее двух p95. Контактный шаг сократился на 13.7%; обычная сцена выросла примерно на 5 мкс, общего ускорения всех входов не заявляем. Отпечатки совпали: baseline — 3646490212806ffa, material-stress — 2b40f0da0dca0af3, contact-stress — c1b226d3cfc02ba1.

Каждый контактный запуск подтвердил 60 свежих эпизодов по 4800 тел: чистое уменьшение на 4800, доля массы на принимающих крышах 0.9927274, максимальная относительная ошибка 4.22e-8. Все 120 оптимизированных шагов всё ещё превысили DT≈16.7 мс.
