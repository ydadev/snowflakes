# Независимое накопление на окнах и полу через панель и GPU

Дата: 15 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P2-01/03, P3-03/04, SN-10. Вода, сайт и поставка отложены.

## Проверяемая цепочка

Настоящие скрытые Win32-checkbox управляют отдельными SnowOnWindows/SnowOnGround через Panel, Owner/Controller, временный TOML и опубликованный View. Нижний Native/Weather/World/GPU работает на другом потоке, ждёт реальные WM_NULL, сверяет токен и оба сохранённых флага. Узкий cfg(test) доступ проверяет скрытость, владельца PID/TID, родителя, Enable и PMv2 перед BM_SETCHECK/WM_COMMAND. Прежние ползунки переиспользуются через тот же мост.

Собственные окна NativeTestHost находятся на невходном startup desktop. Начальная масса нулевая; запас крыш/пола создаётся обычным emitter, затем воздух/очередь освобождаются при интенсивности 0. В проверяемых переходах интенсивность снова 100%, общий размер сугроба остаётся 100%. Профили, частицы и ledger тестом не задаются.

Проверяются все четыре сочетания флагов: оба включены, только окна выключены, только пол выключен, оба выключены; затем оба включаются вновь. Каждый нулевой шаг при off/on сохраняет mass/pending-профили, текущие физические поля воздуха и bitmap. Существующие слои уходят за активное модельное время, включение разрешает новое накопление от осадков.

## Материал и изображение

| Сценарий | Критерий |
| --- | --- |
| Только окна выключены | После первого STEP больше 90% их запаса остаётся; через секунду 35–65%, к 2,5 с меньше 0,001. Пол сохраняет массу с допуском 0,001 и положительную alpha |
| Окна включены вновь | Без шага пустой слой не возвращается, затем новые осадки наполняют крышу |
| Только пол выключен | Тот же плавный переход пола; материал окон сохраняется, их лежащий снег остаётся в GPU |
| Оба выключены | Все накопленные профили пусты с допуском 0,001; введённая масса растёт, летящие тела остаются |
| Обычная заметность при обоих off | Настоящий регулятор заметности 100% даёт пиксели обычных летящих снежинок при прежней физике; обратное скрытие возвращает прежний bitmap |
| Возврат обоих флагов | Нулевые шаги не восстанавливают запас; после осадков и полного оседания крыши/пол вновь имеют положительную массу и alpha |

При неизменной геометрии и выключенном курсоре материал окон учитывает лежащий запас, оторвавшиеся тела с их исходным ключом и ожидающий допуск spill. Это отделяет естественное осыпание кромки от нежелательного удаления другим флагом. Глобальный ledger проверяется на каждом update.

Для измерения лежащего слоя обычные снежинки временно скрыты настоящим регулятором заметности. В полосах крыши и пола отдельно считаются исходная alpha и alpha вне текущих границ физических тел с запасом 2 DIP на обводку/AA. При обоих off вне границ всех тел не должно быть пикселей; при заметности 100% пиксели вне границ связных пластов подтверждают именно обычный снегопад. Границы берутся из текущих render_pose, запас масштабируется по фактическому DPI слоя. Снимок получен после настоящего render_snow/EndDraw, до Present; фильтрация относится к измерению readback.

Bitmap, подробные позы и границы используются только в памяти и не сериализуются в отчёт. Сохранены guards имени/UOI_IO, PID/TID, PMv2, NoActivate, Watchdog и Job Object. Профиль/источник политики изолированы; ручная пауза сохранена, Conditions не готовы, Observer и графический Worker не создаются.

## Результаты

Отдельный debug и окончательный release Passed. Естественный запас получен за 136 STEP снегопада и 2659 STEP ожидания при интенсивности 0; затем все переходы выполнялись при 100% интенсивности. Измеренное развитие после переключения:

Нулевые шаги off/on сохранили профили, bitmap и текущие физические поля воздуха. Пол при выключенных окнах сохранился с разницей менее 0,00002, alpha его полосы оставалась положительной; при выключенном полу материал окон и alpha крыши сохранялись/росли. Удалённые полосы имели нулевую alpha вне тел. При обоих off вне всех физических тел оказалось 0 лишних пикселей; возврат заметности 100% дал 44969 пикселей обычного снегопада вне границ пластов, без изменения физики. Обратное скрытие вернуло точный bitmap.

Прошли четырнадцать настоящих команд/сохранений и пробуждений GPU: ключи 3,1,1,19,1,23,23,24,23,19,19,23,24,1. Трасса: input/dispatch/received/applied=14, superseded=13, observed/submitted=0, rejected/dropped=0, unfinished=1. Нижний стенд сохраняет прежнюю семантику последнего незавершённого токена. На DPI=96 все 6311 Present дали OCCLUDED, S_OK не было; максимальная относительная ошибка массы около 9,72e-7. Воздух/очередь в конце пусты, Host/потоки/Layer завершены, активных процессов в Job нет. Эти числа описывают прогон, а не фиксируют seed-зависимое наполнение.

Полный tools/check.ps1 Passed: fmt/clippy, 515 тестов клиента, 3 протокола и 8 release-повторов — 526 выполнений, 38 ignored. Восемь smoke сохранили эталонные отпечатки и ограничения массы/пулов. Сборщики 35/31, JSON Schema 60, PHP 60+5, SQLite и HTTP проверили прежние компоненты; вода/сайт не разрабатывались. Отдельные release-регрессии положительного и нулевого пределов Passed после изменения общего моста. Две новые аппаратные точки исключены из обычного набора.

Коммит 3e14207 прошёл [GitHub CI](https://github.com/ydadev/snowflakes/actions/runs/43716757147): оба задания success. Декодированные журналы подтвердили 526 выполнений, 38 ignored, восемь точных отпечатков и ограничения массы/пулов, 35/31 в PowerShell 7 и Windows PowerShell, JSON Schema 60, PHP 60+5, SQLite и HTTP. Новая аппаратная точка и helper действительно пропущены в CI; независимые накопления и обе регрессии пределов подтверждены отдельными локальными release-прогонами.

Изменения ограничены cfg(test); производственные силы и двухсекундное удаление не менялись. SHA-256 собранного release EXE: 88E931B409366AFF90D67177FC525968EFDEE148ECABB99E7BD18C0578B928AE. Побайтное равенство прежней сборке не заявляется. Рабочий клиент не заменялся; read-only статус подтвердил manual/rendering=false.

## Границы

Not run: настоящий ввод/видимая панель, показанный переход, полный Worker, CT-10 за 200 мс, Windows 10, mixed DPI/hotplug/device loss и ресурсы всего клиента/восьмичасовой прогон. Модельное время не принимается за wall-FPS, OCCLUDED — за S_OK. Приёмка плавности и всей матрицы окон остаётся открытой.

Рабочий эффект не включался, клиент не заменялся, input desktop не переключался. P2/P3 и общая цель остаются активными; дождь и лужи отложены.
