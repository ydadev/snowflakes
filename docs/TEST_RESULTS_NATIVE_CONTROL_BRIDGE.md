# Скрытая панель, сохранённый профиль и отдельный GPU-поток

Дата: 15 ноября 2026 года. Клиент 0.1.0, Rust 1.99.1/MSVC, Windows x64. Область: P2-01/03, P3-04, частичное CT-10 и CT-12/13. Продолжает [доставку настроек](TEST_RESULTS_CONTROL_LATENCY.md), [процентные пиксели](TEST_RESULTS_NATIVE_APPEARANCE_PIXELS.md) и [ADR 0081](adr/0081-private-desktop-worker-probe.md). Исходники: [сценарий GPU](../crates/snowflakes-client/src/platform/worker_probe/snow_pixels/controls.rs), [доступ к Owner](../crates/snowflakes-client/src/platform/runtime/control_probe.rs), [скрытые контролы](../crates/snowflakes-client/src/platform/panel.rs).

## Настоящие компоненты и границы стенда

На невходном startup desktop работают отдельные ролевые потоки: скрытая настоящая Panel, существующий поток управления Owner/Controller и нижний Weather/GPU. Recorder имеет собственный поток записи. Только cfg(test) открывает узкий доступ к имеющимся компонентам. Перед сообщениями проверяются обязательный desktop guard, UOI_IO=false, PMv2, PID/поток и скрытое состояние панели/trackbar, принадлежность контрола панели. Show/SetForegroundWindow и настоящий ввод не вызываются.

Временный Controller переводится на местный профиль, интенсивность 0, выключенные курсор/таяние/fullscreen; устанавливается ручная пауза. Owner использует существующий изолированный отсутствующий HKCU-источник политики и временный UserStore. HKLM, рабочий профиль, IPC, трей и сетевой опрос не запускаются. Настоящий Observer и графический Worker не создаются. Conditions остаются неготовыми и запрещают полноценный Worker, ручная пауза сохраняется после каждой операции. Нижний update вызывается явно для сравнения компонентов; это не обход гейтов работающего приложения и не его интерактивный запуск.

Синтетические TBM_SETPOS/WM_HSCROLL адресуются только собственным скрытым trackbar. Настоящий window procedure формирует команды, настоящая очередь Panel объединяет промежуточные значения. Owner получает запрос через свой канал, Controller сохраняет TOML, затем публикует View. Ответ сверяется с файлом и View; проверяется WM_NULL окну GUI. Другой GPU-поток получает WM_NULL своей очереди, сам читает опубликованный View и проверяемый токен. Канал стенда задаёт только число шагов/момент снимка, значения настроек через него не передаются.

Первая правка интенсивности 100% создаёт обычные снежинки за 120 STEP без начальной массы/seed. После правки интенсивности 0 время сравнений удерживается: размер и заметность оцениваются на одинаковых позах. На выбранном основном мониторе DPI=96 весь bitmap содержит только летящие снежинки, запас опор равен нулю. Снимки получаются после настоящего render_snow/EndDraw до Present. Физический World при смене заметности и весь bitmap после её возврата сравниваются точно. Это не измерение wall-задержки или FPS.

## Положительные правки и реальный отказ записи

Размеры 125 и 150% ставятся в очередь до обработки: применяется только 150%, с сохранением разброса радиусов. Затем проверяются заметность 0/200/100% и возврат размера 100%. Каждая принятая правка сверяет сохранённый файл, опубликованные настройки, нативное пробуждение и токен, прочитанный отдельным GPU-потоком.

Для отрицательного случая собственный временный файл профиля открыт без совместного доступа на запись/удаление. Нативная правка заметности 50% проходит обычный Owner/Controller, но атомарная замена действительно завершается ошибкой preferences_not_saved. Прежние байты файла, View и последний успешный токен сохраняются. Panel.complete/sync возвращают ползунок к 100%, что читается настоящим TBM_GETPOS. GPU после пробуждения получает прежние настройки, физический World и побайтно прежний кадр. Блокировка снимается закрытием собственного handle; рабочие файлы не затрагиваются.

## Результаты

Окончательные debug и release-пробы Passed. Первая версия стенда остановилась до сравнения пикселей; порядок проверки/установки DPI нового GPU-потока исправлен: сначала desktop, затем PMv2, затем полный guard до создания ресурсов. Это исправление испытательного стенда, производственная ошибка не заявляется. Последующие правки усилили проверки владельца и добавили настоящий отказ записи. Итоговый release дал следующие результаты; радиусы и пиксели меняются с seed.

| Правка через Panel/Owner | Наблюдение release |
| --- | --- |
| Интенсивность 100 → 0 | 260 обычных частиц созданы через опубликованный профиль; после остановки сравниваются те же частицы |
| Размер 125 → 150% в очереди | Промежуточный токен заменён; диапазон радиусов около 1.20–6.37 стал 1.80–9.56, пиксели 6057 → 12666 |
| Заметность 0% | Весь bitmap прозрачен: пиксели и сумма alpha равны 0, физический World прежний |
| Заметность 200% | Сумма alpha 1588012 против 934247 при 100%, физический World прежний |
| Возврат заметности 100% | Побайтно тот же кадр, 12666 пикселей, физика не изменилась |
| Возврат размера 100% | Число частиц прежнее, диапазон радиусов вернулся с относительным допуском 1e-5 |
| Ошибка сохранения заметности 50% | Файл, настройки, ползунок 100%, успешный токен, физика и bitmap сохранились |

В настоящей диагностике: input=9, dispatch=8, received=8, applied=7, rejected=1. Один запрос заменён ещё в Panel; всего superseded=7 с учётом последующих замен прежних применённых токенов. Это не означает, что их нижние кадры не вычислялись. dropped=0. Восемь обработанных запросов разбудили GUI-окно и отдельную нативную очередь GPU; все прочитанные токены соответствовали опубликованному View. Панель осталась скрытой, контрольный и GPU-потоки штатно joined, Layer HWND уничтожен; Job accounting подтвердил ноль живых процессов.

Observed=0 и submitted=0 не подделываются стендом: настоящий Worker отсутствует. Последний успешный токен имеет unfinished=1 по прежней семантике трассы. Все 129 Present дали OCCLUDED, S_OK не было. Максимальная относительная ошибка массы около 1.02e-9. Системные гейты и ручная пауза не снимались. Реальный ввод → сохранение → показанный кадр за 200 мс не принят.

Итоговый полный локальный набор Passed: fmt/clippy, 515 тестов клиента, 3 протокола и 8 release-повторов — 526 выполнений, 30 ignored. Восемь smoke сохранили эталонные отпечатки и ограничения массы/пулов. Сборщики 35/31, JSON Schema 60, PHP 60+5, SQLite и HTTP проверили прежние компоненты; вода/сайт не разрабатывались. Добавлены две ignored-точки: аппаратный сценарий и subprocess helper.

Коммит 45d3e70 прошёл [GitHub CI](https://github.com/ydadev/snowflakes/actions/runs/43704711208): оба задания success. Декодированный Windows-журнал подтвердил 526 выполнений, 30 ignored, восемь эталонных отпечатков и ограничения массы/пулов. Сборщики 35/31 прошли в PowerShell 7 и Windows PowerShell; отдельный журнал подтвердил JSON Schema 60, PHP 60+5, SQLite и HTTP. Обе новые точки действительно исключены из обычного CI. Мост скрытой панели/профиля/GPU подтверждён отдельным локальным release-прогоном, а не зелёным CI или показанным кадром.

Изменения ограничены cfg(test); производственные ветви, силы и фильтры не менялись. SHA-256 собранного release EXE: 1E845923291DAEEDDE02889B759EECC6DDCD80AA87B0D028F888A1ACAC043E46. Побайтное равенство с предыдущим EXE не заявляется. Рабочий клиент не заменялся и не возобновлялся; read-only status подтвердил manual/rendering=false.

## Повторение и ограничения

~~~powershell
cargo test -p snowflakes-client --release --locked --lib platform::weather::worker_probe::snow_pixels::controls::hidden_native_controls_reach_saved_view_and_separate_gpu_thread -- --ignored --exact --nocapture --test-threads=1
.\tools\check.ps1
~~~

Строка native_controls_pixels содержит отдельный результат. Каждый ответ/пробуждение ограничен тайм-аутом, внешний watchdog процесса — 30 секунд wall-времени. Несколько сохранённых bitmap нужны для точного сравнения и не являются замером памяти работающего клиента. Временные TOML/трасса и любые локальные логи не публикуются.

Not run: настоящий ввод и видимая панель, полный активный Worker/Observer, CT-10 за 200 мс, несколько физических мониторов/mixed DPI/WM_DPICHANGED/hotplug, реальная машинная политика, медленный диск, насыщенная сцена, device loss, ресурсы всего клиента, длительный прогон и полная матрица Windows 10/11. P1/P2/P3 и общая цель остаются открытыми; дождь, лужи, сайт и поставка отложены.
