# Движение и закрытие естественно наполненного окна в GPU

Дата: 15 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P2-02, P3-03/04, SN-05/06. Вода, сайт и поставка отложены.

## Связанный сценарий

На собственном невходном startup desktop запускаются настоящий NativeTestHost и нижний Weather/Native/Tracker/World/GPU. Сцена начинается с нулевой массы; снегопад наполняет крышу обычным emitter. Тест не задаёт начальные профили, частицы, ledger или ручной выпуск материала. После интенсивности 0 введённая масса проверяется на каждом шаге, воздух/очередь ожидаются при прежних силах.

Десять собственных команд native-nudge перемещают окно по одному физическому пикселю с SWP_NOACTIVATE. Перед каждой командой проходят два STEP, после обработки WinEvent update увеличивается на 30 мс для штатного объединения Registry. Проверяются настоящие DWM-рамки, прежний ключ, масса и отсутствие нового оторвавшегося материала. Команда native-move затем смещает исходную рамку на 80/40 пикселей. Порог ускорения, сглаживание скорости и определение телепортации используют производственный код; временной DISCONTINUITY для вызова срыва не применяется.

После двух модельных секунд проверяются тела исходной опоры, их опустившиеся визуальные границы, очищенная старая полоса и сохранившийся снег на новой крыше. Настоящее закрытие окна освобождает оставшуюся массу; не менее 90% остатка должно находиться в связных пластах. Затем все тела/очередь завершают жизнь, баланс сопоставляется с приростом массы/высоты/alpha пола и учтённым выходом. Контрольное окно сохраняет свой запас.

Для ограниченного ожидания до/после движения используется по два физических STEP на нижний update: это модельная частота обновления 30 Гц при прежнем фиксированном DT. Верхний предел — 7800 update, отдельный watchdog остаётся 30 секундами wall-времени. Подготовка к перемещениям и раннее падение используют одиночные STEP; update после нативной команды сохраняет описанный интервал 30 мс. Позы и скорость не ускоряются, масса не удаляется для завершения ожидания. Это не измерение FPS.

Снимки берутся из настоящего render_snow после EndDraw, до Present. Старый след проверяется в исходной и смещённой полосах. Bitmap не публикуется; в отчёте остаются безопасные числа. Сохранены строгие guards имени/UOI_IO, PID/TID, PMv2, NoActivate и Job Object. Работа на input desktop и изменения условий Observer/Worker не выполняются.

## Результаты

Первый debug остановился на ошибке сравнения внешней рамки Win32 с видимой рамкой DWM. Проверка исправлена: сравнивается измеренное смещение при неизменном inset. Производственное поведение не менялось. Исправленный debug и окончательный release Passed; дополнительная проверка локального баланса срыва присутствует в итоговом release.

| Итоговый release | Результат |
| --- | --- |
| Наполнение | 209 STEP обычного снегопада; затем 1307 update ожидания при интенсивности 0. Крыша 264,188910 единицы массы, 244 пикселя в полосе |
| Плавный ход | Десять сдвигов по пикселю, максимальная разница массы 0, новые тела/очередь отсутствуют, 244 пикселя сохраняются |
| Ускорение | Настоящее смещение DWM 80/40; осталось 184,149001, около 69,7% запаса |
| Через 2 с | 23 оторвавшихся тела исходной опоры с массой 80,039911. Их визуальные границы опустились ниже исходной крыши; 563 пикселя падающего материала. Старая полоса пуста, новая содержит 187 пикселей |

| Очистка | Исходная и смещённая полосы пусты после полного оседания; HWND/эпоха слоя сохранены, Host/Layer завершены, активных процессов в Job нет |

Введённая масса после выключения осадков оставалась равной 6602,068845. Глобальный ledger и отдельное сравнение запаса/срыва/выхода прошли; максимальная относительная ошибка около 7,06e-7. Все 2755 Present дали OCCLUDED, S_OK не было. Числа описывают этот прогон, не фиксируют seed-зависимое число тел или длительность оседания.

Полный tools/check.ps1 Passed: fmt/clippy, 515 тестов клиента, 3 протокола и 8 release-повторов — 526 выполнений, 34 ignored. Восемь smoke сохранили эталонные отпечатки и ограничения массы/пулов. Сборщики 35/31, JSON Schema 60, PHP 60+5, SQLite и HTTP проверили прежние компоненты; вода/сайт не разрабатывались. Прежний отдельный release-сценарий native-slide/закрытия также Passed после расширения команды. Две новые аппаратные точки исключены из обычного набора. GitHub CI опубликованного исходника ожидается.

Все изменения кода ограничены cfg(test). Производственные силы, сроки, фильтры и Observer/Worker не менялись. Release EXE сохранил прежний SHA-256 A293742BD0ECFD8DB0B0312B262F18C8F76FA78A15CC99CD053EF72E288608DA. Рабочий клиент не заменялся; read-only статус подтвердил manual/rendering=false.

## Границы

Not run: настоящий ввод/перетаскивание, показанный кадр, активный Worker, второй монитор/mixed DPI, hotplug, device loss, Windows 10 и ресурсы всего клиента/восьмичасовой прогон. Длительное естественное накопление допускает периодическую сверку Native; результат не доказывает wall-задержку WinEvent. OCCLUDED не принимается за S_OK. P1/P2/P3 и общая цель остаются открытыми.

Рабочий эффект не включался и не заменялся, desktop пользователя не переключался. Дождь и лужи не разрабатывались.
