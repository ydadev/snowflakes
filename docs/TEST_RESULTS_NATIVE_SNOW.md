# События окон и снежная масса

Дата: 15 ноября 2026 года. Клиент 0.1.0, Rust 1.99.1/MSVC, Windows x64. Область: P2-02/P3-03, SN-05/06, EN-06 и часть OS-03. Продолжает [межпроцессные WinEvent](TEST_RESULTS_NATIVE_WINEVENTS.md).

## Область проверки

Добавлены два библиотечных сценария. Дочерний процесс меняет свои окна на отдельном desktop, который не становится входным. Производственные hooks и callback принимают настоящие уведомления; Native::order и Registry формируют сцены, которые передаются настоящему World::set_scene. Callback напрямую не вызывается, NotifyWinEvent не используется. Производственный код, физические силы и внешний вид не менялись.

Как и раньше, тестовый Source допускает числовую геометрию только известных скрытых HWND ребёнка. Для World они считаются видимыми опорами; Native::read, графический поток и GPU-вывод этим не проверяются. Используется один синтетический дисплей. Два начальных профиля высотой 5 задаются тестом; естественное выпадение для их наполнения здесь не проверяется. Новые осадки, ветер и таяние отключены, размер накопления — 100%.

Время реестра — 0–360 мс: резервная секундная сверка не может скрыть потерю WinEvent. Физическое время продвигается фиксированными шагами World независимо от ожидания очереди Windows. Это не замер реальной задержки или FPS.

## Сценарии и утверждения

| Сценарий | Подтверждение |
| --- | --- |
| Плавное движение | Десять перемещений первого окна на 1 пиксель, по два физических шага между сценами; одно чтение изменённого окна на событие, прежнее поколение, масса обоих профилей сохраняется с допуском 0.01, падающих частиц нет |
| Резкое движение | Серия из 32 SetWindowPos принимается одним обновлением; остаётся не меньше половины и меньше 95% исходного слоя, отделившийся материал падает ниже прежней кромки и не возвращается на движущуюся опору; второе окно сохраняет массу |
| Закрытие | Настоящий DestroyWindow удаляет первую опору, сохраняет поколение второй и выпускает только связные пласты с прежним профилем, массой и направленной вниз скоростью |
| Закрытие на паузе | 120 вызовов step не выпускают тела из очереди при паузе дисплея; масса сохранена. После снятия паузы первый шаг выпускает пласты |
| Естественное приземление | Положение и скорость падающих тел не подменяются. Не позднее 1800 физических шагов пласты оседают, очередь пуста; масса пола совпадает с исходным слоем с относительным допуском 1e-5, второе окно сохраняет массу |
| Локальная горка | Высота выше 1, заняты хотя бы три ячейки, суммарная занятая ширина меньше 400 при ширине дисплея 800 |

Баланс introduced_mass − removed_mass − total_mass проверяется после каждой принятой сцены и каждого шага с относительным допуском 1e-5. Явно учтённое численное удаление ограничено долей 1e-6 исходной массы. Первоначальная проверка точного нуля removed_mass выявила остаток округления около 1.62e-5; тест скорректирован на численный допуск, продуктовая физика не менялась.

Целевой прогон Passed: оба новых сценария, включая активное и приостановленное закрытие в одном из них. Новые проверки завершают три собственных дочерних процесса нормальным кодом; guard очищает ресурсы и при ошибке. Вместе с прежними native-сценариями полный набор использует шесть дочерних запусков.

Полный локальный набор Passed: 507 тестов клиента, 3 протокола и 8 повторных release-тестов — 518 выполнений во внешних Rust-результатах; 6 ignored, включая служебную точку дочернего процесса. fmt/clippy, release-сборка и восемь smoke Passed; отпечатки, масса и ограничения пула сохранены. Сборщики: 35/31; JSON Schema: 60; PHP: 60 общих + 5 транспортных, SQLite и HTTP Passed. Проверки существующих компонентов не возобновляют отложенную разработку воды/сайта.

Продуктовый EXE сохранил SHA-256 предыдущей сборки: 41350D23418487B859A393B3FB7C8285C38C160356C9C5F69C9FEE5813E05200. Read-only status подтвердил manual и rendering=false; рабочий клиент не заменялся. Результат CI фиксируется после завершения.
