# Снег настоящего окна в GPU-буфере

Дата: 15 ноября 2026 года. Клиент 0.1.0, Rust 1.99.1/MSVC, Windows x64. Область: часть P2-02/P3-03/04, GE-01/03 и SN-05/06. [Исходник](../crates/snowflakes-client/src/platform/worker_probe/snow_pixels.rs), [стенд](adr/0081-private-desktop-worker-probe.md).

## Связанный путь

Аппаратный тест запускает отдельный процесс на явно заданном невходном startup desktop. Тот запускает прежний NativeTestHost, создающий два настоящих captioned-окна. Используются настоящие WinEvent, Tracker/Native/DWM, Weather::update, World, Layer/Gpu и чтение отрисованного bitmap. Source, координаты сцены, callback и NotifyWinEvent не подставляются.

Общий launcher создаёт ребёнка suspended, назначает в собственный анонимный Job Object с KILL_ON_JOB_CLOSE и только затем возобновляет. Так аварийное завершение верхнего теста не оставляет процесс с окнами. Нормальное завершение обоих детей проверяется; после выхода верхнего процесса учитывается задержка обновления job accounting, ожидается ноль активных процессов не более 2 секунд. Job API подключён только как Windows dev-dependency. Перед созданием/командами сохраняются проверки имени/UOI_IO=false, PMv2, PID/потока и NoActivate. SwitchDesktop и настоящий ввод не используются.

Выбирается основной монитор; в данном прогоне DPI=96. Начальная масса по 5 единиц высоты задана на двух реальных опорах; осадки, ветер, таяние и курсор выключены только в тестовом Settings. Затем реальные SetWindowPos сдвигают первую рамку вниз на 20 физических пикселей, DestroyWindow закрывает её. Вторая остаётся контрольной. Доставка создания/движения/закрытия проверена до секундной периодической сверки; checkpoint закрытия — 786 мс заданного времени Tracker.

Время модели задаётся возрастающими Instant с шагом STEP. Каждый шаг проходит через настоящий Weather::update/StepClock/World и GPU draw. Это ускоренная проверка последовательности кадров, а не измерение wall-FPS, задержки ввода или устойчивости в реальном времени.

## Пиксели и масса

| Контрольная точка | Подтверждение целевого прогона |
| --- | --- |
| Начальный сугроб | Ненулевая alpha в полосах обеих крыш; на первой — 570 пикселей |
| Перенос | После 40 физических шагов в прежней полосе 0 пикселей, в полосе нового положения крыши 583; контрольная крыша видна и её масса сохраняется |
| Закрытие | Исчезли окно и опора; выпущены 2 связных тела. Через 20 шагов ниже крыши 928 пикселей падающего материала |
| Полное оседание | Очередь и все тела пусты. В прежней полосе закрытой крыши 0 пикселей; на полу 4486 пикселей, пик горки около 13.47 физических пикселя |
| Масса | Исходная общая масса около 1340, контрольная опора около 670. Масса пола вместе с удалённой массой равна исходной массе первой крыши с допуском 1e-5 от общей; баланс проверяется на каждом кадре |
| Очистка | NativeTestHost штатно завершён; после Drop слоя HWND не существует, job accounting подтверждает отсутствие живых потомков |

Чтение включается test-only флагом только для нужных кадров, непосредственно после render_snow/EndDraw и до Present. Оно копирует bitmap собственного тестового слоя. На этом стенде чтение той же области после Present дало 0 при 570 до Present; первоначальная попытка измерить изображение после представления была исправлена. Дополнительной ручной перерисовки для получения снимка нет. Содержимое рабочего desktop не читается.

Первый предел ожидания 1800 кадров оказался недостаточным для мелких инерционных частиц после сдвига. На 30-й модельной секунде оставались 23 обычные частицы, без связных тел и очереди; они затем осели при прежних силах. Предел стенда увеличен до 7200 кадров; release завершил ожидание за 2117 кадров, максимальная относительная ошибка массы составила около 1.88e-7. Положения/скорости не подменялись, масса не удалялась для завершения прогона. Количество частей, итоговый контур и число кадров могут меняться с seed.

Все 2183 наблюдавшихся Present вернули DXGI_STATUS_OCCLUDED, S_OK-счётчик равен нулю. Ненулевые пиксели до Present не означают показанный кадр. Полный Worker и его системные причины паузы этим нижним update-сценарием не принимаются.

Новый release-прогон и обе прежние аппаратные пробы прошли с новым launcher/Job Object; нормальные выходы и нулевой job accounting подтверждены. Полный локальный набор Passed: fmt/clippy, 515 тестов клиента, 3 протокола и 8 release-повторов — 526 выполнений, 12 ignored; восемь smoke сохранили отпечатки и прошли ограничения массы/пулов. Сборщики 35/31, JSON Schema 60, PHP 60+5, SQLite и HTTP прошли как проверка прежних компонентов. Разработка воды/сайта не возобновлялась.

Коммит 629e23e прошёл [GitHub CI](https://github.com/ydadev/snowflakes/actions/runs/43688431663): оба задания success. Декодированный Windows-журнал подтвердил 526 выполнений, 12 ignored, восемь эталонных отпечатков smoke и ограничения массы/пулов. Сборщики 35/31 прошли в PowerShell 7 и Windows PowerShell; отдельное задание подтвердило JSON Schema 60, PHP 60+5, SQLite и HTTP. Новая пиксельная проба и обе прежние аппаратные пробы действительно исключены из обычного CI. Их результаты выше получены отдельными локальными release-запусками; зелёный CI не заменяет аппаратную проверку.

Производственная физика и фильтры не менялись; добавлены test-only чтение пикселей и доступ к прежнему Host. SHA-256 собранного release EXE: 71D4A624AEA85274918A349929F2FE94B183EEE8FC722ED78103EE274970063A. Рабочий клиент не заменялся и не возобновлялся; read-only status подтвердил manual/rendering=false.

## Повторение и ограничения

~~~powershell
cargo test -p snowflakes-client --release --locked --lib platform::weather::worker_probe::snow_pixels::native_window_snow_moves_without_old_pixels_and_closes_into_a_rendered_ground_pile -- --ignored --exact --nocapture --test-threads=1
.\tools\check.ps1
~~~

Строка native_snow_pixels содержит результаты этапов, массу, пиксели и Present-счётчики. Внешний watchdog ограничивает ребёнка 30 секундами wall-времени; 7200 — отдельный предел шагов модели. Публичные отчёты не содержат ID окон/мониторов, реальных имён, координат рабочего окружения или изображений.

Not run: видимый вывод и настоящий ввод/перетаскивание, активный Worker, второй монитор/mixed DPI/hotplug, настоящее перекрытие/cloak в связанном GPU-сценарии, произвольные приложения/стили, device loss, ресурсы всего клиента, длительный прогон и полная матрица Windows 10/11. Снег задан начальным слоем; естественное заполнение крыши снегопадом не принимается этим тестом. P1/P2/P3 и общая цель остаются открытыми; вода, сайт и поставка отложены.

Последующее [перекрытие/APP cloak и скрытое закрытие в GPU](TEST_RESULTS_NATIVE_COVERAGE_PIXELS.md) проверены отдельным продолжением. Оно не заменяет видимый вывод или прочие ограничения исходного прогона.
