# Native: скрытие, сворачивание и cloak

Дата: 15 ноября 2026 года. Клиент 0.1.0, Rust 1.99.1/MSVC, Windows x64. Область: P2-02/P3-03, GE-01/03, OS-02/03 и SN-06. Продолжает [полный Native](TEST_RESULTS_FULL_NATIVE_SCENE.md).

## Нативный стенд

Добавлены три библиотечных сценария. Используются настоящие Tracker::poll, Native, WinEvent, DWM и World на отдельном невходном desktop. Подставного Source, ручного callback и NotifyWinEvent нет. Перед переходом проверяются имя собственного desktop и UOI_IO=false; права переключения нет. Все изменения относятся только к своим окнам, проверяется PID/Thread ID.

Hide/show выполняются через SetWindowPos с SWP_HIDEWINDOW/SWP_SHOWWINDOW и SWP_NOACTIVATE; минимизация/возврат — через SW_SHOWMINNOACTIVE/SW_SHOWNOACTIVATE. Cloak/uncloak задаётся DwmSetWindowAttribute(DWMWA_CLOAK); ребёнок ограниченно ожидает фактическое изменение DWMWA_CLOAKED, а родитель независимо проверяет APP-бит и результат Native::read. Флаги, которые просили бы активацию, не используются.

Начальный профиль высотой 5 задан на двух опорах, новые осадки/ветер/таяние отключены. Время Tracker — 0–90 мс, периодическая сверка исключена. Модель идёт фиксированными шагами. Это не измерение задержки или проверка видимого вывода. Продуктовый код и физика не менялись.

## Подтверждённое поведение

| Сценарий | Подтверждение |
| --- | --- |
| Hide/show | Native исключает скрытое окно, сцена удаляет опору, World выпускает связные пласты. После естественного оседания показ того же HWND получает новый ключ и пустой профиль; масса остаётся на полу |
| Minimize/restore | IsIconic реально устанавливается и снимается. Свёрнутая опора исключена, снег выпущен пластами, при возврате не копируется прежний слой; геометрия возвращается к исходной |
| Пауза при исключении | Hide и minimize проверяются при активном дисплее и после ручной паузы World: 120 шагов сохраняют очередь, после возобновления снег падает и оседает |
| Cloak/uncloak | DWMWA_CLOAKED получает APP-бит; IsWindowVisible не используется как замена cloak. Native сохраняет запись с visible=false, ключ и массу. Видимые сегменты опоры пусты, пробная снежинка проходит ниже кромки, скрытая опора не принимает её массу. Uncloak возвращает тот же ключ и сохранённый слой |
| Закрытие cloaked-окна | Скрытый материал выпускается в скрытом слое: falling_clips пусты, после завершения падения на полу всех дисплеев нулевая масса этого слоя. Его масса явно учитывается в removed_mass; вторая опора сохраняется |

Проверка hide/minimize содержит четыре сочетания с паузой; ещё два сценария проверяют cloak. Новые проверки штатно завершают шесть собственных детей; полный набор вместе с прежними native-сценариями использует пятнадцать запусков. Guard очищает ресурсы и при ошибке.

В циклах паузы/падения и на контрольных этапах переходов баланс массы проверяется с относительным допуском 1e-5. Активный сброшенный слой естественно оседает не позднее 1800 шагов, масса пола совпадает с исходной с тем же допуском; второе окно сохраняет массу с допуском 0.01. Исчезновение скрытого слоя подтверждается отдельно через removed_mass, а не считается сохранением на видимом полу.

Локально Passed: три новых сценария и полный набор из 512 тестов клиента, 3 протокола и 8 повторных release-тестов — 523 выполнения во внешних результатах; 6 ignored, включая служебную точку дочернего процесса. fmt/clippy, release-сборка и восемь smoke Passed. Прежние отпечатки, масса и пределы пула сохранены. Сборщики: 35/31; JSON Schema: 60; PHP: 60 общих + 5 транспортных, SQLite и HTTP Passed. ## Повторение и ограничения

~~~powershell
cargo test -p snowflakes-client --locked --lib platform::scene::tests::events::native_source::visibility:: -- --nocapture
.\tools\check.ps1
~~~

Not run: Shell/inherited cloak и настоящий переход виртуального рабочего стола, реальные приложения/Explorer, быстрый возврат окна до оседания пластов, производственный графический поток, Layer/DPI, несколько физических мониторов, ввод и GPU-вывод на входном desktop, ресурсы полного клиента, длительный прогон и полная матрица Windows 10/11. Пауза World задана тестом и не подтверждает автоматический fullscreen. Native::screens по-прежнему передаёт исходный scale=1; DPI-коррекция слоя здесь не выполняется. P2/P3 остаются In progress; вода, сайт и поставка отложены.

Основания API: [ShowWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-showwindow), [DWMWA_CLOAK/CLOAKED](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute).
