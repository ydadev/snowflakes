# Нулевой размер накопления при продолжающемся снегопаде

Дата: 15 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P2-01/03, P3-03/04, CT-08 и часть SN-10. Вода, сайт и поставка отложены.

## Проверяемая цепочка

Переиспользован настоящий [мост регулятора сугробов](TEST_RESULTS_NATIVE_DRIFT_CONTROL.md): скрытая Panel, поток Owner/Controller, временный UserStore/TOML, опубликованный View и отдельный нижний Native/Weather/World/GPU. Команды проходят реальные очереди и сохранение; каждый GPU-снимок после команды ждёт WM_NULL и сверяет токен/настройки. Дополнительные шаги модели не подделывают новые публикации.

Собственные окна NativeTestHost находятся на невходном startup desktop. Сцена начинается без материала; обычный emitter наполняет крыши и пол. После интенсивности 0 воздух/очередь освобождаются при прежних силах. Тест не задаёт запас, тела, ledger и не вызывает ручной выпуск снега.

После получения естественного запаса настоящий регулятор заметности устанавливается в 0%. Летящие снежинки продолжают физическую симуляцию; это позволяет отдельно измерять накопленный слой в GPU-буфере. Настоящий регулятор интенсивности возвращается к 100%, затем размер сугроба проходит 100→0→100%. Скрытие обычных снежинок не считается выключением осадков: их число, масса и прирост introduced_mass проверяются независимо.

## Сценарии

| Действие | Проверяемое поведение |
| --- | --- |
| Начало с нуля | Единственный источник материала — производственный снегопад; до первого включения масса равна нулю |
| Нулевой шаг после 100→0% | Совпадают профили mass/pending всех опор, bitmap, введённая/удалённая масса и текущие физические поля всех летящих тел |
| Первый STEP | Более 90% накопленного слоя остаётся; мгновенного удаления нет |
| Через 1 модельную секунду | На проверяемой крыше и полу остаётся 35–65% исходного запаса; introduced_mass растёт, тела и воздушная масса положительны |
| Через 2,5 с | Суммарная накопленная масса меньше 0,001, bitmap прозрачен; снегопад продолжает вводить новые тела |
| Ещё 2 с при 0% | Нового накопления/пикселей нет, введённая масса продолжает расти |
| Нулевой шаг после 0→100% | Пустые профили и bitmap, масса и текущие физические поля воздуха сохранены; старый слой не возвращается |
| Последующие осадки | Крыша получает новый запас и alpha; после остановки интенсивности весь воздух/очередь оседают, пол и крыши вновь имеют положительную массу |

Физическое сравнение летящих тел включает положение/скорость, радиус/массу, угол/вращение, возраст, собственную непрозрачность/вид, исходную опору, slab-профиль и текущую единицу DPI. Приватная предыдущая поза интерполяции не сравнивается. Общий ledger проверяется каждым нижним update; итоговый накопленный запас ограничен массой новых осадков после исходного тихого состояния.

Снимок берётся после настоящего render_snow/EndDraw, до Present. Bitmap и подробные физические поля используются только в памяти; числовой отчёт не содержит пользовательских окон или настроек. Сохранены guards имени/UOI_IO, PID/TID, PMv2, NoActivate, Watchdog и Job Object. Ручная пауза сохраняется, Conditions остаются неготовыми, Observer и графический Worker не создаются.

## Результаты

Первый и усиленный debug, итоговый release и регрессия прежнего ненулевого предела Passed. В release первоначальный запас получен за 182 STEP снегопада и 2726 STEP ожидания после интенсивности 0: 5455,127912 единицы массы, из них 437,446548 на проверяемой крыше и 4862,283862 на полу. Другая тестовая крыша учитывается в общем запасе.

| Момент при интенсивности 100% | Общая накопленная масса | Число летящих тел | Введённая масса |
| --- | --- | --- | --- |
| 100→0%, без шага | 5455,127909 | 130 | 7226,356605 |
| Первый STEP | 5409,668510 | 132 | 7252,264111 |
| 1 с, всего 60 STEP | 2727,563756 | 260 | 9010,878505 |
| 2,5 с, всего 150 STEP | 0 | 445 | 11816,797307 |
| Ещё 2 с при 0% | 0 | 677 | 15612,549186 |
| 0→100%, без шага | 0 | 677 | 15612,549186 |
| Ещё 3 с осадков | 913,457195 | 1013 | 21184,346049 |

Профили, полный bitmap и текущие физические поля воздуха совпали при обоих нулевых шагах. При очистке и удержании 0% весь bitmap имел ноль ненулевых alpha-пикселей, несмотря на положительные массу воздуха и прирост осадков. Через три секунды после возврата лимита крыша накопила 585,938599, сумма alpha её полосы выросла до 87950. После конечной интенсивности 0 воздух/очередь освободились за 2641 STEP; новый общий запас 14660,586643 ограничен новой введённой массой после исходного тихого состояния.

Прошли восемь настоящих команд/сохранений и пробуждений GPU: ключи 3,1,1,19,1,3,3,1. Трасса: input/dispatch/received/applied=8, superseded=7, observed/submitted=0, rejected/dropped=0, unfinished=1. Последний незавершённый токен сохраняет прежнюю семантику, нижний стенд не подделывает стадии полного Worker. На DPI=96 все 6074 Present дали OCCLUDED, S_OK не было. Максимальная относительная ошибка баланса около 7,98e-7. Host, контрольный и GPU-потоки завершились штатно, Layer уничтожен, Job не содержит активных процессов. Числа относятся к этому прогону, не фиксируют seed-зависимое наполнение.

Полный tools/check.ps1 Passed: fmt/clippy, 515 тестов клиента, 3 протокола и 8 release-повторов — 526 выполнений, 36 ignored. Восемь smoke сохранили эталонные отпечатки и ограничения массы/пулов. Сборщики 35/31, JSON Schema 60, PHP 60+5, SQLite и HTTP проверили прежние компоненты; вода/сайт не разрабатывались. Две новые аппаратные точки исключены из обычного набора. GitHub CI опубликованного исходника ожидается.

Изменения ограничены cfg(test); силы, двухсекундный переход и производственные гейты не менялись. Release EXE сохранил прежний SHA-256 A293742BD0ECFD8DB0B0312B262F18C8F76FA78A15CC99CD053EF72E288608DA. Рабочий клиент не заменялся; read-only статус подтвердил manual/rendering=false.

## Границы

Not run: настоящий ввод, показанный переход, полный Worker, CT-10 за 200 мс, Windows 10, mixed DPI/hotplug/device loss и ресурсы всего клиента/восьмичасовой прогон. Нулевой bitmap при заметности 0 не означает отсутствие физических снежинок. Модельные секунды не доказывают wall-FPS; OCCLUDED не принимается за S_OK. Отдельные флаги накопления на окнах/полу остаются отдельной связанной проверкой.

Рабочий эффект не включался, клиент не заменялся, input desktop не переключался. P2/P3 и общая цель остаются открытыми; дождь и лужи отложены.
