# Проверки снега без доступных дисплеев

Дата: 14 ноября 2026 года. Windows 11, Rust 1.99.1/MSVC x64. P2-04, P3-03/04, SN-06 и частичное покрытие GE-09/OS-04. Активен только снег и его основа.

Исправлено разрушение геометрии при пустом списке экранов. Последний непустой снимок Screen сохраняет единицы материала и нижние опоры; актуальный список World.scene остаётся пустым. [ADR 0033](adr/0033-suspended-display-geometry.md).

## Регрессии

| Проверка | До исправления | После |
| --- | --- | --- |
| stocked_profiles_freeze_with_no_displays_and_resume_unchanged | Failed: исчезали нижние опоры | Passed: три пустых обновления и 180 возможностей шага сохраняют точные координаты, ширины ячеек, mass/pending всех профилей; возврат прежних экранов не пересэмплирует их. Масштаб 100/200/250% |
| closing_a_roof_with_no_displays_uses_its_last_dpi | Failed: ширина ячейки закрытой крыши теряла DPI 150% | Passed: оба окна закрываются без экранов; после 120 возможностей шага снег ещё ожидает, после возврата выпускаются оба источника с прежней физической шириной ячейки и слоем 5 DIP. Пары DPI: 100/100, 150/250, 250/150 и 200/200% |
| compaction_with_no_displays_keeps_geometry_and_visibility_on_return | Failed: профиль достигал 554 DIP при пределе расстановки 298 DIP | Passed: очередь 130 → 128 при отсутствии экранов; после возврата выпущены 128 пластов, размах не растянут, массы видимых/скрытых источников совпадают с входом в пределах 0,1%. Масштаб 100/200% |

Снег задаётся синтетическими профилями с учётом введённой массы. В первом сценарии лежат 5 DIP на крышах и 3 DIP на нижних опорах. Третий использует 65 синтетических дисплеев и две видимости на каждом, чтобы пересечь границу 2N → 128. Это стресс входных классов, не заявленная нативная аппаратная конфигурация. Окна закрываются через set_scene, без прямого удаления тел из пула.

Во всех сценариях баланс учитывает полный total_mass; явный сток равен нулю. Отсутствие экранов не выдаётся за проведённое активное физическое время. Возвращаются прежние прямоугольники/масштабы, поэтому результат не доказывает корректность произвольной перестановки дисплеев.

Дополнение после [ADR 0037](adr/0037-pending-snow-packets.md): 128 записей очереди теперь могут содержать несколько самостоятельных тел. Третий тест выпускает все 130 исходных пластов, ограничивая ширину каждого исходной крышей 54 DIP; прежнее ожидание 128 объединённых тел заменено более точным сохранением геометрии. Остальные условия баланса и видимости сохранены.

Полный tools/check.ps1 Passed: 227 тестов клиента, включая 103 в snow и 36 модульных, 3 теста протокола, 33 проверки ресурсов, 31 проверка кадров, fmt/clippy/release, JSON Schema и PHP/SQLite/HTTP. Один аппаратный тест кадров исключён из обычного прогона. Прежний конечный поток из 340 закрытий также остаётся в наборе.

Аудит сверил 148 файлов с GitHub по blob SHA и HEAD; история, метаданные и отсутствие частных значений проверены, 321 местная Markdown-ссылка действительна. Подготовленная сборка использовалась только для чтения статуса существующего клиента: ручная пауза, rendering=false. Рабочий эффект не перезапускался.

Not run: физическое отключение/подключение экранов, частичный возврат или новая расстановка/DPI, видимые маски и контуры, Windows 10, CT-10, CPU/GPU/память и восьмичасовой прогон. Сохранён один последний набор экранов; история каждого тела не добавлена. Рабочий эффект и CUA не запускались.
