## GPU-прототип

Стенд: Windows 11, два экрана 2560×1440, масштаб обоих 100%. Запущены отдельные процессы синтетического окна и слоя. Вызовы создания D3D11, DXGI, DirectComposition и Present завершались без ошибок. Ограниченный прогон завершился сам через 180 секунд.

- Passed: перечислены два монитора, созданы два окна со swap chain.
- Passed: во время программной паузы счётчик кадров оставался 147.
- Passed: графические ресурсы пересозданы, отрисовка продолжилась.
- Passed: ни одно окно слоя не обнаружено активным при проверках во время цикла.
- Диагностика завершения: 7300 кадровых циклов; это не замер на базовом стенде ТЗ.
- Дополнительная проверка: alpha-композиция на основном экране Windows 11 видима над синтетическим окном. Реальный ввод через слой и перетаскивание не засчитаны; полный интерактивный прогон остаётся Not run.
- Not run: Windows 10, смешанный DPI, подключение монитора на ходу, настоящий сброс GPU/драйвера, блокировка/сон/RDP и производительность ТЗ.

Программное пересоздание ресурсов и отсутствие зарегистрированной активации не заменяют эти интерактивные проверки. P1-03/P1-04 остаются незавершёнными.

## Следующий прогон

Повторить ввод и видимость на чистом синтетическом окне, затем Windows 10 и смешанный DPI. До этого путь графики остаётся кандидатом; независимые состояния клиента и тесты геометрии можно разрабатывать дальше.
