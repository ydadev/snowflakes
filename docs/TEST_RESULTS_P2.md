# Проверки основы клиента P2

Дата: 13 ноября 2026 года. Код: 16801a9. Этап не завершён. Проверяется библиотечное ядро session/timing, без оконного цикла и сетевого транспорта.

## Проверено

Команды: cargo test --workspace --locked и cargo clippy --workspace --all-targets --locked -- -D warnings. Среда: Windows 11, Rust 1.99.1/MSVC x64. Все 19 новых интеграционных тестов прошли; прежние 3 теста протокола также проходят.

| Область | Результат и охват |
| --- | --- |
| Профили | Passed: ожидание сервера по умолчанию, независимость местных значений, отказ местного редактирования в серверном режиме, возврат профиля |
| Отмена | Passed: один текущий запрос, выключение/включение галочки, поздний ответ, ответ другой Session, тайм-аут |
| Кеш | Passed: ошибки/меньшая ревизия/конфликт не продлевают срок; одинаковый ответ продлевает; новое поколение сбрасывает порядок ревизий |
| Истечение | Passed: отключение эффекта и маркер очистки, опрос остаётся разрешён; истечение серверного кеша не очищает местный режим |
| Паузы | Passed: независимость причин, очистка и синхронизация во время паузы, серверное/местное выключение во время паузы |
| Политики | Passed: пределы обоих режимов, восстановление исходных значений, обязательные паузы, запрет режима, атомарный отказ ошибочной политики |
| Завершение | Passed: выход и Enabled=false отменяют запрос; ответ и снятие запрета не возобновляют закрытую Session |
| Мониторы | Passed на модели: полноэкранность одного экрана не останавливает другой, ручная пауза остаётся общей |
| Время | Passed: одинаковое число шагов за 120 секунд при 30/60 FPS с допуском одного шага, пауза/сон без догоняющих осадков, ограничение работы медленного кадра |
| CI | Passed: [GitHub Checks](https://github.com/ydadev/snowflakes/actions/runs/43376674259), Rust/Windows и PHP/контракт/Linux |
| Публикация | Passed: проверены 58 файлов, 60 местных ссылок и метаданные; опубликованные blob SHA совпали с проверенным индексом |

## Не проверено и не реализовано

Not run: реальное применение этих состояний в окне/трее, чтение реестра GPO, события Windows, отмена HTTP-операции, отсутствие GPU-кадров и физическое очищение частиц. Тесты подтверждают решения ядра, а не ещё не подключённые внешние действия.

TOML и серверный кеш на диске, CLI/IPC, одноэкземплярность и автозапуск пока не реализованы. Испытания на Windows 10 и проверки P1 видимости/ввода остаются открытыми.
