# Проверки основы клиента P2

Дата: 13 ноября 2026 года. Начальное ядро: 16801a9; хранение: 87f7531; Windows runtime: 58e06ea. В текущем шаге добавлена нативная панель (ADR 0007). Этап не завершён, GPU и HTTP не подключены.

## Проверено

Команды: tools/check.ps1 и отдельный запуск обычных debug/release процессов с CLI и штатным quit. Среда: Windows 11, Rust 1.99.1/MSVC x64. Прошли 56 тестов клиента: 20 Session/timing, 20 хранения, 7 Controller, 4 очереди/раскладки UI, 1 скрытой панели Win32, 3 Win32 IPC/ACL/mutex и 1 процессный сценарий. Три теста протокола, PHP/SQLite/HTTP/JSON Schema и release-сборка также прошли.

## Не проверено и не реализовано

Not run: визуальная работа меню трея, полная клавиатурная навигация и масштаб панели, перезапуск Explorer, смена реальных GPO и уведомления реестра, другие сеансы/принципалы и сетевой клиент канала, события Windows, отмена HTTP и физическое очищение частиц. API трея возвращали успех; это не заменяет интерактивную проверку.

Обычный запуск теперь использует UserStore и Controller. Расширенные настройки панели, административная адресация другого сеанса, создание автозапуска, уведомления реестра и очистка marker прошлых входов впереди. Настоящие перезагрузки, сон, часы, несколько сеансов и отключение питания — Not run. Windows 10 и P1 видимость/ввод остаются открытыми. Привязка кеша к регистрации и DPAPI-токен будут подключены до HTTP.
