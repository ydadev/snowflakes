## Повторение и оставшаяся приёмка

~~~powershell
cargo test -p snowflakes-client --locked --lib policy -- --nocapture
.\tools\check.ps1
~~~

Нативные тесты выполняются в обычном контексте Windows с правом создавать и удалять собственные тестовые HKCU-ключи. Конструктор такого Source компилируется только для unit-тестов; продукт использует фиксированный машинный путь и 64-битное представление.

Not run: настоящая доменная GPO, изменяемый HKLM на изолированных Windows 10/11, реальные security transitions и RegRestoreKey, применение к видимому снегу и измерение кадров/ресурсов полного клиента. Нужен отдельный разрешённый стенд. Успех временных HKCU-проверок эту приёмку не заменяет. Активный приоритет — снег и необходимая основа клиента; дождь, лужи, сайт и развёртывание отложены.
