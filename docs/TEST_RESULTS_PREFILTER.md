# Предварительный отбор снежных пластов

Дата: 14 ноября 2026 года. Windows 11 x64, Rust 1.99.1/MSVC. База — a72fc0c; решение — [ADR 0055](adr/0055-slab-contact-prefilter.md). Физика дуги из [ADR 0054](adr/0054-angular-contour-contact.md) сохраняется.

Последующий [замер массовых приземлений](TEST_RESULTS_CONTACT_WORKLOAD.md) добавляет настоящий контактный вход и отдельную остановку поиска на нуле. Приведённый здесь material-stress сохраняет прежнюю область далёких тел.

Эталон вызывает тот же step с отключённым предварительным отбором. Сравниваются значения всех полей World через тестовый Debug, включая RNG, позы и единицы, профили/массу, очереди, слои, индекс и бюджеты; исключены только тестовые счётчики работы. Сравнение выполняется после каждого из 720 шагов двух последних сценариев, дополнительно — в одиночном тесте. Это сравнение модельных состояний, без сравнения адресов памяти или native клиента.

Контрольное изменение, заставляющее фильтр отбрасывать все контакты, получило Failed в сравнении состояний. Источник восстановлен в finally с совпадением SHA; все шесть сценариев повторно Passed до полного прогона. Изменение было только проверкой чувствительности теста и не опубликовано. Баланс introduced − removed − total проверяется с пределом 0.1%.

## Release-измерение

Прежний и новый EXE запускались последовательно A/B/B/A. В каждом: seed 24301, прогрев 120 шагов, baseline — 1200 измеряемых шагов, material-stress — 360 с эпизодами по 120. Восемь запусков не пересекались с другими проверками. Подготовка и наблюдение исключены из таймера шага; [методика](MODEL_BENCHMARK.md) сохраняется.

| Сценарий | Прежний средний / p95, мс | Новый средний / p95, мс |
| --- | --- | --- |
| baseline, пик 383 тела | 0.05293 / 0.06420 | 0.05349 / 0.06405 |
| material-stress, пик 4800 пластов | 4.69690 / 4.85870 | 0.53723 / 0.63700 |

Показаны средние двух запусков каждого варианта, включая среднее двух p95. Средний шаг тяжёлой сцены снизился примерно на 88.6%. Обычная сцена отличается примерно на 1% и не подтверждает общего ускорения. В material-stress во время шагов нет обычных окон; пласты большую часть эпизода далеки от нижних опор. Это подходящий вход для отбора, а не замер плотного потока реальных контактов.

Выборочные отпечатки совпали: 3646490212806ffa и 2b40f0da0dca0af3. Максимальная наблюдённая относительная ошибка массы — 7.03e-7/7.16e-9. Отпечаток не охватывает все скрытые поля и не заменяет отдельное сравнение World или регрессии вращения.

| Проверка | Результат | Причина |

| Внешний вид, реальный ввод и обе ОС | Not run | Рабочий эффект на ручной паузе; CUA остановлена |

| Стоимость сцены с тысячами действительных одновременных контактов | Not run | Фильтр оставляет полный решатель; модельный стресс измеряет другой режим |
