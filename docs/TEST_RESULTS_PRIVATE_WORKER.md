# Worker и нижний GPU-слой на невходном desktop

Дата: 15 ноября 2026 года. Клиент 0.1.0, Rust 1.99.1/MSVC, Windows x64. Область: часть P1-03/04 и P2-04; [ADR 0081](adr/0081-private-desktop-worker-probe.md). Исходник: [worker_probe.rs](../crates/snowflakes-client/src/platform/worker_probe.rs).

## Изоляция

Проверен дочерний процесс библиотечного тестового EXE с явно заданным STARTUPINFOW.lpDesktop. До создания настоящего Worker и его очереди проверяются имя и UOI_IO=false. Родитель не меняет свой desktop; переключение desktop, активация и ввод не запрашиваются. У ребёнка временный профиль, собственные View/Report и настоящий Observer; рабочего IPC/трея и обращения к профилю работающего клиента нет. Ограничение времени и guard принадлежащих процессных handles защищают очистку при отказе.

## Полученные результаты

| Фаза | Результат | Фактическое подтверждение |
| --- | --- | --- |
| Настоящий Worker/Observer | Passed для системного запрета | Observer ready=true; Windows сообщает locked, displays_off, disconnected. renderer=d3d11_direct2d_idle, без графической ошибки, частиц, слоёв или Present. За 250 мс запрет сохраняется; Worker штатно завершается, ID очереди обнуляется, Observer снимает ready |
| Полный активный Worker | Not run | worker_cycle=not_run_system_pause. Системные биты не очищались, активный цикл pause/clear/resume не достигнут |
| Нижний Layer/Gpu | Passed для создания и рендера в буфер | Настоящие D3D11/DXGI/Direct2D/DirectComposition, PMv2, HWND с производственными стилями, DPI=96 и соответствующий scale. В буфере 256×256 получено 245 пикселей с ненулевой alpha, остальная большая область прозрачна |
| Четыре настоящих Present | Статус получен, S_OK Not run | Каждый исходный HRESULT равен 0x087A0001 (DXGI_STATUS_OCCLUDED); счётчик S_OK остаётся 0. gpu_layer=rendered_present_status. Ошибки HRESULT нет |
| Жизненный цикл нижнего слоя | Passed | Флаги видимости меняются только на частном desktop; после Drop HWND больше не существует |

Снежинка в фикстуре имеет возраст 1 с: первый вариант с age=0 дал полностью прозрачный буфер из-за штатного 0.7-секундного появления. Исправлены входные данные теста, производственное появление не менялось. Первая строгая попытка активного Worker не достигла Present; добавленная диагностика выявила реальные системные причины. Эти попытки не засчитаны как прохождение активного пути.

probe_completed=true означает завершение диагностики, а не приёмку вывода. Положительный OCCLUDED сохранён исходным кодом; его нельзя заменить S_OK или доказательством показанного кадра. Документация DXGI описывает исключение для flip model; приведённый результат относится к наблюдаемой composition swap chain данного стенда и не обобщается на другие условия.

Итоговая release-проба завершилась с указанными выше фазами и штатным выходом ребёнка. Полный локальный набор Passed: fmt/clippy, 515 тестов клиента, 3 протокола и 8 повторных release-тестов — 526 выполнений; 8 ignored. Все восемь smoke сохранили эталонные отпечатки и прошли ограничения массы/пулов. Сборщики 35/31, JSON Schema 60, PHP 60+5, SQLite и HTTP прошли как проверка прежних компонентов; отложенная разработка сайта не возобновлялась. Новая аппаратная проба запускается отдельно от этих 526 выполнений.

Коммит d2ff7bd прошёл [GitHub CI](https://github.com/ydadev/snowflakes/actions/runs/43683692985): оба задания success. Декодированный Windows-журнал подтвердил 515 тестов клиента, 3 протокола и 8 release-повторов — 526 выполнений, 8 ignored; обе новые аппаратные точки действительно исключены. Этот CI не выполнял GPU-пробу и не подтверждает её активные фазы.

## Повторение

~~~powershell
cargo test -p snowflakes-client --release --locked --lib platform::weather::worker_probe::native_private_desktop_worker_and_layer_capability_probe -- --ignored --exact --nocapture --test-threads=1
.\tools\check.ps1
~~~

Результат печатается одной строкой private_worker_probe с фазами и числовыми подтверждениями. При чтении сначала проверять worker_cycle и gpu_layer. Если изменились состояние сеанса или доступность аппаратного пути, фиксировать новый результат отдельно; для полного Worker ожидается worker_cycle=passed. Для нижнего слоя gpu_layer=passed означает четыре S_OK, а не видимый DWM-кадр. Ошибки создания ресурсов и ошибка после их создания различаются.

Not run: видимое изображение и настоящий ввод, активный цикл Worker, фактический многомониторный вывод и разные DPI/WM_DPICHANGED, потери устройства и восстановление, ресурсы всего клиента, длительная устойчивость и полная матрица Windows 10/11. Одна снежинка и короткий прогон не подтверждают нагрузку снегопада/сугробов. Вода, сайт и поставка остаются отложенными; P1/P2/P3 и общая цель не завершены.

Продолжение на общем launcher: [настоящий Native/Weather/Layer при выборе экрана](TEST_RESULTS_NATIVE_LAYER_SELECTION.md). Его отдельный одноэкранный результат не меняет приведённые здесь границы Worker и видимого вывода.
