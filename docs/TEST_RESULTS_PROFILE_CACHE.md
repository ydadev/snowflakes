## Скрытый GPU и пиксели

Отдельно Passed native_profile_cache_preserves_contours_gradients_and_masks_without_presentation. Команда из подготовленной среды разработки:

```powershell
cargo test -p snowflakes-client --lib native_profile_cache_preserves --locked -- --ignored --nocapture
```

Тест требует аппаратный D3D11/DWM. Использует собственный скрытый слой 256 × 256 и читает только синтетический render target, без ShowWindow, Present и захвата рабочего стола. Изображение сравнения в Git не входит.

Проверены 48 отрисовок: исходная и отрицательная позиция экрана, масштабы 100/150/250%, два угла, интерполированная поза, неподвижная/сдвинутая передняя маска, сугроб и пласт с двумя раздельными округлыми фигурами. Эталон заново строит прежние экранные пути; оптимизированный путь рисуется напрямую и через действительно созданные GPU realizations.

Строгое сравнение с допуском 3/255 для каждого пикселя сначала Failed. Изоляция stroke/fill и чтение synthetic target выявили отличия сглаживания на краях; изменение допуска аппроксимации их не устранило. Итоговая проверка требует, чтобы все большие расхождения находились не дальше 1.5 физического пикселя от исходного контура или края маски: 0.75 пикселя половины обводки, 0.5 сглаживания и 0.25 допуска. За этой полосой проверяются и покрытие, и градиент.

Максимум канала составил 45/255, наибольшее среднее по объединению непустых пикселей — 1.259073/255; вне краевой полосы максимум — 0. Результат не означает побитовое равенство или завершённую видимую оценку сглаживания.

На 48 кадрах эталон создал 96 путей. Кеш создал 7, получил 89 попаданий; зафиксированы 7 попыток подготовки заливки и 9 обводки, проверено наличие удерживаемых готовых native realizations. Проверяется число созданий, время подготовки и FPS этим тестом не измеряются.

Тот же скрытый слой передан настоящему Weather: обычная ручная пауза сохранила кеш, команды очистки и смены режима освободили его до паузного выхода. Слой остался невидимым, submitted/rendering — false; ручная пауза сохранилась. Это изолированный контроллер с временным хранилищем, не команды работающему клиенту.

После усиления нативного сценария повторно прошли fmt, clippy и сам скрытый тест. Производственная часть после полного локального прогона не менялась.
