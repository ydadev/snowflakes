# Заливка и обводка графических профилей снега

Дата: 14 ноября 2026 года. База — 12b7287, решение — [ADR 0051](adr/0051-direct-fill-cached-stroke.md). Только снег P2/P3; рабочий эффект остаётся приостановленным.

## Среда и повторение

Windows 11 x64, Rust 1.99.1/MSVC. DXGI: VendorId 0x8086, DeviceId 0xA780, software=false, feature level 0xb000, UMD 32.0.101.7088. Эти сведения описывают один адаптер, не идентифицируют машину. Description/LUID и данные рабочего окружения не выводятся.

```powershell
cargo test -p snowflakes-client --lib native_profile_components_cost_without_presentation --release --locked -- --ignored --nocapture
cargo test -p snowflakes-client --lib native_profile_cache_preserves --release --locked -- --ignored --nocapture
```

Оба сценария явно запускаются и ignored по умолчанию. Измеритель использует прежние factory/screen-space пути как эталон и настоящий производственный render_snow на собственном скрытом target. ShowWindow, Present и команды работающему клиенту отсутствуют. Метод query/ограничений времени — [ADR 0050](adr/0050-hidden-profile-cost-experiment.md).

## Разделение стоимости

Первый опыт Passed за 28.62 с. Он указал на filled realization; затем рабочий путь заменён прямой заливкой с кешированной обводкой. После изменения запросов ресурсов итоговый опыт Passed за 27.16 с: 44 блока по 48 измеряемых кадров = 2112 кадров, 12 прогревочных перед каждым блоком. Все GPU-интервалы достоверны, каждый содержит pixel shading. JSON начинается с profile_components, schema_version=2; production_default отмечает новый рабочий вариант, allocation_policy=requested_components_only.

Проверяются 16/128 пластов по 24 ячейки и девять сугробов. Для всей фигуры используются пять вариантов: прежний рендер без кеша путей, кеш путей, только filled realization, только stroked realization и обе realizations. Порядок прямой и обратный даёт два повтора. Дополнительно три базовых варианта сравниваются для одной заливки и одной обводки. Предварительные пиксельные сравнения всех смешанных/раздельных вариантов прошли; между временными блоками bitmap не читается. Финальные отпечатки форм/поз совпали.

Ниже mean двух повторов в миллисекундах; значения разделены знаком /. CPU wall включает Direct2D/driver/возможные ожидания. GPU interval — прошедший интервал команд, не busy time. Размер target — 1280 × 720; сравнение не включает физику, IPC, трекер или DWM.

| Пласты / обе операции | CPU wall mean, мс | GPU interval mean, мс | Pixel shader, млн |
| --- | --- | --- | --- |
| 16 / прежние обе realizations | 0.480 / 0.402 | 1.015 / 1.007 | 0.659 |
| 16 / новая прямая заливка + stroked | 0.483 / 0.428 | 0.836 / 0.825 | 0.520 |
| 128 / прежние обе realizations | 4.489 / 4.118 | 4.319 / 4.327 | 3.263 |
| 128 / новая прямая заливка + stroked | 3.637 / 4.005 | 3.695 / 3.690 | 2.844 |

Для всей фигуры GPU-интервал снизился на 17.9%/14.6% при 16/128 пластах. CPU wall в небольшой сцене вырос примерно на 3.3%, в тяжёлой снизился на 11.2%. Это сравнение с прежним production-путём обеих realizations; оно не выдаётся за универсальный выигрыш или рост FPS.

Изоляция одной заливки показывает источник затрат:

| Пласты / заливка | GPU interval mean, мс | Входные примитивы, тыс. | Pixel shader, млн |
| --- | --- | --- | --- |
| 16 / кешированный прямой путь | 0.394 / 0.390 | 4.50 | 0.189 |
| 16 / filled realization | 0.604 / 0.603 | 11.15 | 0.327 |
| 128 / кешированный прямой путь | 1.499 / 1.500 | 19.33 | 1.187 |
| 128 / filled realization | 2.288 / 2.271 | 63.48 | 1.606 |

Native заливка увеличила GPU-интервал примерно на 54%/52%. Для обводки её кеш сохраняет пользу CPU в этих сценах; в тяжёлой сцене её GPU-интервал 2.204/2.192 мс против 2.342/2.337 мс прямого кешированного пути. Число примитивов само по себе не определяет стоимость: для stroked realization их больше, а интервал здесь меньше.

На новом полном пути после прогрева новых геометрий не было: 1200 попаданий на блок с 16 пластами, 6576 — со 128. Вызовов CreateFilledGeometryRealization — ноль; готовых stroked realizations — 25/137, по одной на форму. Это счётчики собственных ресурсов кеша, не всех внутренних выделений Direct2D. Удерживаемый кеш не превысил 137 записей и 77 336 условных точек. Старые режимы остаются в test-only измерителе для воспроизведения сравнения.

## Форма, качество и ресурсы

Полный tools/check.ps1 Passed: 339 тестов клиента (99 библиотечных), 3 protocol, 35 утверждений ресурсов и 31 кадров, fmt/clippy, release, baseline smoke модели и Ajv/PHP/SQLite/HTTP. Пять нативных сценариев исключены из обычного прогона; компонентный опыт и 96-кадровый oracle явно выполнены отдельно. После временного прогона production-часть не менялась; повторные измерения без новой причины не запускались.

Новый обычный тест stroke_only_policy_skips_fill_and_reduced_quality_without_losing_cached_strokes Passed: fill-builder не вызывается, 100 обращений без дополнительной обводки не создают GPU-ресурсы и не уничтожают прежнюю обводку, возврат прежней ширины использует её повторно.

Расширенный native_profile_cache_preserves_contours_gradients_and_masks_without_presentation Passed: 96 кадров с двумя уровнями детализации, 100/150/250%, двумя углами/положениями, интерполяцией и сдвинутой передней маской. Эталон строит 192 пути, кеш — 7, попаданий 185; native fill attempts=0, stroke attempts=9. Очистка и смена режима при ручной паузе освобождают ресурсы, слой остаётся невидимым.

Максимум канала — 9/255, наибольшее среднее по непустым пикселям — 0.345752/255, вне краевой полосы 1.5 px — 0. Прежний [48-кадровый результат](TEST_RESULTS_PROFILE_CACHE.md) имел максимум 45/255. Новый набор шире; побитовое совпадение не заявляется.
