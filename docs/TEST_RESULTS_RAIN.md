# Проверки дождя

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: первый шаг P4-01 и основа P4-04. Лужи, сток, рябь, курсор и испарение ещё не реализованы; P4 остаётся In progress.

Полный tools/check.ps1 Passed: 140 тестов клиента, 3 теста протокола, fmt, clippy с -D warnings, release, JSON Schema, PHP syntax, контракт, SQLite и HTTP. Девять новых сценариев находятся в rain, один — в нативном маршрутизаторе погоды.

| Проверка | Результат |
| --- | --- |
| Интенсивность | Passed: за 30 шагов при 0/25/50/100% получено 0/60/120/240 капель на 1920 DIP; при 200% DPI число совпадает |
| Распределение | Passed: первые 20 толщин, длин, предельных скоростей и объёмов совпадают при разных интенсивностях и DPI; частицы отличаются между собой |
| Контакты | Passed: быстрые капли пересекают несколько высот за шаг и попадают на первую открытую опору; объём передаётся ровно один раз |
| Перекрытие | Passed: закрытые передним окном и cloaked-границы не принимают дождь; капли продолжают путь до нижней опоры |
| Ветер и DPI | Passed: скорость плавно приближается к ветру; логические координаты и скорость при 100/200% совпадают, объём сохраняется |
| FPS и экономия | Passed: после 12 секунд при 60 FPS с полными брызгами и 30 FPS с экономией капли, контакты и объём совпадают; брызг меньше |
| Паузы | Passed: один экран сохраняет положения и возраст, второй продолжает работу; полная пауза и возобновление не создают долг дождя; переход в приостановленный экран ждёт на границе |
| Бюджеты | Passed: 4096 основных и не более 768 вторичных частиц; насыщение учитывает подавленные капли; интенсивность 0 не воспроизводит их позже, брызги истекают |
| Геометрия и очистка | Passed: контакт следует за текущей высотой плавной опоры и пересекает границу индекса; очистка и удаление экрана сохраняют баланс принятого объёма |
| Переключение режима | Passed: снег → дождь → снег и очистка удаляют оба вида частиц; повторный кадр на паузе сохраняет счётчик; тест не создаёт слои и не снимает ручную паузу |

Первый полный прогон остановился на требовании clippy размещать тестовый модуль после остальных элементов файла. Модуль перемещён, повторный полный прогон Passed.

Нативная проверка переключения использует собственный Tracker и временный профиль, не создаёт видимых окон погоды и не посылает команды действующему экземпляру. Путь draw_rain проверен компиляцией; тесты модели не подтверждают внешний вид GPU-отрисовки.

Not run: визуальное восприятие штрихов и брызг, фактические 30/60 FPS, CPU/GPU, несколько реальных DPI/экранов, горячее подключение и Windows 10. Лужи и полный водный баланс, включая поступление при насыщении основного бюджета, Not implemented. Регулятор размера луж пока сохраняет предпочтение для следующего этапа.
