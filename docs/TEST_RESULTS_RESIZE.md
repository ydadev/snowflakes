# Снег при изменении ширины окна

Дата: 14 ноября 2026 года. Среда: Windows 11 x64, Rust 1.99.1/MSVC. База — 6c48f90, решение — [ADR 0052](adr/0052-window-resize-snow.md). Входы — синтетические Scene/Window; native окна не создаются.

## Результат и повторение

```powershell
cargo test -p snowflakes-client --test resize --locked
```

Все 13 сценариев Passed. Полный итоговый tools/check.ps1 также Passed: 352 теста клиента (99 библиотечных, 19 control, 5 global_budget, 7 interpolation, 6 IPC, 9 rain, 13 resize, 11 scene, 22 session, 122 snow, 22 storage, 11 UI, 6 example), 3 protocol, 35 утверждений ресурсов и 31 кадров. Прошли fmt/clippy, release, baseline smoke модели, Ajv/PHP/SQLite/HTTP. Пять прежних нативных сценариев остаются ignored в обычном прогоне.

Коммит fafc97e прошёл [GitHub CI](https://github.com/ydadev/snowflakes/actions/runs/43575447975): Windows — 4 мин 1 с, contract-and-php — 29 с. Логи подтвердили все 13 новых сценариев и итоговые 352 теста клиента, а также сбор ресурсов/кадров в PowerShell 7 и 5.1. Это автоматическая проверка исходников, без видимого эффекта.

Для IPC/WTS использован обычный Windows-контекст; ограниченный запуск получил Access denied в трёх проверках. Совместимый прогон вне песочницы Passed, как и итоговый полный набор. Это не запуск эффекта на рабочем столе.

После временного исключения origins из обоих поисков контакта сценарий 1100 срезов получил Failed с возвратом уплотнённого снега на живой источник. Изменение восстановлено в finally; исходные защиты и весь набор повторно Passed. Это контроль чувствительности теста, не отдельный дефект опубликованной версии.

Погрешность баланса introduced − removed − total проверяется на каждом физическом шаге и обновлении стрессовой сцены с пределом 0.1%. Плотность и переданные объёмы проверены существенно точнее. После оседания возможны несколько ULP f32, явно учтённые как outflow: наблюдалось около 3.8e-6; тест частот ограничивает их значением менее 0.001. Предел active/queue не изменяется и не подменяется удалением снега при насыщении.

## Границы

| Проверка | Результат | Причина |
| --- | --- | --- |
| Настоящее перетаскивание границ, внешний вид среза и задержка | Not run | Рабочий эффект не возобновляется, CUA остановлена |
| Windows 10, несколько настоящих DPI, произвольные одновременные рамки/DPI | Not run | Проверены модели и прежние регрессии DPI; native матрица не выполнена |
| CPU/GPU/память и длительный поток resize | Not run | Ограниченный модельный стресс не заменяет ресурсный прогон клиента |
| Полная приёмка GE-03/P3 | Not run | Нативные и крайние последовательности остаются открытыми |

Обычная смена DPI сохраняет отдельный пересчёт единиц из ADR 0035. Нижняя опора, интерфейс, сервер и поставка этим исправлением не меняются. Дождь/лужи остаются отложенными; текущий клиент вручную приостановлен.
