# Проверки сборщика ресурсов

Дата: 13 ноября 2026 года. Среда: Windows 11 x64, PowerShell 7.6.9 и Windows PowerShell 5.1. Область: сбор CPU, памяти, GPU и состояния для P2/P3; дождь/лужи Deferred.

Добавлен внешний необязательный сборщик tools/measure-resources.ps1, отдельный модуль вычислений и небольшой C#-помощник PDH. Код и поведение снеговой модели не менялись. Сборщик подключён к tools/check.ps1 и Windows CI.

Полный tools/check.ps1 Passed: 203 теста клиента, 3 теста протокола, 33 проверки сборщика, fmt/clippy/release, JSON Schema и PHP/SQLite/HTTP. Те же 33 проверки прошли отдельно в PowerShell 5.1; короткий двухсекундный сбор в нём тоже завершился с доступными GPU-счётчиками. Стандартная политика сначала запретила скрипты; повторение использовало RemoteSigned только в отдельном тестовом процессе, постоянные политики не менялись. Оба варианта PowerShell включены в CI.

## Автоматические проверки

tools/test-resources.ps1 проверяет нормализацию CPU по всем логическим процессорам; отрицательный/нулевой интервал; максимум GPU engine вместо суммы; сумму памяти адаптеров; действительный ноль и отсутствие данных; отрицательные, NaN и слишком большие проценты; удаление посторонних полей из профиля; соответствие сценария текущему состоянию; взвешенное среднее и покрытие GPU; изменение private bytes; отсутствие выдуманного FPS; файловый предел и резерв summary; нативное число CPU; отказ отсутствующего счётчика; запрет относительного/drive-relative пути и сохранность существующего файла через отдельные CLI-процессы.

Отдельная регрессия проверяет дробное ожидание: 0,25 секунды даёт 250 мс, а положительный остаток менее миллисекунды — 1 мс. Первый минутный прогон обнаружил активный опрос последних долей секунды из-за выбора целочисленной перегрузки Math.Min; вычисление переведено на double и покрыто проверкой. Также начало CPU-окна и повторный PDH baseline вынесены за прогрев.

## Проверка записи

Короткий локальный прогон подтвердил чтение доступных нулевых GPU-отсчётов, committed memory и запись законченного NDJSON. Недоступность времени защищённого DWM сначала мешала запуску; зависимость от него удалена, отдельно читается только GPU DWM нужного сеанса.

Повторный минутный сбор завершился с reason=completed: 58 отсчётов, покрытие CPU/GPU 60,007 секунды, все три GPU-показателя доступны в 58 отсчётах, обнаруженных изменений состояния нет. Сбор выполнялся только на уже приостановленном экземпляре. Он проверяет работоспособность сбора, а не базовый стенд ТЗ. Сырые аппаратные сведения, параметры действующего экземпляра и файлы измерения остаются локально вне Git. Новая графика не запускалась, ручная пауза сохранена.

## Повторение

~~~powershell
.\tools\test-resources.ps1
$clientExe = (Resolve-Path .\target\release\snowflakes.exe).Path
$outputPath = Join-Path $PWD '.local/resources.ndjson'
.\tools\measure-resources.ps1 -ClientExe $clientExe -OutputPath $outputPath -Scenario paused -Seconds 60
~~~

Требуются уже запущенный клиент текущего пользователя/сеанса и отсутствующий выходной файл. Сценарий не включает и не выключает эффект. [Порядок и формат](RESOURCE_COLLECTION.md), [ADR 0028](adr/0028-resource-collection.md).
