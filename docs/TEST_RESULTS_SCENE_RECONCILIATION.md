# Повтор периодической сверки сцены

Дата: 15 ноября 2026 года. Клиент 0.1.0, Rust 1.99.1/MSVC, Windows x64. Область: P2-02/04 и OS-03. [Решение](adr/0079-retry-periodic-reconciliation.md).

## Воспроизведение

Начальный снимок получен в 0 мс. Затем без WinEvent изменены прямоугольник окна и нижняя опора дисплея. Периодическая попытка в 1000 мс получает ошибку order либо screens; в 1100 мс выполняется обычный повтор порядка Tracker.

Оба регрессионных теста до исправления Failed: возвращались прежние Rect и floor=600 вместо изменённых Rect и floor=580. После исправления повтор получает оба новых значения; стабильное окно сохраняет свой ключ. Следующая периодическая сверка приходится на 2100 мс, а не на 2000 мс.

## Автоматические сценарии

Добавлены четыре теста: три scene_registry и один библиотечный сценарий Tracker.

| Проверка | Подтверждение |
| --- | --- |
| Ошибка порядка | Полная геометрия и дисплеи перечитаны при первом успешном повторе; поколение сохранено |
| Ошибка дисплеев | Успешное чтение порядка до ошибки не завершает полную сверку; повтор обновляет оба вида данных |
| Destroy и overflow | Две последовательные ошибки не расходуют изменения и не читают геометрию; успешная полная сверка сбрасывает ненадёжные поколения обоих окон |
| Tracker | Оба вида ошибки переводят сцену в ожидание; до 100 мс источник не вызывается; после второй ошибки готовность возвращается только с новой геометрией/опорой, следующий полный опрос — спустя секунду |

Целевые проверки Passed: 24 сценария scene_registry и два сценария Tracker. Полный локальный набор Passed: 503 теста клиента и 3 протокола; 5 ignored. Дополнительно повторены 8 release-тестов снега — всего 514 выполнений Rust. fmt/clippy и release-сборка Passed. Восемь smoke модели сохранили прежние отпечатки, массу и ограничения пула. Сборщики: 35/31 проверка; JSON Schema: 60; PHP: 60 общих + 5 транспортных, SQLite и HTTP Passed. Это регрессионная проверка существующих компонентов; новые работы по воде/сайту не выполнялись.

## Повторение и предел доказательства

~~~powershell
cargo test -p snowflakes-client --locked --test scene_registry
cargo test -p snowflakes-client --locked --lib platform::scene::tests::
.\tools\check.ps1
~~~

Тесты проверяют производственные Registry и Tracker с подставным Source и управляемым временем. Они не вызывают настоящие ошибки Win32 и не заменяют нативную матрицу. Геометрия отдельных недоступных окон исключается как прежде. Ошибки сцены не расходуют бюджет восстановления GPU; прежние тесты сохранены. Физика и рисование снега не менялись.

Not run: Windows 10/11 с настоящими пропущенными событиями, массовой сменой окон, Shell/автоскрытием, видимым возвратом кадра после ошибки, реальным вводом, ресурсами всего клиента и длительным прогоном. P2/P3 остаются In progress. Разработка дождя и луж отложена; рабочий снег не возобновляется.
