# Проверки первой реализации снега

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. P1–P3 остаются In progress.

## Автоматические проверки

Полный tools/check.ps1 прошёл: fmt, clippy с -D warnings, 77 тестов клиента, 3 теста протокола, release-сборка, Ajv, PHP syntax, SQLite и HTTP. Контракт v2 проходит 60 общих случаев и 5 дополнительных лексических проверок Rust/PHP.

## Запуск Windows

Debug и release создали D3D11/Direct2D/DirectComposition-слой; статус подтверждал rendering=true. После выбора all release сообщил monitor_count=2: это число слоёв, помеченных видимыми, а не полная приёмка нескольких мониторов. Физический вид оценён как подходящий базовый вариант 100%. Отдельный местный профиль и изменения настроек сохранились при переходе на новую сборку.

Управление окнами через инструмент остановлено Esc. Полный повторный интерактивный прогон шести регуляторов, взаимодействий и последнего исправления сугроба не засчитан; исправление проверено регрессиями и сборкой. Снимки рабочего окружения в Git не включались.

## Не проверено

Not run: Windows 10, смешанный DPI, hotplug, настоящее восстановление после device lost, длительный прогон и показатели базового стенда ТЗ. Остаются доработки инкрементального трекера, масок системных меню, ручной проверки инерции окна, паузы физики по отдельному монитору, блокировки/сна и стабильных monitor_ids.

Дождь, HTTP-синхронизация, готовый сайт и поставка ещё не подключены. Общая цель активна. CI и аудит публикации этого шага записываются после отправки коммита.
