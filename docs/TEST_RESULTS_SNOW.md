# Проверки физического снега

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. P1–P3 остаются In progress.

## Автоматические проверки

Полный tools/check.ps1 прошёл: fmt, clippy с -D warnings, 90 тестов клиента, 3 теста протокола, release-сборка, Ajv, PHP syntax, SQLite и HTTP. Контракт v2 проходит 60 общих случаев и 5 дополнительных лексических проверок Rust/PHP.

| Область | Результат |
| --- | --- |
| Полёт | Passed: гравитация, предельная скорость, зависимость от массы и плавная реакция скорости на изменение ветра |
| Время | Passed: совпадение физического состояния при показе 30 и 60 кадров/с |
| Контакт | Passed: пересечение отрезка с опорой, масса поступает только от столкнувшейся частицы |
| Поверхности | Passed на модели: перекрытие, края монитора, перенос/изменение ширины, исчезновение и новая идентичность окна |
| Накопление | Passed: учёт полётной, рыхлой, осевшей и вышедшей массы; ограничение количества частиц |

| Заметность | Passed: изменение не меняет физическое состояние или баланс массы |

| Устойчивость | Passed: очень лёгкие фрагменты сохраняют устойчивое сопротивление при сильном ветре |

24 сценария снега включают регрессию повторной тряски: слишком большой радиус при малой массе сначала дал Failed, после исправления — Passed. Проверяется падение видимых фрагментов в неподвижном воздухе. Три сценария пластов подтверждают исходный профиль, массу, независимость от размера снежинок, контакт нижнего контура, распад и оседание. Решение: [ADR 0010](adr/0010-falling-snow-slabs.md).

Инкрементальный реестр проходит 9 сценариев из [ADR 0009](adr/0009-incremental-window-registry.md): объединение событий, число запросов, поколения, порядок и видимость, потеря событий и восстановление. Это проверка модели источника геометрии, не приёмка реальных WinEvent и не измерение производительности.

## Запуск Windows

Debug и release создали D3D11/Direct2D/DirectComposition-слой; статус подтверждал rendering=true. После выбора all release сообщил monitor_count=2: это число слоёв, помеченных видимыми, а не полная приёмка нескольких мониторов. Физический вид оценён как подходящий базовый вариант 100%. Отдельный местный профиль и изменения настроек сохранились при переходе на новую сборку.

Управление окнами через инструмент остановлено Esc. Полный повторный интерактивный прогон шести регуляторов, взаимодействий и последнего исправления сугроба не засчитан; исправление проверено регрессиями и сборкой. Снимки рабочего окружения в Git не включались.

## Не проверено

Not run: Windows 10, смешанный DPI, hotplug, настоящее восстановление после device lost, длительный прогон и показатели базового стенда ТЗ. Остаются проверка нативных уведомлений реестра, доработка масок системных меню и нижней опоры, ручная проверка инерции и пластов, пауза физики по отдельному монитору, блокировка/сон и стабильные monitor_ids.

Дождь, HTTP-синхронизация, готовый сайт и поставка ещё не подключены. Общая цель активна.
