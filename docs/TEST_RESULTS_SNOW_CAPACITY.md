# Проверки предела при оседании снега

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P3-02/04, SN-04/09. Активна разработка снега; P4 отложен.

Полный tools/check.ps1 Passed: 182 теста клиента, 3 теста протокола, fmt, clippy с -D warnings, release, JSON Schema, PHP syntax, контракт, SQLite и HTTP. Добавлены шесть сценариев snow; всего 79 сценариев снега/геометрии.

Коммит c19cfc6 прошёл [GitHub CI](https://github.com/ydadev/snowflakes/actions/runs/43460557634): Windows и contract-and-php.

Аудит сверил 119 опубликованных файлов по blob SHA и HEAD, проверил историю, метаданные и отсутствие частных значений. Все 206 местных Markdown-ссылок действительны; рабочие настройки, журналы и изображения не публиковались.

Прежние сценарии симметрии сугроба, плавного уменьшения размера, смахивания, масок, пауз, пластов, осыпания и бюджетов прошли. Новая регрессия проверяет и положительный перенос, поэтому простое отключение relax её не удовлетворяет. Общий лимит притока не достигается удалением материала.

Not run: видимое оседание около настоящих окон и панелей, смешанный DPI на физических мониторах, Windows 10, замеры CPU/GPU и длительный прогон. Существующий избыток после пользовательского уменьшения размера может сохраняться на время принятого плавного перехода; проверка не подменяет его мгновенным обрезанием. Рабочий эффект для этого этапа не запускался.
