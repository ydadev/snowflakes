# Проверки осыпания с края окна

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P3-03/04, SN-04, маски, паузы и бюджеты. P2/P3 остаются In progress; P4 отложен.

Полный tools/check.ps1 Passed: 166 тестов клиента, 3 теста протокола, fmt, clippy с -D warnings, release, JSON Schema, PHP syntax, контракт, SQLite и HTTP. Добавлены девять сценариев snow.

Коммит 1628ffb прошёл [GitHub CI](https://github.com/ydadev/snowflakes/actions/runs/43453897318): Windows и contract-and-php. Аудит сверил 115 файлов с опубликованными blob SHA и HEAD; 186 местных Markdown-ссылок действительны, частные значения и рабочие артефакты не опубликованы.

| Проверка | Результат |
| --- | --- |
| Неподвижная кромка | Passed: высокая кромка теряет материал, появляются связные тела с исходной опорой в skip_support; после падения масса пополняет нижний сугроб |
| Устойчивый снег | Passed: низкая кромка 5 DIP сохраняет массу и не создаёт тела; прежняя проверка плавного движения окна проходит |
| Узкое перекрытие | Passed: обе крайние полосы закрыты препятствиями шириной 0,5 пикселя; видимые углы не позволяют выпустить скрытый кусок. Соседние свободные полосы принимаются как единая открытая область |
| Паузы | Passed: кромка одного экрана остаётся неизменной, другая осыпается; направление за границу окна в приостановленный экран удерживает материал |
| FPS и сцена | Passed: после пяти секунд при 30/60 FPS совпадают тела, их контуры, положения, скорости и профиль накопления при периодических снимках сцены |
| Полный бюджет частиц | Passed: снег остаётся на кромке при 2400 занятых местах; после освобождения места отделяются связные куски |
| 256 опор | Passed: все окна обслужены, прирост видимых тел не более восьми за шаг и общий предел соблюдён; последние ключи не голодают |
| Переполненная очередь | Passed: закрытие очень широкой опоры сохраняет 128 существующих связных тел; непредставимый остаток учитывается в стоке, баланс сохраняется. Это не принятие полного визуального представления всей сброшенной массы |
| Синтетический DPI | Passed: 100/200/400% используют логические размеры, не более 12 ячеек; масса кусков различается менее чем на 5% из-за дискретизации и соответствует их профилю |
| Пространственный индекс | Passed: столкновения работают на синтетическом рабочем столе с отрицательными координатами и шириной 80 000 пикселей, на границах столбцов и после переноса опоры |

Первый прогон 62 сценариев snow занял 73,62 с. После добавления горизонтального индекса тот же набор прошёл за 1,87 с; итоговый набор из 63 сценариев — за 1,88 с. Это единичные наблюдения времени debug-тестов без сборки, а не принятый замер CPU/GPU или FPS продукта. Сценарий с 256 окнами не был сокращён ради ускорения.

В новом тесте индекса исходная позиция частицы сначала не пересекала опору за один шаг из-за существующего ограничения скорости снежинок 160 DIP/с. Положение тестового тела скорректировано; физическое ограничение не менялось.

Not run: видимое поведение отделения/приземления, реальные окна и панели, смешанный DPI, Windows 10 и измерения производительности. Скрытые пласты при закрытии и ёмкость после relax остаются открытыми пунктами [матрицы](SNOW_REQUIREMENTS.md). Рабочий эффект для этого этапа не запускался.
