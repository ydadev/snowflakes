# Проверки уменьшения лимита и интенсивности снега

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P3-02/04, CT-02/03/06/07 и независимые паузы. P2/P3 остаются In progress; P4 отложен.

Полный tools/check.ps1 Passed: 157 тестов клиента, 3 теста протокола, fmt, clippy с -D warnings, release, JSON Schema, PHP syntax, контракт, SQLite и HTTP. Добавлены пять сценариев snow; остальные прошли как регрессии.

| Проверка | Результат |
| --- | --- |
| Малое уменьшение | Failed на прежнем коде: избыток при 100 → 99% исчезал до середины перехода; после исправления Passed — через секунду остаётся около половины избытка, за 2,5 с достигается цель |
| Обе опоры | Passed: проверены пределы 120 DIP у нижней поверхности и 32 DIP на окне |
| Снимок и resize | Passed: периодическая пересборка сцены и сужение окна в ходе перехода не перезапускают срок; к концу новый предел соблюдается |
| Паузы | Passed: один экран сохраняет профиль, другой завершает переход; возобновление начинает отсчёт активного времени своей области |
| Возврат размера | Passed: увеличение лимита останавливает удаление, сохраняя массу без нового материала |
| Ожидающая масса/FPS/DPI | Passed: осевшая и ожидающая масса учитываются вместе; профили при 30/60 FPS совпадают на синтетических 100/200%; после 2,5 с предел соблюдается |
| Баланс | Passed: исчезающий избыток учитывается в removed_mass; уменьшение не создаёт новые частицы |
| Частота осадков | Passed: 25/50/100% на 1920 DIP при синтетических 100/200% дают ожидаемую частоту 0,65 × интенсивность частиц/с с погрешностью не более одной частицы за 4 секунды до насыщения |
| Интенсивность 0 | Passed: после выключения эмиссии introduced_mass не увеличивается, существующие частицы продолжают физические шаги |

Not run: видимая оценка перехода, реальный ввод и задержки, Windows 10, реальные DPI/hotplug и измерения производительности. Пять сценариев не закрывают все требования SN/CT; конкретные остатки перечислены в [матрице](SNOW_REQUIREMENTS.md).
