# Проверки местных переключателей снега

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P2-01/03, P3-03/04, SN-07/08/10 и CT-08. Этапы P2/P3 остаются In progress; P4 отложен.

Полный tools/check.ps1 Passed: 146 тестов клиента, 3 теста протокола, fmt, clippy с -D warnings, release, JSON Schema, PHP syntax, контракт, SQLite и HTTP. Добавлено шесть сценариев: четыре в snow, по одному в control и ui. Существующие проверки скрытой панели и IPC расширены.

| Проверка | Результат |
| --- | --- |
| Плавное выключение | Failed на прежнем коде: малый сугроб исчезал до середины перехода; после исправления Passed — на первой секунде остаётся около половины, за 2,5 с остаток исчезает |
| Ожидающая масса | Passed: осевшая и ещё не осевшая масса убывают постепенно; баланс массы сохраняется |
| Независимые опоры | Passed: выключение снега на окнах сохраняет нижнее накопление; выключение нижнего накопления и размер 0 используют плавный переход |
| Пауза и сцена | Passed: один экран сохраняет массу, другой завершает удаление; периодический снимок сцены не начинает переход заново |
| Возврат и размер окна | Passed: повторное включение останавливает удаление; изменение числа ячеек переносит состояние и не перезапускает исчезновение |
| FPS и другие флаги | Passed: промежуточный профиль при 30/60 FPS совпадает; отключённый курсор не снимает снег, отдельное таяние уменьшает массу; включённый курсор снова смахивает |
| Хранение | Passed: четыре независимых флага сохраняются и перечитываются; ошибка записи сохраняет старый профиль; серверный режим отклоняет местную команду |
| Очередь и панель | Passed: частые изменения объединяются независимо; скрытые Win32-галочки передают команды и сохраняют новый вид до подтверждения; ID всех контролов уникальны |
| IPC и пауза | Passed: команды проходят через отдельный headless-процесс, значения применяются при ручной паузе, пауза остаётся включённой |

Нативная проверка нашла пересечение двух новых ID с существующими подписями панели; ID исправлены, проверка уникальности добавлена. Первый полный прогон также выявил незаключённый в unsafe вызов Win32 в тесте; исправлено. В новом сценарии курсора первоначально ожидалось появление частиц в том же шаге, хотя существующая очередь выдаёт их на следующем; исправлено ожидание, механика смахивания не менялась.

Not run: видимая панель, клавиатурный обход и масштабирование нового блока на реальном рабочем столе, визуальная оценка удаления, Windows 10 и измерения производительности. Скрытые контролы не заменяют эти проверки. Новая сборка не запускает рабочий эффект; его ручная пауза сохраняется.
