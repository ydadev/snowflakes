# Проверки пресетов, ветра и непрозрачности снега

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P2-01/03 и P3-04, SN-02, CT-01/11/13. P2/P3 остаются In progress; дождь и лужи отложены.

Полный tools/check.ps1 Passed: 152 теста клиента, 3 теста протокола, fmt, clippy с -D warnings, release, JSON Schema, PHP syntax, контракт, SQLite и HTTP. Добавлены шесть сценариев: два в control, по одному в storage, ui, snow и скрытой нативной панели. IPC-проверка расширена.

| Проверка | Результат |
| --- | --- |
| Состав пресетов | Passed: light/normal/heavy устанавливают 20/50/85%; весь остальной профиль, включая ветер и непрозрачность, совпадает с исходным |
| Свои настройки | Passed: ручное изменение переводит название в custom; ручные 20% не распознаются автоматически как «Лёгкий» |
| Источник и режим | Passed: серверный режим отклоняет местную команду и скрывает местную метку в status; пресет снега отклоняется в режиме rain; переключение источника сохраняет местное состояние |
| Политика | Passed: сохранённые 85% остаются в профиле при эффективных 25%; выбранное название сохраняется |
| Ошибка записи | Passed: невозможность сохранения оставляет прежние погоду и метку |
| Совместимость TOML | Passed: старый файл без поля принимается как custom; действующий выбор переживает запись/чтение; неизвестное имя и несогласованная интенсивность восстанавливаются без изменения погоды |
| Очередь | Passed: пресет образует границу объединения; последовательность ручного значения, light и custom сохраняет применённые 20% |
| Нативные регуляторы | Passed: trackbar передаёт −100/100/−45 для ветра и 10/100/63 для непрозрачности; старый снимок не перезаписывает ожидающий ввод |
| Нативный пресет | Passed: выбор «Сильный» сохраняет 85% при ограничении 25%; изменение ветра возвращает «Свои настройки»; серверный источник выключает поля |
| Прозрачность и физика | Passed: при 10% и 100% совпадают положения/скорости частиц, осевшая и ожидающая масса, общий баланс |
| IPC и пауза | Passed: отдельный headless-процесс применяет normal=50%, сообщает имя и сохраняет ручную паузу |

Скрытые Win32-контролы не создают видимую панель и не управляют действующим экземпляром. Графический эффект для проверки не включался. Дождевые пресеты не реализовывались; существующие проверки дождя проходят как регрессии общего клиента.

Not run: видимая компоновка, управление клавиатурой и реальное масштабирование нового блока, восприятие ветра/непрозрачности на нескольких экранах, Windows 10, производительность. Полная приёмка SN/CT не заменяется этим набором.
