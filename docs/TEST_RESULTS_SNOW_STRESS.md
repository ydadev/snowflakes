# Проверка непрерывного поступления снега и смены экранов

Дата: 13 ноября 2026 года. Область: P2-04, P3-03/04, SN-06. Windows 11, Rust 1.99.1/MSVC x64. Дождь и лужи Deferred.

Добавлен [continuous_roof_inflow_survives_monitor_pauses_and_disconnects](../crates/snowflakes-client/tests/snow.rs). Это проверка модели без окон рабочего стола, графики и запуска эффекта. Поведение продукта не менялось.

## Условия

Два синтетических экрана по 800 × 600 DIP, масштаб 100% или 200%. Исходный снег на двух крышах отделяется обычным закрытием опор. Полученные пласты копируются через World::release до заполнения всех 4800 активных мест: весь исходный пул занят пластами, обычных летящих снежинок нет. Искусственное заполнение нужно для воспроизводимой перегрузки; это не запись пользовательской работы.

Далее каждые 15 физических шагов на каждом подключённом экране создаётся и закрывается крыша шириной 300 DIP со слоем 2 DIP. Профиль задаётся непосредственно, с учётом массы в introduced_mass; проверяется выпуск уже накопленного снега отдельно от генерации снегопада. Интенсивность осадков равна 0, таяние выключено.

| Интервал модельных часов | Экраны и пауза |
| --- | --- |
| 0–10 с | Два экрана, первый на паузе |
| 10–20 с | Два экрана, второй на паузе |
| 20–25 с | Второй экран отключён, первый активен |
| 25–30 с | Оба экрана отключены, шаг не продвигает материал |
| 30–32 с | Оба экрана подключены и приостановлены |
| 32–40 с | Оба активны |
| 40–50 с | Первый на паузе |
| 50–70 с | Оба активны, поступление прекращено |

Всего 4200 возможностей фиксированного шага 1/60 с и 340 закрытий на каждом масштабе. Пауза замораживает соответствующий материал; 70 секунд модельных часов не означают 70 секунд активной физики для каждого тела или измерение реального времени.

## Результат

Passed при 100% и 200%:

- очередь достигла 128 записей и не превысила предел;
- занятость активного пула перед шагом достигала текущей цели допуска на 127 и 135 шагах соответственно;
- уменьшение числа экранов не даёт новых тел сверх большего из прежнего количества и новой цели допуска; общий максимум — 4800;
- при общей паузе и отсутствии экранов не меняются масса, количество, положения, скорости, возраст, углы и вращение активных тел;
- баланс introduced_mass − removed_mass − total_mass проверяется каждые 15 шагов и в конце с допуском 0,1%; явный сток учитывается отдельно;
- число опор/ячеек ограничено, активные массы и координаты конечны, профиль пласта содержит до 16 конечных неотрицательных высот;
- после заключительного интервала активных экранов очередь и летящие тела пусты; на нижних опорах есть снег;
- маски источников, выбранных из активных тел каждые 15 шагов, после завершения больше не возвращаются через falling_clips.

Не утверждается, что вся исходная масса должна остаться на полу: отключение экрана, выход за границы и ограничения накопления имеют явный сток. Проверяется полный баланс с этим стоком.

Полный tools/check.ps1: 220 тестов клиента, включая 97 в snow, 3 теста протокола, 33 проверки ресурсов, 31 проверка кадров, fmt/clippy/release и существующие проверки JSON Schema/PHP/SQLite/HTTP. Аппаратный тест кадров исключён из обычного прогона.

Коммит 4fc9a13 прошёл [GitHub CI](https://github.com/ydadev/snowflakes/actions/runs/43502854088): Windows, инструменты в PowerShell 7/5.1, release и contract-and-php. Аудит сверил 144 файла с GitHub по blob SHA и HEAD; история, метаданные и отсутствие частных значений проверены, все 300 местных Markdown-ссылок действительны.

## Границы подтверждения

Это конечный поток с начальным насыщением и последующим освобождением мест, а не непрерывно заполненный пул при неограниченном поступлении. Универсальный срок ожидания пластов не доказан. Проверка 20-секундного заключительного интервала не является обещанием такой задержки пользователю.

Not run: видимый результат, настоящее отключение дисплеев, смешанный DPI, Windows 10, CT-10, CPU/GPU/память и восьмичасовой прогон. Рабочий эффект и интерактивная автоматизация не запускались.
