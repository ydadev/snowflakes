# Проверки пустот в падающих пластах

Дата: 14 ноября 2026 года. Windows 11, Rust 1.99.1/MSVC x64. P3-02/03/04, частичное покрытие SN-06/GE-09. Активны только снег и его основа.

Исправлены ложные контакты/обводка через пустые ячейки укрупнённого профиля и выбор недоступного центра оседания. Решение: [ADR 0036](adr/0036-disconnected-snow-contours.md).

## Регрессии

| Проверка | До исправления | После |
| --- | --- | --- |
| sparse_snow_contours_exclude_empty_regions | Failed: два островка соединялись одной фигурой | Passed: отдельные контуры внутри занятых диапазонов; пустой/нулевой профиль не имеет фигур, чередование 16 ячеек даёт восемь |
| sparse_snow_does_not_land_through_its_empty_gap | Failed: пустота над узкой нижней опорой осаждала около 160 единиц массы | Passed: горки нет, материал за пределами оставшегося экрана учитывается как выход из сцены |
| sparse_snow_uses_a_free_impact_when_its_center_is_covered | Failed: свободный контакт терял материал из-за перекрытого центра | Passed: около 160 единиц оседает возле доступного удара; числовой остаток выхода меньше 0,0001 |
| sparse_snow_mound_uses_an_active_impact_instead_of_a_paused_center | Failed: горка смещалась к границе паузы около x=800 | Passed: центр осевшей массы x>950 при ударе около x=1000; приостановленные ячейки пусты, масса сохранена |
| sparse_snow_partial_monitor_return_cannot_create_a_central_mound | Failed: снег с удалённых внешних экранов создавал около 168 единиц на пустом центральном | Passed: центральная опора пуста, очередь опустела, материал вне экранов учтён в балансе |

Последний сценарий использует 66 синтетических экранов, чтобы сжатие очереди при сохранении только центрального экрана объединило раздельные источники. Это нагрузочный вход модели, не конфигурация нативного стенда. На 65 внешних экранах находятся по две опоры разных классов видимости. После закрытия на паузе очередь содержит не менее 130 записей; сокращение состава экранов ограничивает её до 128. Два объединённых тела имеют центр над центральным экраном, но материал лежит по сторонам от него. После возобновления выполняются 300 физических шагов. Варианты: DPI 100/200%, с узкой несобирающей панелью и без неё. Проверяются масса, отсутствие ложной горки и завершение очереди, а не универсальная локальность укрупнения.

~~~text
cargo test -p snowflakes-client --lib sparse_snow --locked
cargo test -p snowflakes-client --test snow sparse_snow --locked
~~~

Полный tools/check.ps1 Passed: 247 тестов клиента, включая 117 в snow и 42 модульных, 3 теста протокола, 33 проверки ресурсов, 31 проверка кадров, fmt/clippy/release, Ajv и PHP/SQLite/HTTP. Один аппаратный тест кадров исключён из обычного прогона. Отдельная release-сборка подготовлена для проверки; чтение статуса существующего клиента подтвердило ручную паузу и rendering=false.

## Открытая приёмка

Not run: видимая отрисовка раздельных фигур и масок, настоящее отключение/перестановка дисплеев, Windows 10, CT-10, ресурсы и длительный прогон. Успешные тесты модели не подтверждают эти пункты. Дальняя геометрия и распределение по высоте при укрупнении остаются приближёнными.

Рабочий эффект не включался и не перезапускался. Интерактивная автоматизация не возобновлялась. P2/P3 и полный проект остаются In progress; дождь, сайт и поставка отложены.
