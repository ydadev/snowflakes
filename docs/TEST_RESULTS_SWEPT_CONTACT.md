# Проверки пересечения снежной поверхности

Дата: 14 ноября 2026 года. Windows 11 x64, Rust 1.99.1/MSVC. P3-02/04. [Решение](adr/0042-swept-snow-contact.md).

## Воспроизведение

До изменения три новых теста Failed:

- Кромка x=[26,114), y=300; сегмент (90,290) → (130,310) пересекает её при t=0,5, x=110. Конечный столбец не содержал опору.
- Кромка открыта только на x=[110,75;111,75). Сегмент (110;299,5) → (113;300,5) пересекает открытый x=111,5, но заканчивается под перекрытием.
- У соседних ячеек высоты 6 и 0. Падающая точка пересекает верх первой, затем оказывается над второй; прежний поиск брал только высоту второй.

Локальный повтор: cargo test -p snowflakes-client --lib swept_contact_. После исправления все восемь Passed.

## Общая проверка

Полный tools/check.ps1 Passed: 274 теста клиента, включая 59 модульных, 122 сценария snow и 5 проверок примера; 3 теста протокола, 33 проверки ресурсов, 31 проверка кадров, fmt/clippy/release, baseline smoke, Ajv и PHP/SQLite/HTTP. Один аппаратный тест кадров исключён из обычного прогона.

Release-сборка подготовлена отдельно. Чтение статуса существующего клиента подтвердило ручную паузу и rendering=false; процесс не заменялся.
