# Проверки нативных пауз

Дата: 13 ноября 2026 года. Среда: Windows 11, Rust 1.99.1/MSVC x64. Область: P2-04, OS-07/08. Этап P2 остаётся In progress.

## Автоматические проверки

Полный tools/check.ps1 прошёл: 104 теста клиента, 3 теста протокола, fmt, clippy с -D warnings, release, JSON Schema, PHP syntax, SQLite и HTTP. Шесть новых сценариев выполняются в модуле platform::system_events.

| Проверка | Результат |
| --- | --- |
| Независимые причины | Passed: пробуждение снимает Suspended, сохраняя блокировку, выключенный дисплей и Manual; окончание системных причин сохраняет Manual |
| Сеансы и RDP | Passed: чужой Session ID игнорируется; RDP учитывает настройку, отключение остаётся отдельной причиной |
| Дисплей и время | Passed: выключение приостанавливает, затемнение разрешает работу; неизвестные значения не снимают паузу, быстрый цикл сохраняется в счётчике изменений |
| Начальное состояние | Passed: снимок различает блокировку, подключение и протокол; неизвестный флаг отклоняется |
| WTS собственного сеанса | Passed: запросы возвращают ожидаемые размеры структур и числовые поля; персональные поля не выводятся |
| Скрытое Win32-окно | Passed: нативная регистрация, отправка синтетических WTS/power/end-session сообщений, проверка длины данных, невидимость и уничтожение окна |

WTS-запрос первоначально получил AccessDenied под ограниченным токеном инструментов. Полный прогон с обычным токеном Windows прошёл; это ограничение среды проверки, а не воспроизведение ошибки продукта.

## Нативная приёмка

Not run: настоящие блокировка/разблокировка, сон/пробуждение, выключение дисплеев, выход пользователя, смена сеанса и подключение RDP на Windows 10/11. Работа рендерера после реальных системных переходов и отсутствие всплеска нагрузки требуют отдельной приёмки. Измерение CPU во время паузы не выполнялось.

Проверки не блокируют и не усыпляют рабочий компьютер. Новая release-сборка подготовлена; интерактивный экземпляр не заменялся. Синтетические сообщения адресованы только тестовому скрытому окну.
