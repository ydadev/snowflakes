## Реализация и проверки

Отрицательный ответ возможен только после прежнего solid-overlap, с допустимым внешним временем и доказанно разделёнными диапазонами проекции. Кривизна, округлённый x, допуск решателя, соседние float и сокращение больших слагаемых учитываются запасом; неопределённость оставляет полный поиск. Положительный ответ не создаёт контакт. Старое ядро доступно тестам через отдельную константную ветвь без фильтра. Масса, очередь, геометрия ячеек, коэффициенты и параметры не меняются.

| Новая проверка | Подтверждение |
| --- | --- |
| an_accepted_earlier_hit_skips_the_cell_equations | Обычный путь вызывает решатель, временной фильтр сохраняет результат без построения уравнений |
| initial_solid_overlap_precedes_the_surface_projection_test | Прежний t=0 сохраняется, хотя поверхность сама недостижима в проверяемом интервале |
| a_curved_interior_hit_outside_the_endpoint_strip_is_retained | Настоящее попадание выгнутой траектории вне полосы её концов требует запаса кривизны |
| cancellation_and_solver_residual_uncertainty_keep_the_full_path | Сокращение координат порядка миллиона и близкий к нулю span сохраняют полный поиск |
| invalid_limits_and_uncertain_projections_do_not_reject_the_solver | Невалидные времена, нечисловые/бесконечные/обратные интервалы, точечное ребро и неположительные масштабы сохраняют прежний путь |
