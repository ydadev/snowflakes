# Проверки повторного использования преобразований

Дата: 14 ноября 2026 года. Windows 11 x64, Rust 1.99.1/MSVC, release, 28 доступных логических процессоров. P3-04. [ADR 0040](adr/0040-reuse-body-transforms.md), [методика модели](MODEL_BENCHMARK.md).

Проверена замена повторных вычислений sin/cos на снимок преобразования одного тела. Контуры и физические параметры сохранены. Это оптимизация модели и проекции, не новая механика снега.

## Варианты и вход

A использует прежнюю математику физики из 869da7e; B — BodyTransform. Оба содержат одинаковый новый наблюдатель с отпечатком состояния. Бинарные копии сохранены отдельно, рабочий клиент не заменялся. Прогоны выполнялись последовательно, без параллельной сборки.

Каждый запуск: seed 24301, 120 шагов прогрева и 3600 измеряемых шагов. Сначала baseline A/B, затем material-stress в порядке A/B/B/A. Нагрузка — 4800 активных пластов, 812 ожидающих частей в 128 пакетах, одинаковые 40814/12279 ячеек активных/ожидающих профилей. Пересоздание эпизода каждые 120 шагов остаётся отдельной метрикой.

## Совпадение наблюдаемых состояний

Для всех четырёх material-прогонов совпал sampled_active_and_drift_hash версии 1; для обоих baseline он тоже совпал. Наблюдатель использует одинаковый порядок обхода, float::to_bits и 64-битный некриптографический отпечаток. Входят активные положения, скорости, углы, масса, профиль, преобразованные вершины, единицы и ключи слоя, а также mass/pending ячеек опор и счётчики.

Снятие выполняется через 30 шагов и на границах эпизодов, вне таймера World::step. CPU процесса включает этот наблюдатель. Совпадение — дополнительное свидетельство для выбранных состояний, не криптографическое доказательство и не полный снимок скрытых полей World. Отдельная проверка подтверждает, что изменение скорости либо ожидающей массы меняет отпечаток при прежних бюджетах.

До полного прогона Passed пять существующих сценариев falling_masks: узкие перекрытия, геометрия/вращение, актуальные прямоугольники, освобождение масок и FPS/DPI. Проверки контактов, DPI, массы и очередей выполняются общим набором.

## Открытая приёмка

Полный tools/check.ps1 Passed: 262 теста клиента, включая 47 модульных, 122 сценария snow и 5 проверок примера; 3 теста протокола, 33 проверки ресурсов, 31 проверка кадров, fmt/clippy/release, baseline smoke, Ajv и PHP/SQLite/HTTP. Один аппаратный тест кадров исключён из обычного прогона.

Новая release-сборка подготовлена отдельно. Чтение статуса существующего клиента подтвердило ручную паузу и rendering=false; рабочий процесс не заменялся.

Not run: видимая отрисовка, настоящие окна/DPI/hotplug, Windows 10, ввод → кадр, GPU/DWM, ресурсы приложения и восемь часов. Рендерер использует тот же снимок преобразования, но реальный выигрыш FPS не измерялся. Рабочий эффект остаётся выключенным, CUA не возобновлялась. Дождь, сайт и поставка отложены; P2/P3 и полный проект In progress.
