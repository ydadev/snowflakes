# ADR 0001 Основа проекта

Статус: принято. Дата: 12 ноября 2026 года.

## Задача

Создать самостоятельные эффекты снега и дождя для Windows и простое центральное управление, сохранив местный режим и обычную файловую установку сайта.

## Решение

- Windows-клиент на Rust, Windows 10/11 x64.
- Предпочтительный GPU-путь Win32/D3D11/DXGI/DirectComposition с проверкой в P1.
- Панель и API на PHP + SQLite.
- Прямой настраиваемый IP:порт; пример локального стенда 127.0.0.1:805.
- Опрос каждые 10 минут, включённый по умолчанию follow_server и местная галочка отказа.
- Отдельные местный профиль и серверный кеш, независимые причины паузы.
- Общий контракт JSON и примеры для проверок Rust/PHP.
- Самостоятельные код, графика и ресурсы.
- Реальная конфигурация размещения и любые реквизиты исключены из Git.

## Последствия

Сайт не требует постоянно работающего отдельного backend-процесса. Работа клиента в трее нужна для опроса, даже когда эффект выключен. Закрытый процесс запускается обычными механизмами Windows.

PHP и Rust независимо реализуют один контракт, поэтому нужны общие примеры и проверки совместимости. Графический путь остаётся предметом прототипа; итог выбора оформляется отдельным ADR.

## Изменения

Менять это решение следует новым ADR и синхронным обновлением требований, архитектуры и плана.
