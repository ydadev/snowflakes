# ADR 0003 Проверка GPU-слоя

Статус: эксперимент, выбор ещё не подтверждён полностью. Дата: 13 ноября 2026 года.

## Реализованный кандидат

Win32-окно на каждом мониторе использует WS_EX_LAYERED, WS_EX_TRANSPARENT, WS_EX_NOACTIVATE, WS_EX_TOOLWINDOW и WS_EX_NOREDIRECTIONBITMAP. SetLayeredWindowAttributes задаёт общую alpha 255, ShowWindow не активирует окно. WM_NCHITTEST и WM_MOUSEACTIVATE дополняют стили; один HTTRANSPARENT не считается достаточной проверкой.

D3D11 с BGRA создаёт DXGI swap chain: FLIP_SEQUENTIAL, два буфера, SCALING_STRETCH, premultiplied alpha. DirectComposition связывает visual с HWND. Прямоугольники ClearView проверяют этот путь без шейдеров будущей симуляции. Ввод проверяется отдельным процессом с синтетическим окном.

## Полученные результаты и границы

Создание COM-ресурсов, Present, программная пауза и полное пересоздание прошли на Windows 11 с двумя мониторами одинакового DPI. Периодические проверки не обнаружили активацию слоя.

Видимость alpha-композиции и реальный ввод не подтверждены: интерактивная проверка не получила разрешение инструмента до истечения ожидания. Настоящий device lost, Windows 10, смешанный DPI и горячее подключение также остаются Not run. Полная запись — [TEST_RESULTS_P1](../TEST_RESULTS_P1.md).

## Дальнейшее решение

Оставить код изолированным явной командой overlay-prototype. Он не включается обычным запуском и не выдаётся за готовый эффект.

Перед принятием пути закончить P1-03/P1-04. При неудовлетворительном результате сравнить другую конфигурацию композиции либо layered/UpdateLayeredWindow и измерить стоимость копирования. Требования пропуска ввода и производительности сохраняются; второй полноценный рендерер заранее не разрабатывается.
