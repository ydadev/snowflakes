# ADR 0007 Нативная панель настроек

Статус: принято для основы P2. Дата: 13 ноября 2026 года.

## Интерфейс

Модельное состояние остаётся у Controller. Нативная немодальная панель Win32 показывает источник, адрес, режим, четыре независимых регулятора и ручную паузу. В серверном режиме погодные поля доступны только для чтения. При отсутствии проверенного серверного профиля показано ожидание, значения не подменяются местными.

Обычный запуск и повторный запуск без аргументов открывают настройки. ensure-running запускает клиент в трее. Левое действие значка открывает панель, контекстное меню содержит отдельный пункт настроек. Закрытие панели скрывает окно; выход остаётся отдельной командой.

Раскладка задана в DIP, шрифт и координаты пересчитываются по DPI. При недостаточной высоте предусмотрена вертикальная прокрутка и показ элемента, получившего клавиатурный фокус. Обработчик WM_DPICHANGED использует предложенный Windows прямоугольник. Это реализация, а не подтверждение матрицы разных DPI.

Для клавиатурной навигации используется IsDialogMessageW. Уже обработанное сообщение повторно не передаётся TranslateMessage/DispatchMessage. При явном открытии учитывается, что первый ShowWindow может соблюдать скрытое начальное состояние процесса.

## Выполнение команд

GUI не ждёт дисковой операции: отправляет типизированную команду владельцу состояния и проверяет ответ из цикла сообщений. Одновременно ожидается одна команда GUI, очередь ожидающих действий ограничена 32 элементами. Повторные изменения регулятора объединяются внутри одного интервала источника; переключение источника или адреса сохраняет границу порядка. Переполнение сообщается в панели.

Новый снимок публикуется перед подтверждением команды. При ошибке записи сохраняются прежние предпочтения. Подтверждение адреса не затирает текст, введённый после отправки. Сохранение изменённого адреса сбрасывает серверный профиль и текущий запрос в памяти; старый ответ не становится ответом нового запроса. Местный профиль сохраняется, а кеш на диске по-прежнему проверяется на соответствие адресу.

## Частные данные и границы

Внутрипроцессный View содержит адрес для панели и ограничения политики. Он не сериализуется. Публичный Status/Response по IPC не содержит адреса, токена или персональной идентичности. URL проходит прежнюю нормализацию без реквизитов, query и fragment; пустое значение удаляет адрес.

GPU и сетевой транспорт ещё не подключены. Кнопка проверки сервера выключена, панель прямо сообщает состояние разработки. Регистрационный токен, расширенные параметры, реальные системные события и приёмка обеих ОС остаются отдельными задачами.

## Проверка

Проверены Controller, отмена старого ответа, ограниченная очередь и расчёт прокрутки. Скрытые настоящие Win32-контролы проверяют ABI, read-only и проекцию политики. Отдельно на Windows 11 при 100% выполнены открытие, четыре изменения, клавиатурная стрелка, сохранение адреса и переключение источника. Подробности и Not run — в [результатах P2](../TEST_RESULTS_P2.md).
