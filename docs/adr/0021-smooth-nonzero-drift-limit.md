# ADR 0021 Плавное уменьшение ненулевого лимита сугроба

Статус: принято для P3-02/04. Дата: 13 ноября 2026 года. Основание: CT-07 и сохранение принятого поведения роста/смахивания.

Прежний фиксированный предел удаления 48 DIP/с убирал небольшой избыток после уменьшения ненулевого лимита почти сразу. Переход 100 → 99% не имел обещанной длительности 1–3 секунды; ещё не осевший избыток удалялся без перехода.

Каждая ячейка сохраняет последнее применённое значение размера и оставшееся активное время уменьшения. Снижение ненулевого размера задаёт две секунды. Шаг удаляет долю текущего избытка dt / remaining, пропорционально из осевшей и ожидающей массы; удаление учитывается в removed_mass. При неизменной геометрии и без иных воздействий это линейный переход. Пересчёт по текущему избытку сохраняет срок при изменении вместимости окна в ходе перехода.

Пауза монитора не расходует время и не меняет материал. Снимок сцены переносит оставшееся время вместе с состоянием; при изменении числа ячеек масса перераспределяется прежним способом, оставшееся время переносится по пересекающимся ячейкам. В смешанной ячейке выбирается большее оставшееся время. Увеличение размера прекращает этот переход и не создаёт массу. Новый приход не пополняет превышающий лимит участок через deposit_capacity.

Явное выключение опоры и размер 0 сохраняют ранее реализованный переход полного удаления из [ADR 0019](0019-snow-local-options.md). Для ограничений, возникших только из геометрии вне пользовательского перехода, сохраняется прежняя ограниченная обработка ёмкости. Перенос за край опоры и дополнительные ограничения relax остаются отдельными задачами [матрицы](../SNOW_REQUIREMENTS.md).

Общий помощник remove_amount удаляет одну долю осевшей и ожидающей массы, чтобы оба перехода одинаково учитывали баланс. Состояние переходов не входит в профиль и не переживает очистку материала. Смахивание, пласты и силы снежинок сохраняют прежние пути.

Подтверждение: [TEST_RESULTS_SNOW_LIMITS](../TEST_RESULTS_SNOW_LIMITS.md). Визуальная приёмка, обе ОС, реальные DPI и производительность остаются открытыми.
