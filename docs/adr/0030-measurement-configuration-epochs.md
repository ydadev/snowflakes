# ADR 0030 Эпохи настроек при измерении кадров

Статус: принято для диагностики P2/P3. Дата: 13 ноября 2026 года.

## Причина

Опрос состояния раз в пять секунд может увидеть A, затем снова A, пропустив временное B. Счётчики Present и гистограммы за этот период тогда смешивают разные параметры без видимого изменения снимка настроек. Эпохи пересоздания дисплея этого не обнаруживают.

## Рендерер

При --frame-metrics графический поток отслеживает полные действующие Settings, RenderQuality, clear_epoch и desired_effects_enabled. При первом наблюдении и каждом изменении он увеличивает configuration_epoch; возврат к A получает новую эпоху. Копия настроек обновляется только при изменении. Без флага наблюдение не выполняется.

Смена конфигурации разрывает непрерывность интервалов слоёв, не стирая накопительные счётчики. Пауза сама по себе остаётся отдельным разрывом. Внешнее сообщение или команда, которые не были увидены графическим потоком, не считаются наблюдённой конфигурацией. Номер не заменяет запись всех событий окна, аппаратных условий или геометрии сцены.

Снимок кадров имеет schema_version=2 и configuration_epoch. Новая CLI читает прежний снимок v1 с неизвестной эпохой; отсутствие номера не выдаётся за гарантию стабильности. Погодный сетевой контракт и сохранённые настройки не меняются.

## Сборщик

Разность разных configuration_epoch не вычисляется: окно получает configuration_changed, а разность эпох показывает число наблюдённых переходов. Агрегация разделена по паре «эпоха конфигурации, дисплей»; возвращённое A не объединяется с первоначальным A. Частота и p95 вычисляются отдельно, без смешения распределений. CPU/GPU в общих итогах относятся ко всему прогону; для приёмки стабильного профиля нужны полное покрытие и отсутствие неожиданных переходов.

Историческая память ограничена 32 такими парами. Переполнение явно задаёт segment_limit и display_limit, непринятые данные не выглядят полным замером. NDJSON schema_version=3 добавляет сегменты и признаки configuration_tracking, configuration_changes и legacy_windows. Снимки кадров v1 по-прежнему дают частоту, но configuration_tracking=false и эпоха null. Они не подтверждают неизменность параметров.

Полные параметры промежуточного B не восстанавливаются из номера. Гарантия относится к наблюдениям графического потока и перечисленным входам; она не заменяет проверку сцены, питания, DPI и внешней нагрузки. Ручная пауза и запрет возобновления рабочего эффекта сохраняются. [Проверки](../TEST_RESULTS_CONFIGURATION_EPOCHS.md).
