# ADR 0042 Контакт по месту пересечения поверхности

Статус: принято для P3-02/04. Дата: 14 ноября 2026 года. Уточняет [ADR 0041](0041-contact-candidates-per-body.md).

## Задача

Прежний поиск использовал конечный x шага для столбца индекса, высоты и маски. Сегмент мог пересечь открытый край, но закончиться за ним, в перекрытии или над соседней ячейкой. Воспроизведены три пропуска: кромка между столбцами, видимый зазор шириной один физический пиксель и переход с высокой ячейки на пустую.

## Решение

Кандидаты собираются по прямоугольнику строк и столбцов обоих концов сегмента. Горизонтальный запрос ограничен зарегистрированной областью индекса 0..=256. Ключ временного списка содержит обе строки и оба столбца. Для одной ячейки индекса сохраняется заимствованный отсортированный срез; остальные случаи объединяют ID без дублей в прежнем порядке. Срок жизни по-прежнему ограничен обработкой одного тела.

Для каждой подходящей опоры перебираются ячейки профиля в горизонтальном размахе сегмента. У каждой своя плоскость верха y с учётом осевшей и ожидающей массы и текущих единиц площади. Вычисляются t и x линейного пересечения. Контакт принимается, только если этот x принадлежит проверяемой ячейке и полуоткрытой опоре, виден в её span, открыт в двумерной маске и находится на активном экране. Пауза и маски больше не берутся из конечной точки. Выбирается минимальное t; равенство сохраняет порядок ID.

Сохраняется контакт только при движении вниз. Уже возникшее перекрытие выросшим сугробом разрешается при t=0 в начальной точке; тело ниже основания окна проходит дальше. Боковой вход в толщу снега не заменяет удар сверху. Исключение источника, передний слой закрытого окна и переключатели накопления действуют до проверки ячеек.

## Подтверждение и границы

Восемь новых сценариев Passed; три исходные регрессии сначала Failed. Проверены ложные попадания по конечной точке, границы слева/справа, высоты, фильтры, паузы, отрицательные координаты и 100/250% DPI. Сквозной World::step принимает снежинку через узкий зазор и сохраняет баланс массы. [Результаты](../TEST_RESULTS_SWEPT_CONTACT.md).

Контакт остаётся по линейным траекториям выбранных точек контура за фиксированный шаг. Это не доказательство полного пересечения вращающихся рёбер или непрерывной кривой между кадрами. Геометрия пластов, силы, формирование горки, бюджеты и правила курсора не упрощаются. Отпечаток модели может измениться из-за исправленного поведения; совпадение с прежней ошибкой не является критерием.

Нативная матрица, Windows 10, реальный FPS/GPU и длительная устойчивость остаются открытыми. Рабочий эффект не включается; дождь, сайт и поставка отложены.
