# ADR 0044 Местная настройка исключения из захвата

Статус: принято для P2-01/04 и OS-11. Дата: 14 ноября 2026 года.

## Настройка и управление

exclude_from_capture — отдельный bool местного config.toml версии 2, по умолчанию false. Он не входит в сетевой Settings, не меняет погодный профиль и остаётся редактируемым при включённом серверном источнике. Старый файл получает false; неверный тип сохраняет значение по умолчанию с предупреждением.

Команда ExcludeFromCapture и CLI --exclude-from-capture on/off сначала атомарно сохраняют конфигурацию. При ошибке записи новое значение не применяется. Команда не снимает паузу, не очищает снег и не запускает отсутствующий процесс. Панель показывает отдельный местный переключатель и результат применения. Очередь использует самостоятельный ключ и сохраняет существующие барьеры источника.

## Применение к слою

Windows допускает SetWindowDisplayAffinity для собственного окна верхнего уровня; WDA_EXCLUDEFROMCAPTURE поддерживается с Windows 10 версии 2004. Это ограничение совместимых путей захвата, а не универсальное сокрытие. [Microsoft](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity).

Новый слой получает настройку после создания GPU/DirectComposition и до показа. Существующие слои обновляются перед проверкой паузы, поэтому скрытый слой не требует возобновления симуляции. Включение использует WDA_EXCLUDEFROMCAPTURE, выключение — WDA_NONE. После вызова читается GetWindowDisplayAffinity; другой флаг или ошибка чтения не считаются подтверждённым результатом. [Описание чтения](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getwindowdisplayaffinity).

Для пары окно/запрошенное значение выполняется одна попытка. Повтор разрешён изменением значения либо созданием нового слоя при восстановлении/смене экранов. Ошибка этой настройки не запускает восстановление GPU, не замораживает снег и не создаёт цикл вызовов.

## Отчёт и диагностика

Status.exclude_from_capture хранит желание пользователя. capture_exclusion содержит запрос, наблюдённый потоком графики, число существующих слоёв, подтверждений, ошибок и последнюю числовую причину. Ошибка API и другой прочитанный флаг различаются. Дескрипторы окон и сведения о программах в отчёт не попадают.

Ноль слоёв означает ожидание, а не подтверждённое сокрытие. Старый отчёт для другого запроса показывается как ожидающий обновления. Частичная ошибка сохраняет выбранную галочку и пояснение о повторе. Старый IPC-статус читается с безопасными значениями по умолчанию.

Наблюдённая смена флага меняет configuration_epoch кадров. Сборщик ресурсов включает bool в разрешённый снимок, принимая отсутствие поля у старого клиента за false. Быстрый возврат значения не объединяет разные наблюдённые конфигурации.

## Проверка и границы

[Результаты](../TEST_RESULTS_CAPTURE_EXCLUSION.md) подтверждают хранение, команды, скрытую панель, отказ записи/API, паузу и IPC. Отдельная нативная проверка Windows 11 создаёт настоящий скрытый GPU-слой, применяет и снимает флаг с чтением обратно. ShowWindow и Present в ней не используются.

Захват изображения конкретными программами и Windows 10 остаются Not run; OS-11 целиком не принят. [Команды и поля](../CLIENT_CLI.md). Рабочий эффект не включается и не заменяется; вода, сайт и поставка отложены.
