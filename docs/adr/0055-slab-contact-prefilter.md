# ADR 0055 Предварительный отбор контактов целого пласта

Статус: принято для части EN-09, P3-02/04. Дата: 14 ноября 2026 года. Дополняет [ADR 0054](0054-angular-contour-contact.md), не изменяя непрерывный решатель.

## Избыточная работа

После интеграции каждый активный пласт строил скруглённые контуры и проверял их рёбра, даже когда рядом с траекторией не было ни одной опоры. Инструментированный прежний путь воспроизвёл это на одном пласте далеко над землёй: построен один контур, хотя запросов к решателю можно избежать. Проверка отсутствия этой работы сначала Failed.

## Охватывающая граница

До AngularMotion и построения контуров вычисляется ограничивающая окружность из локальных крайних координат профиля. Радиус ограничен суммой максимальных абсолютных x и y; конечные положительные высоты выбираются по тому же правилу, что в contours. Пустоты могут расширить границу, но не соединяют фигуры в решателе.

Прямоугольник охватывает отрезок движения центра и окружность при максимальном из двух масштабов. Поэтому он включает любой промежуточный угол, короткую дугу через ноль и изменение масштаба. Дополнительный запас учитывает расширенные запросы рёбер из ADR 0054: их радиальная L1-норма не больше 2R, а предел угла общий для обоих расчётов. Отдельно добавлены 32 × EPS_f32 × (модуль координат + R × масштаб + 1) для построения контура/линейного преобразования и округление наружу.

Если конечную границу доказать нельзя — нечисловой центр/единицы, неположительный масштаб или переполнение f32 — выполняется полный прежний обход. Такая ситуация не удаляет тело и не считается доказанным отсутствием контакта.

## Ограниченный запрос

Граница переводится в те же строки/столбцы, что запрос ребра. BTreeMap::range посещает только существующие записи; столбцы внутри диапазона строк фильтруются явно. Даже огромный разрыв координат не создаёт цикл по миллиардам отсутствующих строк.

Если в диапазоне нет кандидатов, пропускаются только построение контуров и запросы рёбер. Интеграция, единицы, поза, время жизни, уход за экран и сохранение тела в alive выполняются прежним путём. При наличии хотя бы одного кандидата применяется полный AngularMotion со всеми масками, источником/origins, паузами и выбором первого удара. Фильтр не пытается заранее исключать кандидатов по их типу/видимости.

Постоянного кеша, новых очередей, настроек, IPC или native API нет. Профиль просматривается один раз без создания геометрии. Общий бюджет и баланс массы не меняются.

## Подтверждение

[Шесть новых проверок](../TEST_RESULTS_PREFILTER.md) включают фактические счётчики построенных контуров/запросов, более 50 тысяч границ рёбер в 1134 позах, числовой fallback и огромные разрывы. 16×30 и 240 шагов сравнивают значения всех полей World с вариантом без фильтра, кроме тестовых счётчиков. Принудительное ошибочное отбрасывание всех кандидатов заставило сравнение Failed; после побайтного восстановления всё Passed.

Счётчики, Debug состояния и эталонная специализация существуют только в тестовой сборке. Производственный step использует фильтр без дополнительной пользовательской опции.

В release A/B/B/A средний шаг при 4800 пластах снизился с 4.697 до 0.537 мс, обычная сцена осталась около 0.053 мс. Эти пласты большую часть эпизода находятся вдали от опор; ускорение насыщенного настоящими контактами клиента не следует из этого опыта. Нативная приёмка Windows 10/11, CPU/GPU/память и восемь часов остаются открытыми. Эффект вручную приостановлен; вода отложена.
