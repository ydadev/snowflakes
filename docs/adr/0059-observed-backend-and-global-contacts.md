# ADR 0059 Вычислитель модели и контакты общего пула

Статус: принято для части EN-03/09, P3-04. Дата: 14 ноября 2026 года. Развивает [контактный измеритель](0056-contact-workload-and-zero-hit.md) и [FMA-путь](0058-runtime-fused-contact-evaluation.md).

## Наблюдаемый выбор

Прежний JSON не фиксировал выбранные функции, поэтому разницу локального стенда и CI нельзя было объяснить по backend. Теперь World создаёт и хранит один Evaluator. Тот же экземпляр передаётся AngularMotion, полиному и рекурсии. Read-only contact_backend возвращает закрытую метку этого экземпляра; измеритель пишет contact_evaluator=fma либо portable.

Конструкторы сохраняют соответствие метки и указателей функций. Test-only счётчики на входах value/refine подтверждают фактически вызванные функции для обоих вариантов, включая принудительный portable в World. Контрольные подмены метки и передачи экземпляра выявляются. В release нет этих счётчиков; сведения не содержат имён оборудования или пользователей. Настроек CPU для пользователя и сетевых полей не добавляется. Правила FMA/CPU/OS из ADR 0058 сохраняются.

## Общий активный предел

contact-global создаёт восемь синтетических 3840×2160 при 200%, восемь закрытых источников и 64 принимающих окна. Настоящие связные тела из закрытых источников насыщают общий пул 16000 через release: по 2000 на экран, ниже локального предела 2400. Очередей и начальной массы принимающих крыш нет. Двухэкранный contact-stress сохраняет порядок подготовки и прежний отпечаток.

Каждый эпизод содержит один настоящий World::step. Глобальная проверка требует свежих 16000 тел, баланс 0.1% и значительный прирост массы. Дополнительно каждый экран должен начинать с 2000 тел, терять не менее 90% активного количества и получать на крышах минимум 25% исходной активной массы. Одного общего уменьшения либо хорошего суммарного переноса недостаточно. per_screen содержит число наблюдений, минимумы и сумму полученной массы по каждому синтетическому экрану.

Подготовка/проверки исключены из таймера шага. Эпизоды независимы: это расширение нагрузки общего пула, непрерывный поток не объявляется проверенным. Добавлен третий release smoke в check.ps1 и CI.

## Результат и остаток

[Проверки и замер](../TEST_RESULTS_GLOBAL_CONTACTS.md): шесть новых сценариев, три выявленные мутации, прежние отпечатки совпали. Локальный новый JSON наблюдает fma. Двухэкранный contact-stress около 15.425 мс, contact-global — 74.325 мс; все 120 глобальных шагов превысили DT. При этом каждый экран подтвердил перенос массы, глобальная доля около 0.9919768. Это подтверждённый пробел производительности общего пула. Следующая работа должна локализовать стоимость на этой нагрузке, сохраняя физику, маски и баланс. Нативная приёмка, обе ОС, ресурсы полного клиента и восемь часов остаются открытыми; эффект на ручной паузе, вода отложена.
