# ADR 0077 Полноэкранный режим и накопление снега

Статус: принято для P2-02/04, OS-06. Дата: 15 ноября 2026 года. Продолжает [реестр окон](0009-incremental-window-registry.md) и [паузу монитора](0011-monitor-physics-pause.md). [Проверки](../TEST_RESULTS_FULLSCREEN_CLASSIFICATION.md).

## Основание

Прежний классификатор требовал collect=false. Native использует collect для наличия заголовка и пригодности крыши, поэтому окно на весь монитор с collect=true не вызывало паузу. Обратный случай — максимизированное окно без опоры и с доступной панелью задач — также ошибочно признавался fullscreen. Два новых сценария воспроизвели обе ошибки до изменения условия.

## Решение

WindowInfo отдельно сохраняет maximized из IsZoomed. Запрос выполняется до завершающей проверки PID/потока, исключающей исчезнувший или заменённый HWND. Этот флаг не объявляется признаком fullscreen. collect продолжает управлять только накоплением; поколения и Scene::Window не меняются.

Кандидат — имеющееся в текущем порядке окно GetForegroundWindow, видимое по входным фактам и не являющееся панелью задач. Прежнее покрытие прямоугольника монитора с физическим допуском 1 px проверяется независимо от collect. Скрытое, недоступное, отсутствующее или фоновое окно паузу не создаёт.

Для maximized действует исключение: видимая панель задач выше кандидата в front-to-back порядке и с положительным пересечением данного монитора означает доступную панель. Это включает геометрическую полосу активации автоскрытия. Панель за кандидатом, за краем экрана либо на другом мониторе исключение не создаёт. Обычное окно, занимающее только рабочую область, не проходит исходную проверку покрытия. Результат рассчитывается отдельно для каждого монитора.

Используются уже сохранённые геометрия и порядок. Смена максимизации читает только изменённое окно; reorder не перечитывает известную геометрию. Сохраняются предел 512 окон, объединение 30 мс и резервная сверка раз в секунду. Это изменение классификации; физика, профили, ручная пауза и схема IPC остаются прежними.

## Границы

Это геометрическая модель доступности панели, а не проверка пикселей, успешного наведения или универсальный API эксклюзивного режима. Нативные данные могут меняться между запросами. Source требует front-to-back; текущий adapter получает список через EnumWindows. Справочник перечисления не заменяет проверку соответствия этого списка требуемому порядку. Настоящие панели/автоскрытие, приложения и exclusive swap chain на Windows 10/11 остаются Not run. Приёмка OS-06 целиком не засчитывается.
