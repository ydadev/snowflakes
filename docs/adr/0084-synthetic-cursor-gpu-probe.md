# ADR 0084 Синтетический курсор в нижнем GPU-стенде

Статус: принято для компонентной проверки P3/SN-07. Дата: 15 ноября 2026 года.

## Основание

Физика смахивания описана в [ADR 0012](0012-cursor-sweeping.md). Для связи сохранённой галочки с естественным запасом и GPU используется прежний [частный desktop и мост управления](0081-private-desktop-worker-probe.md). Настоящий рабочий курсор и системные паузы сохраняются; интерактивная приёмка остаётся отдельным условием.

## Решение

Узкий cfg(test) доступ добавляет только существующий скрытый checkbox CursorEnabled, индекс 3/ключ 26, с прежними guards владельца/потока/parent/hidden/enabled/PMv2. Реальные Owner/Controller, временный TOML, View и пробуждение графического потока переиспользованы.

Тестовая Action::Cursor подаёт явный Cursor существующему Weather::advance_models по фиксированному времени. Последующий настоящий update читает Native/Tracker и рисует GPU в том же timestamp; дополнительного шага часов нет. Позиции, скорости и промежутки времени сверяются с бюджетом округления координат f32. Возраст впервые допущенных фрагментов отдельно проверяет ровно один шаг. GetCursorPos не заменяется, системный курсор не перемещается, ввод в рабочий desktop не посылается.

Action::Rest ждёт 120 последовательных шагов без активных тел, spill и очереди обрушений, с общим пределом 7200 STEP. Это естественная стабилизация прежними силами; масса, профили, очередь и часы вручную не задаются. Обычный Settle также учитывает spill, чтобы не принять только что созданную очередь за пустой воздух.

Длительные и видимые метрики полного Worker не выводятся из этого стенда. Conditions, Observer и ручная пауза не подменяются; observed/submitted в трассе управления остаются отсутствующими. Материал вводит только обычный emitter. Прежние launcher/Job Object/watchdog/UOI_IO/NoActivate сохраняются. [Результаты и ограничения](../TEST_RESULTS_NATIVE_CURSOR_SWEEPING.md).
