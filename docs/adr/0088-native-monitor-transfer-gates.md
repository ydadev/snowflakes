# ADR 0088 Адресный GPU-снимок и условия переноса между мониторами

Статус: принято для test-only стенда; двухмониторная приёмка не выполнена. Дата: 15 ноября 2026 года.

## Основание

SN-05/GE-08/09 требуют настоящего переноса и общей идентичности поверхности. Прежний [выбор GPU-слоёв](../TEST_RESULTS_NATIVE_LAYER_SELECTION.md) не переносил естественно нагруженное окно; локальный стенд предоставлял один монитор. Нельзя заменять второй монитор увеличенным виртуальным rect или считать запуск родительского теста положительным переносом.

## Решение

Использовать прежний [невходной startup desktop и Job Object](0081-private-desktop-worker-probe.md), PMv2/NoActivate и собственные NativeTestHost окна. Новые команды выбирают primary/secondary по настоящему списку Windows, сортируя rect; отсутствие вторичного/общей вертикальной границы возвращается явно. Положения и размеры ограничены фактическими рамками. DPI, раскладка и пользовательский desktop не изменяются.

Обычный тест проверяет размещение, независимый DWM/Tracker, ключ окна, нетронутый контроль и отрицательный запрос отсутствующего secondary. Готовая сцена не навязывается при отсутствии native-событий. Отдельное имя фикстура не является доказанным исправлением ERROR_BUSY другого теста.

Прежний readback захватывал первый отрисованный Gpu. Добавить необязательный test-only адресат по живому bitmap: несовпадающий Gpu оставляет запрос, совпавший потребляет один снимок до Present. None сохраняет старый режим. Снимки слоёв читаются последовательно в одном модельном timestamp; идентификаторы COM/ HWND не сериализуются.

Аппаратный report разделяет завершение preflight и transfer_status/bridge_status. При одном экране проверки адресации и ресурсов могут пройти, но положительные ветви не запускаются, массивы переноса пусты, идентичность/сохранение слоёв не отмечены. Значение not_run_distinct_secondary_unavailable остаётся Not run независимо от зелёного результата процесса.

На двух различных мониторах подготовленная ветка получает снег только обычным emitter, замораживает приток при интенсивности 0, ждёт естественного оседания и проверяет запас/пиксели пола каждого экрана. Настоящие primary/secondary/bridge/primary движения проверяют геометрию, ключ, общий баланс, неизменный introduced_mass, ресурсы слоёв и пиксели в текущих рамках материала. Срыв от ускорения допускается и учитывается; большой перенос не заменяется искусственной постановкой World. Пересечение общей вертикальной границы — отдельное условие, другая топология этим не принимается.

## Подтверждение и границы

[Результаты](../TEST_RESULTS_MONITOR_TRANSFER_PREPARATION.md) подтверждают размещение и primary/неверный GPU-захват в debug/release, прежний нативный capture и общий набор. Windows предоставила один монитор; положительные ветви второго экрана только скомпилированы, требуют настоящего исполнения и могут выявить ошибки. Подготовка не закрывает GE-08/09, mixed DPI или видимый вывод.

Однократный ERROR_BUSY при строгом восстановлении прежнего test desktop имеет отдельный незавершённый аудит. Его не скрывать повтором, не игнорировать проверку восстановления и не уничтожать неизвестные окна/системные объекты по предположению. Рабочий эффект остаётся на ручной паузе; вода, сайт и поставка отложены.
