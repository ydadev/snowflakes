# ADR 0091 Предупреждения TOML в локальном журнале

Статус: принято. Дата: 15 ноября 2026 года.

## Основание

TECHNICAL_SPEC требует игнорировать неизвестные параметры конфигурации с записью в локальный журнал. Загрузчик уже возвращал WarningKind, а Controller сохранял их общее количество в Status. Журнал [ADR 0090](0090-local-fault-journal.md) записывал восстановление повреждённого файла, но не обычные предупреждения успешного разбора. Регрессия подтвердила отсутствие записи после загрузки профиля с 13 предупреждениями.

## Решение

При успешном открытии Controller с Recorder подсчитать четыре существующих вида предупреждений: Unknown, WrongType, Adjusted и InvalidValue. Каждой непустой категории соответствует одна запись с фиксированным fault и code.kind=count/code.value. Счётчики u32 насыщаются; на одну загрузку не более четырёх таких событий независимо от числа полей. Сами имена/пути полей и значения в Recorder не передаются: неизвестный ключ тоже может содержать приватный текст.

Recovered сохраняет прежнее отдельное событие и не учитывается повторно. Пустая категория не записывается; отсутствующий/чистый профиль не создаёт историю. Чтение Status не повторяет предупреждения. Повторная загрузка в новом Controller снова отражает состояние своего входного файла.

Разбор и диапазоны полей, восстановление, общий configuration_warnings, настройки, Status/IPC и физика сохраняются. Успешный разбор не перезаписывает исходный TOML. Ротация, ограниченность и возможные потери журнала прежние. Код count расширяет только локальный JSONL, версия схемы 1 сохраняется как совместимое добавление категории; строгий внешний читатель должен учитывать новый вид кода.

## Подтверждение и границы

Три новые проверки проходят через настоящий UserStore/Controller и временный TOML: все категории/нормализация/ручная пауза/сохранность файла, 2500 неизвестных ключей с одной записью, отсутствие истории для чистого/пропущенного файла. Прежняя проверка восстановления требует ровно одно событие. Это не нативная приёмка UI или многосеансового запуска. [Результаты и повторение](../TEST_RESULTS_CONFIG_WARNINGS.md).
