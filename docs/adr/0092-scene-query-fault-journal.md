# ADR 0092 Ошибки общей сцены в локальном журнале

Статус: принято. Дата: 16 ноября 2026 года.

## Основание

В [аудите F1](../SNOW_CLIENT_AUDIT.md) установлено, что Tracker::poll_source поглощал ошибку общего порядка окон/дисплеев: безопасно откладывал сцену, но терял HRESULT. Отдельный MonitorDiscovery в Owner не покрывал этот вызов. Последующий успешный снимок мог полностью заменить наблюдаемое состояние отказа.

## Решение

Tracker получает optional Arc существующего Recorder. Worker привязывает его после Weather::new до первого опроса. При отказе Registry::poll сам Tracker ставит в ограниченную очередь fault=scene_query и code.kind=hresult/code.value. Сообщение Error, пути, заголовки/идентификаторы окон и значения настроек не передаются писателю. Схема и пределы записи/ротации прежние по [ADR 0090](0090-local-fault-journal.md).

Для ограничения повторов хранится только последний неустранённый числовой код. Первый или изменившийся код создаёт попытку записи; одинаковый следующий код подавляется. Поле очищается только при получении Some(Scene). Ожидание, Ok(None), refresh и defer сами по себе эпизод не завершают. Новый отказ после настоящего снимка снова записывается. Recorder привязывается до опросов; динамическое переключение журнала не добавляется в интерфейс.

Регистрация hooks, возврат Ok(None) при ошибке, задержка 100 мс, ready, события и полное обновление Registry не меняются. Ошибка геометрии не переводится в Graphics Recovery и не расходует его бюджет. Status/IPC/панель, физические процессы и настройки сохраняются.

## Подтверждение и границы

Проверки используют настоящий poll_source/Registry и управляемые fallible Source без нативных окон/хуков. Проверяются запись до возможного чтения итоговой сцены, одинаковые/изменившиеся коды, refresh, граница повтора, новый эпизод и полное восстановление геометрии/поколения. Error с синтетическим приватным сообщением оставляет только HRESULT; исправные опросы не создают историю. Общие прежние проверки scene_pending и пауз остаются отдельными регрессиями.

Это проверка кодированного обработчика, а не настоящий отказ EnumWindows/DWM/дисплеев, активный полный Worker или видимая приёмка. Запись остаётся по возможности; переполнение/ошибки диска не превращаются в рекурсивную диагностику. [Результаты и повторение](../TEST_RESULTS_SCENE_ERROR_LOG.md).
